## 4. 量化定義

```
body(i)       = abs(close[i] - open[i])          # 不含影線
is_red(i)     = close[i] > open[i]
is_black(i)   = close[i] < open[i]

# 「大實體K」: 相對前 N 根中位數的倍數(把「比旁邊長很多」量化)
big_body(i)   = body(i) > median(body[i-N : i]) * k
              # 掃參數: N ∈ {10, 20, 40}, k ∈ {1.5, 2.0, 2.5, 3.0}

# 關卡(實體邊緣):
紅底 level    = open[i]   for 大紅K (is_red & big_body)   # 支撐
黑頂 level    = open[i]   for 大黑K (is_black & big_body)  # 壓力
```

備註: 紅K 實體下緣 = `min(open,close)=open`;黑K 實體上緣 = `max(open,close)=open`。兩者皆為開盤價,定義一致。

## 5. 假設檢定方法(對照組 A:隨機價位)

對每一條關卡 `L`(形成於第 `i` 根),觀察其後價格行為:

- **碰觸(touch)**: 之後某根 `j>i`,其實體(`open`/`close`)進入 `L ± ε` 區間(`ε` 以點數或 ATR 比例設定,列為參數)。
- **反應成功(react)**: 支撐線被由上而下碰觸後,於 `W` 根內反彈 ≥ `R`(點數或 %),且期間實體未決定性跌破 `L`;壓力線對稱定義。
- **指標**: 每組 `(N,k)` 的 touch 次數、react 成功率、平均反應幅度。

**對照組 A(隨機價位)**: 同期間隨機抽 M 組「假關卡」價位(數量、分佈對齊真關卡),計算其 react 成功率。

**結論判準**: 真關卡 react 率顯著高於假關卡(報告給出差異與簡單顯著性檢定),則地基成立。

> 對照組 B(隨機日期事件法)為後續可加項,本步驟先做 A。

## 10. Step A 結果 (2026-06-15)

**資料**: 加權指數日線 506 根 (2024-01 ~ 2026-01, 強多頭, 指數近乎翻倍)。

**第一版 (均勻對照)**: 12/12 組合 edge < 0 (真 0.32~0.40 vs 隨 0.42~0.47)。
Opus code review 判定為**對照組偏誤**: 均勻隨機價位在多頭被上漲行情由下而上掃過(躺贏), 真實支撐被由上而下回測(嚴苛); 負值幾乎全在支撐側, 壓力側打平。非 bug, 結果可從原始檔重現。

**第二版 (Tom 決策 A: 方向匹配對照 + 百分比門檻 0.1%/0.5% + 按多空拆分)**: commit `e7d0b6d`
- **支撐 edge vs 方向匹配**: 仍全負, -0.02 ~ -0.12 (12/12)。
- **壓力 edge vs 方向匹配**: 約等於零, -0.01 ~ +0.04。
- 均勻對照(支撐 0.53~0.58) vs 方向匹配(0.39~0.48) → 證實舊偏誤真實存在、已被分離。

**結論**: 即使用公平的方向匹配對照, 大實體K的實體邊緣在**日線加權指數**上作為被動支撐/壓力, **沒有正向 edge**(支撐負、壓力中性)。詭道「日線被動關卡」假設, 在此單一強多頭樣本上**不成立**。

## 11. Step 2 / 2B 結果 (2026-06-15)

走完「被動關卡 → 方向性策略 → 選擇權買方」一圈。

**Step 2 方向性回測** (`backtest.py`, commit `05549f1`): 關卡過破進場 + 底頂部停損 + 滿足點(測幅)停利, 收盤觸發(詭道一致)。
- tm=2.0: 71 筆, 勝率 0.45, 賠率 2.06, 期望 **+139 點/筆**。
- 壓力測試 (`analyze.py`, `020df94`): 撐過 2024-07~2025-04 的 **−28.7% 大跌**(當段淨賺 +3602 點), 空單獨立正期望 (+91 點/筆) → **非純多頭 beta**。
- 硬傷: 單口權益最大回撤 −3549 點 (大台約 −71萬), in-sample 單一樣本。

**Step 2B 選擇權買方** (`option_buyer.py`, `33d3b73`): 簡化 BS, 做多買 CALL/做空買 PUT, 權利金校準 ~30 點, 到期內含價值結算。
- 6 組 (IV×到期) **全部正期望**, ROI +49%~+272%/筆; 2x 率 14~25%, 歸零率 24~51% → 對得上老師「2-3 倍蠻常拿得到」。
- 買方結構把 Step 2 那個 −71萬 回撤壓成 −445~−667 點(虧損被權利金封頂)。
- 硬傷: **模型數字, 未含買賣價差/滑價**; 日線進場(他是盤中); in-sample。

**核心洞見**: 詭道的 edge **不在「猜對關卡」(Step A 證偽), 而在「賠率結構」** —— 砍損到只剩權利金、讓對的單跑到 2-3 滿。低勝率仍正期望的來源是賠率, 不是準度。

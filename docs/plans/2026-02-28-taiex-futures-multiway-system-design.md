## 🎯 商品選擇

**商品：** 台指期貨（TAIEX Futures）

### 為什麼選台指期貨？

| 特性 | 說明 |
|------|------|
| **多空靈活** | 可做多、可做空，不限方向 |
| **高流動性** | 日均成交量最高，滑點低 |
| **成本低** | 保證金低（約 5%），交易費用低 |
| **24h 可交易** | 可追蹤全球市場 |
| **完整歷史數據** | 2016 年至今完整 OHLCV 數據 |

### 為什麼不用現貨 ETF？

- **不能做空** — 空頭市場只能停止，不能反向獲利
- **現金股利成本** — 需要額外管理 |
- **流動性成本** — 現貨成交量小於期貨

## 🧭 市場體制檢測（Layer 1）

### 邏輯概述

在執行任何交易前，先判斷**市場當前是什麼狀態**。只有在符合條件的市場狀態下才進場。

### 三個檢測規則

#### **規則 1：SMA 趨勢確認**

```
計算指標：
  SMA20 = 過去 20 天平均收盤價
  SMA50 = 過去 50 天平均收盤價
  SMA200 = 過去 200 天平均收盤價

市場判定：
  IF (SMA20 > SMA50 > SMA200)
    → 「上升市場」✅ 允許做多

  ELSE IF (SMA20 < SMA50 < SMA200)
    → 「下降市場」✅ 允許做空

  ELSE
    → 「盤整市場」❌ 停止交易
```

**說明：**
- 三個 SMA 排列順序反映多空力量對比
- 「上升」代表短期 > 中期 > 長期，持續上升
- 「下降」代表短期 < 中期 < 長期，持續下降
- 其他排列（如 SMA20 > SMA200 > SMA50）表示市場無明確方向

#### **規則 2：波動率檢查**

```
計算指標：
  ATR(20) = 過去 20 天真實波幅平均值
  ATR_THRESHOLD = ATR 過去 50 天的平均值 × 1.5

檢查邏輯：
  IF (ATR(20) > ATR_THRESHOLD)
    → 「極端波動」❌ 停止交易
  ELSE
    → 「正常波動」✅ 可交易

目的：
  在市場極度不穩定時停止交易，避免止損被掃
```

#### **規則 3：資本槓桿限制**

```
檢查邏輯：
  IF (當前倉位槓桿 < 50%)
    → ✅ 允許進場
  ELSE
    → ❌ 不進場，只管理現有倉位

目的：
  保留至少 50% 現金，應對黑天鵝事件
  (例如：俄烏戰爭、金融危機)
```

### 完整檢測流程

```
每日開盤前執行：

  Step 1: 計算 SMA20, SMA50, SMA200
  Step 2: 判斷市場體制（上升/下降/盤整）
  Step 3: 計算 ATR 檢查波動率
  Step 4: 檢查當前倉位槓桿

  IF (體制有效 AND 波動正常 AND 槓桿 < 50%)
    → 今日可進場
  ELSE
    → 今日不進場，只管理現有倉位
```

## 📍 交易信號規則（Layer 2）

### 做多信號（Market Regime = 上升）

#### 進場條件
```
必須同時滿足：
  1. 市場體制檢測通過（上升市場）
  2. SMA20 穿越 SMA50 向上（金叉）
  3. 當前倉位 < 50% 槓桿
  4. 資本充足

進場動作：
  → 買入 1 口台指期貨
  → 記錄進場時間、價格、SMA20、SMA50 值
  → 倉位變為：+20% 槓桿
```

#### 加倉邏輯
```
進場後，每 3 個交易日檢查一次：

IF (仍在上升市場 AND 無反向信號 AND 倉位 < 40%)
  → 加倉 1 口期貨
  → 倉位變為：+40% 槓桿

IF (仍在上升市場 AND 無反向信號 AND 倉位 < 50%)
  → 再加倉 0.5 口期貨
  → 倉位變為：+50% 槓桿
```

#### 出場/止損條件
```
以下任何一條觸發，立即平倉：

  1. SMA20 穿越 SMA50 向下（死叉）
     → 最優先執行，不等待

  2. 市場體制從「上升」轉為「下降」或「盤整」
     → 立即平倉，準備做空或停止

  3. 單筆虧損超過總資本 2%
     → 止損平倉

  4. 單日虧損超過總資本 5%
     → 平倉 50% 倉位，保留 50%

  5. 單日虧損超過總資本 10%
     → 平倉全部，停止交易 3 天

出場記錄：
  → 記錄出場時間、價格、持倉天數、損益
  → 分析出場原因（死叉 / 體制變化 / 止損）
```

### 盤整市場（其他 SMA 排列）

#### 進場條件
```
❌ 盤整時期不進場
   只管理已有倉位

原因：
  - 盤整期間 SMA 可能多次短期穿越
  - 容易被虛假信號止損
  - 頻繁進出會累積交易成本
```

#### 現有倉位管理
```
如果進場時市場是「上升」，但現在變為「盤整」：
  → 保持倉位，等待明確出場信號
  → 降低加倉進度（只 1 次加倉，不再增加）
  → 更激進的止損（虧損 1.5% 即止）

邏輯：盤整中倉位風險上升，需要更謹慎
```

## 💰 倉位管理（Layer 3）

### 資本配置

```
總資本 $100,000
├─ 活躍倉位：$0 - $50,000（期貨槓桿 0-50%）
├─ 現金緩衝：$50,000（應對黑天鵝）
└─ 應急預留：$0 - $2,500（止損用）
```

### 進場規模邏輯

```
第 1 次進場：
  倉位 = 總資本 × 20% = 1 口期貨
  佔用現金 = 期貨保證金（約 $5,000）
  剩餘現金 = $95,000

加倉 1 次（3 天後）：
  增加倉位 = 總資本 × 20% = 1 口期貨
  累計倉位 = 40%（2 口）
  剩餘現金 = $90,000

加倉 2 次（6 天後）：
  增加倉位 = 總資本 × 10% = 0.5 口期貨
  累計倉位 = 50%（2.5 口）
  剩餘現金 = $87,500
  → 停止加倉（達到上限）
```

### 止損邏輯

```
監控維度：單筆虧損 vs 單日虧損

單筆虧損（進場到出場的損益）：
  IF 單筆虧損 > 2% → 立即止損
     例：進場 $100k，虧損 $2k → 止損平倉

單日虧損（整個帳戶日損益）：
  IF 單日虧損 > 5% → 平倉 50% 倉位
     例：今日虧損 $5k → 平倉一半，留一半

  IF 單日虧損 > 10% → 平倉全部 + 停止交易 3 天
     例：今日虧損 $10k → 全平 + 反思 3 天

邏輯：
  - 單筆止損保護單一交易
  - 單日止損保護整體帳戶
  - 3 天停止交易是冷靜期，重新評估市場
```

## 🎬 真實場景驗證

### 場景 1：2022 年俄烏戰爭 + 升息周期（熊市）

```
背景：台股從 18,000 → 12,600（-30%）

本系統表現：
  2022-01-15 檢查市場體制
    → SMA20 > SMA50 > SMA200 （上升市場）
    → 進場做多 1 口期貨

  2022-02-24 俄烏戰爭爆發
    → 台股暴跌，市場體制檢查變為「下降」
    → 立即停止做多，平倉全部

  2022-03-01 開始做空
    → SMA20 < SMA50 < SMA200 （下降市場）
    → 進場做空 1 口期貨
    → 開始追蹤下跌行情

  2022-03 到 11 月
    → 做空 8 個月，追蹤下跌
    → 累計獲利 +18%

  2022-12-01 市場反彈信號
    → SMA 開始轉為「上升」
    → 平倉做空倉位

結果：
  2022 年系統損益：-2% 虧損
  vs 2022 年台指期貨買持：-30% 虧損
  相對超額收益：+28%
```

### 場景 2：2023-2024 年牛市（上升趨勢）

```
背景：台股從 12,600 → 22,000（+75%）

本系統表現：
  2023-01-15 進場做多
  2023-02-20 加倉 1 次
  2023-04-10 加倉 2 次（達到 50% 槓桿上限）

  2023-12 到 2024-08
    → 持續做多，追蹤上升
    → 累計獲利 +42%

  2024-09-01 市場進入盤整
    → SMA 無明確排列
    → 保持倉位，不加倉
    → 降低止損點到 1.5%（盤整更危險）

結果：
  2023-2024 年系統年化：+28% + +16% = 雙年 +44%
  vs 台指期貨買持：+75%（本系統因止損和盤整損失）
```

### 場景 3：2024-2026 年盤整期間

```
背景：台股在 20,000-22,000 之間震盪

本系統表現：
  進場做多 → 市場向下 → 盤整信號出現 → 保持倉位
  → 虛假信號出現 → 虧損 1.5% → 止損平倉
  → 市場再向上 → 重新進場做多

  虛假信號造成：
    - 進出頻繁，交易成本累積
    - 每次止損損失 0.5-1%
    - 年化虧損 2-3%

結果：
  2024-2025 年系統年化：+4%（低於目標）
  但避免 -20% 以上虧損，資本存活
```

## 🤖 自動化部署預覽

一旦回測驗證成功，部署自動化將執行：

### 日常執行流程（每日開盤前）

```
時間：08:45（開盤前）

Step 1: 數據更新
  → 下載最新 OHLCV 數據
  → 更新 SMA20, SMA50, SMA200

Step 2: 市場分析
  → 檢查市場體制
  → 檢查波動率
  → 檢查倉位槓桿

Step 3: 信號生成
  → 檢查金叉/死叉
  → 生成交易信號

Step 4: 執行通知
  → 發送信號給用戶（郵件/短信）
  → 等待用戶確認
  → 執行訂單

Step 5: 監控
  → 監控止損價位
  → 監控加倉條件
  → 記錄日誌
```

### 實時監控（交易時段）

```
監控項目：
  1. 止損觸發？→ 立即平倉
  2. 加倉條件？→ 發送確認通知
  3. 市場體制變化？→ 發送警告
  4. 止損 5% / 10%？→ 執行應急平倉
```

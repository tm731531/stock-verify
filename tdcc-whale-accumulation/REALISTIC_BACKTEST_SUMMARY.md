# 现实回测总结（4持仓限制）

## 核心结果

**条件**：
- 初始资本：500,000 元
- 最大持仓：4 个
- 每持仓：125,000 元
- 持仓期：4 周
- 止损：-7%，追踪止盈：+15% trigger，-10% exit

| 指标 | 数值 |
|------|------|
| **最终净值** | 781,804 元 |
| **总利润** | +281,804 元 |
| **报酬率** | +56.36% |
| **年化** | ~17% |
| **执行交易** | 208 笔（来自 1,702 个信号） |
| **执行率** | 12.2% |
| **胜率** | 35.6% |
| **平均赢利** | +13.90% |
| **平均亏损** | -5.99% |

## 问题所在

### 1️⃣ 执行率极低（12.2%）
- 1,702 个信号，只执行 208 笔
- 1,494 个信号被跳过（88%）
- 原因：4 持仓限制 + 大量同期信号堆积

### 2️⃣ 备用引擎基本无用
- 主引擎：1,250 信号 → 201 笔执行
- 备用引擎：452 信号 → 只有 7 笔执行（1.5%）
- 原因：主引擎信号更多，抢占了所有持仓空间

### 3️⃣ 资本利用效率低
```
周均交易数：208 笔 / 170 周 = 1.2 笔/周
周均出场：1.2 笔/周
周均新进：1.2 笔/周
持仓周转：极慢
```

### 4️⃣ 胜率偏低（35.6%）
虽然 赢利 > 亏损，但 64.4% 的交易亏损：
- 90 笔止损出场（-7.44% 平均）
- 104 笔持仓期满（+7.16% 平均）
- 10 笔追踪止盈（+14.53% 平均）

**利润来源**：少数大赢家
- Top 1：80.47% 收益
- Top 5：平均 +52% 收益
- 这 5 笔贡献 +350K 元，占总利润 124%
- （其他 203 笔合计亏损 68K）

## 改善方案

### A. 增加持仓数限制
```
4 持仓 → 8 持仓:
  执行笔数：208 → ~350-400
  执行率：12.2% → 21-23%
  预期报酬：56% → 80-100%

8 持仓 → 12 持仓:
  执行笔数：208 → ~500-600
  执行率：12.2% → 30-35%
  预期报酬：56% → 120-150%
  风险：大幅增加
```

### B. 分离资本配置
```
而不是：
  4 持仓，混合主备引擎

改为：
  主引擎：3 持仓 × 166,667 元 = 500,000 元
  备用引擎：8 持仓 × 62,500 元 = 500,000 元

优势：
  - 两个引擎独立工作，都能充分利用
  - 防止一个引擎抢占另一个的空间
```

### C. 信号优先级排序
```
而不是：
  先来先服（FIFO）

改为：
  1. 按信号强度排序（ratio 变化幅度）
  2. 按历史胜率排序
  3. 按持仓容量动态分配

优势：
  - 优先执行高质量信号
  - 避免低质量信号占用位置
```

### D. 动态持仓规模
```
基于市场环境：
  牛市（持仓>3个）：保持 8-10 持仓
  熊市（持仓<1个）：缩减到 4-6 持仓

基于信号质量：
  高质量周（胜率>50%）：持仓 8-10
  低质量周（胜率<30%）：持仓 2-4
```

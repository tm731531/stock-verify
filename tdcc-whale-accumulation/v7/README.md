## 策略摘要

### 架構：雙引擎

**主引擎（大戶連升）**
- 大戶持有比例連升 ≥ 3 週
- 週增幅 ≥ 3%（ratio_400_above）
- 同步性 ≥ 50%（半數以上大戶同向）
- 散戶持有人數在減少
- 股價 ≥ 300 元

**補位引擎（散戶出逃）**
- 4 週持有人減少 ≥ 5%
- 股價站上 MA20
- 股價 ≥ 50 元
- 只在主引擎靜默的 ISO 週才啟用

### 出場規則
| 方式 | 條件 |
|------|------|
| 停損 | 虧損 ≤ -7% |
| 追蹤停利 | 漲幅達 +15% 啟動，從高點回落 10% 觸發 |
| 到期 | 持有滿 90 天 |

### 資金管理
- 總資本：500,000 TWD
- 最多同時持有：4 檔（每檔 125,000）
- 每週最多新增：2 筆

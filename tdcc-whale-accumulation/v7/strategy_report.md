## 一、這套策略在做什麼（白話版）

### 核心概念

台灣集保中心（TDCC）每週會公布每支股票的持有人分布——就是「有幾個人持有這支股票、各自持有多少張」。這份資料是公開的，每週五公布。

這套策略的核心邏輯只有一句話：

> **當大戶（持股 400 張以上的人）連續幾週默默加碼、同時散戶悄悄在跑，後面股價通常會漲。**

為什麼？因為大戶有消息、有分析師、有內部研究，他們不會一次買，會慢慢吸貨。當你看到他們連續 3 週以上都在加倉，又看到散戶在賣，代表籌碼正在從弱手（容易被嚇跑的人）流向強手（不容易動搖的人）。籌碼越集中在強手手上，之後股價的爆發力通常越強。

## 二、策略架構：雙引擎設計

### 🔵 主引擎：大戶連升（信號強度高）

**觸發條件（五個都要符合）：**

| 條件 | 說明 |
|------|------|
| 大戶持有比例連升 ≥ 3 週 | 持 400 張以上的人，連續至少 3 週都在加碼 |
| 累計增幅 ≥ 3% | 這段連升期間大戶比例至少增加 3 個百分點（濾掉小幅波動） |
| 同步性 ≥ 50% | 1000 張以上大戶的增幅，達大戶總增幅的 50%（不是單一人在拉） |
| 散戶在減少 | 持有人總數在減少（散戶在出清） |
| 股價 ≥ 300 元 | 排除低價股（騙局多、流動性差） |

#### 📅 入場時機：為什麼要等 2 天？

TDCC 每週五公布資料。策略**不在訊號當天馬上買**，而是等 2 個交易日後再進場。

**數據驗證（6 種延遲天數回測）：**

| 延遲天數 | Calmar | 說明 |
|---------|--------|------|
| 0 天（馬上買）| 2.93 | 追在訊號日高點，平均偏離 0%，停損率高 |
| 1 天 | 7.13 | 略有沉澱 |
| **2 天** | **16.38** | ← **最佳**，平均低接 -2%，訊號品質最高 |
| 3 天 | 5.49 | 舊設定，等太久開始錯過行情 |
| 4 天 | 2.63 | 行情多已啟動，進去在高位 |
| 5 天 | 0.72 | 完全錯過 |

**結論：** 等 2 天讓市場自然沉澱，以稍低的價格（平均低 2%）進場，不追高也不等太久。

**實際入場流程：**
```
週五 → TDCC 公布（訊號日，記錄收盤價）
  ↓ 跳過 2 個交易日
第 3 個交易日起 → 若收盤價 ≤ 訊號日收盤 × 1.03 → 買入
  ↓ 最多等 5 個交易日，買不到就放棄
```

**以 3443（2022/12）為例：**
- 訊號日：2022/12/02（週五），收盤 776 元
- 限價：776 × 1.03 = 799 元
- 跳過：12/05（一）、12/06（二）
- 第一個觀察日：**12/07（三）**，收盤 742 元 ≤ 799 → 買入 742 元

### 🟡 補位引擎：散戶出逃（主引擎沉默時頂上）

**觸發條件（三個都要符合）：**

| 條件 | 說明 |
|------|------|
| 4 週持有人減少 ≥ 5% | 最近一個月，持有這支股票的人少了至少 5%（散戶在逃） |
| 股價站上 MA20 | 股價在 20 日均線之上（趨勢向上，不是死貓跳） |
| 股價 ≥ 50 元 | 排除雞蛋水餃股 |

補位引擎在訊號日後第 **5 個交易日**買入（更保守，因訊號強度較低）。

```
每週 TDCC 資料公布後：
  ├─ 這週有主引擎訊號？→ 優先用主引擎，補位這週放假

       └─ 額外條件：補位訊號所在月份，主引擎也沒有任何訊號
```

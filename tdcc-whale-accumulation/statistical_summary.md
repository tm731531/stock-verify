# BACKTEST 統計有效性審查 - 執行摘要

## 被審查案例
- **原始版本**：201 筆交易，年化 52.9%，勝率 43.3%
- **修正版本**：81 筆交易，年化 11.1%，勝率 42.0%
- **回測周期**：3.22 年（2022-12-09 ~ 2026-02-26）

---

## 關鍵發現

### 1️⃣ 樣本量分析

| 指標 | 原始版本 | 修正版本 |
|------|---------|---------|
| 交易筆數 | 201 | 81 |
| 統計有效性 | ✓ 足夠 | ✓ 足夠 |
| 論證 | n > 30 | n > 30 |
| 結論 | **樣本量都足夠，不是主要問題** | |

**結論**：81 筆交易足以進行統計推論，樣本量本身不是限制因素。

---

### 2️⃣ 分布分析（統計特徵）

| 指標 | 原始版本 | 修正版本 | 健全性評價 |
|------|---------|---------|----------|
| **平均報酬** | 5.17% | 2.69% | 原始版本更高 |
| **中位數** | -4.90% | -4.90% | 相同，都是負 ⚠️ |
| **標準差** | 19.85% | 15.89% | 修正版本風險更低 |
| **偏度** | 2.550 | 2.019 | 修正版本更接近正態 |
| **峰度** | 9.320 | 3.621 | 原始版本異常高 |
| **最大值** | 132.89% | 61.39% | 原始版本有極端交易 |

**統計矛盾的根源**：
- 中位數為 -4.90% 表示 50% 的交易虧損
- 平均值為 +5.17% 表示平均獲利
- **這說明分布被少數大贏交易拉高，不能用平均值代表典型表現**

**分布健全性評價**：
- 修正版本：偏度和峰度都有改善，更接近正態分布
- 原始版本：峰度 9.32 是異常高的（正常分布為 0），表示被極端值主導

---

### 3️⃣ 勝率分析

| 指標 | 原始版本 | 修正版本 |
|------|---------|---------|
| 盈利交易 | 87 筆 (43.3%) | 34 筆 (42.0%) |
| 虧損交易 | 114 筆 (56.7%) | 47 筆 (58.0%) |
| **95% 置信區間** | [36.4%, 50.1%] | [31.2%, 52.7%] |
| **統計意義** | ✓ 顯著 | ✓ 顯著 |

**關鍵警訊**：
- 兩個版本勝率都低於 50%（只有 42-43%）
- 這意味著大多數交易虧損
- 只有通過高獲利/虧損比才能賺錢

---

### 4️⃣ 獲利/虧損比

| 指標 | 原始版本 | 修正版本 |
|------|---------|---------|
| 平均虧損 | -6.67% | -6.68% |
| 平均獲利 | +20.68% | +15.64% |
| **獲利/虧損比** | 3.10x | 2.34x |

**期望值驗證**：
```
原始版本：43.3% × 20.68% - 56.7% × 6.67% = 5.17% ✓
修正版本：42.0% × 15.64% - 58.0% × 6.68% = 2.69% ✓
```

**結論**：修正版本的獲利/虧損比下降，但仍保持正期望值。

---

### 5️⃣ 年化報酬的真實計算（CAGR）

#### 計算結果
| 版本 | 回測期間 | 總報酬 | CAGR 計算 | 報告年化 |
|------|---------|--------|----------|---------|
| 原始 | 3.22年 | 707.02% | 91.38% | 52.9% |
| 修正 | 3.22年 | 131.37% | 29.79% | 11.1% |

⚠️ **重大矛盾**：
- 原始版本：報告 52.9% vs 計算 91.38%（差異 38.5%）
- 修正版本：報告 11.1% vs 計算 29.79%（差異 18.7%）
- 可能原因：報告包含手續費/滑點等成本扣除

#### 線性推算檢驗（失敗）
```
樣本量比率：201/81 = 2.48x
線性推算：29.79% × 2.48 = 73.93%
實際原始版本 CAGR：91.38%
差異：17.46 個百分點

結論：線性推算 NOT 成立 ✗
原因：年化報酬受離群值極大影響，不是線性函數
```

---

### 6️⃣ 離群值分析（統計陷阱的根源）

#### 原始版本
- **離群值數量**：16 筆 (8.0%)
- **範圍**：外於 [-35%, 38.48%]
- **前 5 大離群值**：
  1. 132.89% ← **極端異常**
  2. 80.84%
  3. 71.81%
  4. 68.83%
  5. 55.34%

#### 修正版本
- **離群值數量**：10 筆 (12.3%)
- **最大值**：61.39% (原始版本的 46%)

#### 影響分析
```
刪除原始版本的 132.89% 那筆交易：
  新報酬總和：707.02% - 132.89% = 574.13%
  新 CAGR：66.3% (相比 91.38%)
  
一筆交易造成 25% 的差異！
```

**結論**：
- 原始版本被少數極端交易主導
- 8% 的交易決定了整個 CAGR
- 典型的「超參數優化偏差」或「倖存偏差」

---

### 7️⃣ 統計假設檢驗

#### 獨立樣本 t 檢驗
```
原始版本均值：5.17% ± 1.28% (95% CI: [2.64%, 7.69%])
修正版本均值：2.69% ± 1.47% (95% CI: [0.20%, 5.18%])

t 統計量：1.0033
p 值：0.3166

結論：差異 NOT 顯著 (p > 0.05)
解釋：樣本小時難以達到統計顯著性
```

#### 曼-惠特尼 U 檢驗（非參數）
```
U 統計量：8489.5
p 值：0.5511

結論：中位數差異 NOT 顯著 (p > 0.05)
```

**統計含義**：
- 從統計角度，差異可能來自隨機波動
- 但實際表現差異明顯（91% vs 30%）
- 樣本量小導致統計能力不足

---

### 8️⃣ 倖存偏差檢驗

#### 刪除交易的特徵
被刪除的 120 筆交易（59.7%）表明：
- 極有可能：原始版本的高返回交易集中在特定時期/股票
- 極有可能：修正版本刪除了過度擬合的交易
- 結果：修正版本更保守但更接近真實

#### 指標改善
```
峰度：9.32 → 3.621 (改善 61%)
  → 明顯去除了極端離群值

偏度：2.55 → 2.02 (改善 21%)
  → 分布變得更對稱

最大值：132.89% → 61.39%
  → 去除了極端交易

結論：修正版本進行了有選擇性的篩選
```

## 最終結論

### 🏆 修正版本更值得信任（11.1% CAGR）

**優勢**：
1. **統計分布更健全**
   - 峰度改善 61%，偏度改善 21%
   - 更接近正態分布
   - 統計推論更可靠

2. **去除極端離群值**
   - 刪除了單筆 132.89% 的異常交易
   - 去除超參數優化的扭曲結果
   - 保留"正常"交易

3. **樣本量仍足夠**
   - n = 81 > 30（統計有效性門檻）
   - 足以進行可靠推論

4. **實戰表現預期更準確**
   - 不依賴少數極端交易
   - 代表策略的"正常"表現
   - 降低未來表現不佳風險

**預期表現**：
- 實際年化報酬：10-15%（基於 CAGR 29.79% 扣除成本）
- 勝率：42%（但有高獲利/虧損比補償）
- 穩定性：較高，離群值較少

---

### ❌ 原始版本存在統計陷阱（52.9% CAGR）

**風險**：
1. **分布嚴重扭曲**
   - 中位數 -4.90% vs 平均值 5.17%（矛盾）
   - 峰度 9.32（異常高）
   - 被少數交易主導

2. **過度擬合風險極高**
   - 16 筆離群值（8%）決定整個結果
   - 超參數優化的跡象明顯
   - 未來難以複製

3. **實戰表現可能大幅低於預期**
   - 52.9% vs 計算 91.38%（已有矛盾）
   - 一旦極端交易消失，崩潰
   - 倖存偏差明確存在

4. **統計陷阱信號明確**
   - 勝率只有 43%（低於 50%）
   - 卻聲稱 52.9% 年化（邏輯跳躍）
   - 被少數"倖運"事件拉抬

**預期表現**：
- 實際年化報酬：20-30%（被離群值拉高）
- 實戰可能只有：5-10%（離群值難以重複）
- 穩定性：極低，波動大

---

## 統計陷阱的四大矛盾

| 矛盾 | 現象 | 含義 |
|------|------|------|
| **#1** | 中位數 -4.90% vs 平均值 5.17% | 分布被單側拉高 |
| **#2** | 勝率 43% vs 年化 52.9% | 高獲利/虧損比來自少數大贏 |

| **#4** | 線性推算失效（73.93% ≠ 91.38%）| 年化報酬由複合效應決定 |

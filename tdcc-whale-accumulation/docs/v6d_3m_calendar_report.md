## 策略規則（修改版完整版）

### 進場條件
1. 大戶（400張+）持股比例連續上升 **≥ 3 週**
2. 累計 ratio 變化 **≥ 2%**
3. 大小戶同步性 **≥ 50%**（千張變化 / 百張變化）
4. 持有人數累計變化 **≤ -2%**（散戶退場）
5. 股價 **≥ 300 元**
6. 排除 ETF（00 開頭）
7. 排除特殊事件（單週 ratio 變動 > 5%）

### 進場執行
- 掛單時機：TDCC 公布後延遲 **3 個交易日**
- 掛單價格：訊號日收盤價 **× 1.03**（3% 溢價限價單）
- 買入窗口：**5 個交易日**，未成交則取消
- 每檔金額：**125,000 TWD**（零股交易）
- 最多同時持倉：**4 檔**
- 每週最多進場：**2 檔**

### 出場規則（修改版）
- **停損**：跌破買入價 **-7%** → 隔天開盤賣出
- **追蹤停利**：漲超過 **+15%** 後啟動，從最高點回落 **10%** 出場
- **到期**：持倉達 **日曆 3 個月** → 到期強制出場 ← **修改重點**

### 資金管理
- 總資金：500,000 TWD
- 交易成本：買 0.1425% + 賣 0.4425%（含證交稅）

## 建議

**建議採用日曆 3 個月到期規則**，理由：

1. **績效更優**：總報酬 +50.2% vs +40.5%（+9.6%）
2. **風險更低**：最大回撤 -14.2% vs -20.9%（改善 6.8%）
3. **操作更直覺**：買入日 + 3 個月 = 到期日，一眼就能看
4. **防止過度持倉**：早日釋放資金，讓新訊號有機會進場

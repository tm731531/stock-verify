## 💥 核心案例分析

### 案例1：1472股票（補位引擎）

**交易訊號：** 2024-09-06
**買入價：** ~35元

#### 42天版本
```
買日：20240906  賣日：20241112
持倉：42天（到期強制出場）
報酬：-3.4% （虧5,015元）
出場原因：到期
```

#### 90天版本
```
買日：20240906  賣日：20250310
持倉：90天（到期出場）
報酬：+24.4%（賺29,664元）
出場原因：到期
```

**差異影響：** **+27.8pp 差異** = 虧5千 → 賺3萬
**原因：** 42天版本在股票剛回檔的時候就出場了，股票在第42天左右只是小幅回升，實際上整個漲幅是在後續的4個月才完成的。

## 💡 為什麼90天優於42天的根本原因

### 1. **鯨魚吃貨的時間週期**
- TDCC大戶訊號代表「開始集中買進」
- 實際上升需要**4-8週**才能充分反應市場
- 42天 ≈ 6週 ≈ 訊號發出後的**沉澱期** ← 還在低位盤整
- 90天 ≈ 13週 ≈ 訊號發出後的**反應期+加速期** ← 股票開始起飛

### 2. **追蹤停利啟動條件**
- 需要漲15%才啟動追蹤停利
- 短週期內許多股票無法達到15%漲幅
- 42天被迫到期時，常常只有0-10%漲幅
- 90天持倉給了股票更多時間達到15%，然後再由追蹤停利接手

### 3. **補位引擎的特性**
- 補位引擎識別「散戶出逃」（持有人大幅下降）
- 這代表股票已經經歷了大戶初期買進
- 補位進場時股票已經**偏離最低點**
- 股票仍需要4-6週才能完整反彈
- 42天不足以等到完整反彈

### 4. **市場週期特性**
- 台股TDCC持股每週五公布
- 訊號發出→大戶開始買進→媒體關注→散戶跟進 = 約2-3個月週期
- 42天 ≈ 6週（還在上升初期）
- 90天 ≈ 13週（剛好涵蓋完整週期）

## 🎯 結論

### ❌ 不應該用42天
- Calmar 只有2.15（相當於3.97倍差距）
- 2023年虧損37,886元，2025年也損失225,836元
- 強制到期出場比例過高（25%），導致過多未成熟交易被平倉
- 年化報酬 +50%不足以補償风险（回撤-23.3%）

### ✅ 應該用90天（v7.1配置）
- **Calmar 8.53** —— 風險調整後報酬遠優於42天
- 最大回撤只有-15.0%（相對安全）
- 2023年轉虧為盈（+53,086），2025年大幅獲利（+272,949）
- 到期強制出場比例少（只有13%），讓大多數交易自然達到停利或停損

### 💡 v7.2相比v7.1的改進
- v7.1延遲3天 → Calmar 8.53（90天）
- v7.2延遲2天 → Calmar 16.38（官方驗證）
- 延遲天數差1天，Calmar差異47%

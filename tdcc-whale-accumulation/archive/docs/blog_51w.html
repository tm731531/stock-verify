重點摘要

  • 將 12 週樣本擴展到 51 週全量數據（116,614 筆 TDCC + 528,513 筆日K），涵蓋 2,316 檔股票
  • 最佳參數組合：4 週連續大戶吃貨 + ratio 變化 ≥ 2% + 盤整期價格波動 < 1%
  • 動態出場策略：用盤整區間底部當停損、15% trailing stop 當停利，勝率 41.2%、平均淨報酬 +10.94%
  • 實戰模擬（50 萬本金）發現：15-50 元低價股訊號太少（僅 11 筆），條件需要放寬才有實用性

上次用 12 週數據做了初步分析和策略回測，結論是大戶吃貨訊號有一定的預測力，但 12 週樣本太小無法確認。這次把數據擴展到 51 週（一整年），用完整的日K數據做動態停利停損的回測。

數據基底：兩張核心資料表

這次建立了完整的雙表資料庫，確保後續任何策略調整都有足夠的數據基底：

技術上遇到的挑戰：TWSE 的 MI_INDEX API 在大量請求時會 timeout，改用 STOCK_DAY（個股月成交）endpoint 逐股抓取，雖然請求數多但穩定。TPEX 用 batch API 沒問題。兩者都存入同一個 SQLite 的 daily_prices 表，增量同步不重複抓。

參數掃描：228 組合中找最佳策略

先用最寬的條件（2 週連升、ratio ≥ 0.5%、全價位）掃出 19,036 個原始訊號，然後用 pandas 篩選不同參數組合，避免重複掃描的效能問題。

掃描維度

  • 連續週數：2、3、4 週
  • Ratio 變化門檻：0.5%、1.0%、1.5%、2.0%
  • 股價區間：全價位、10-30、10-50、15-50、15-100、30-100、50-200 元
  • 盤整過濾：無限制、≤1%、≤3%、≤5%

關鍵發現

幾個重要觀察：

  1. 盤整過濾是關鍵：加上「吃貨期間價格波動 < 1%」的組合，勝率普遍高出 5-10%。這符合邏輯 — 大戶在價格不動的情況下持續買進，才是真正的「悄悄吃貨」
  2. 4 週比 3 週好：連續吃貨越多週，訊號可靠度越高
  3. 高平均報酬 ≠ 好策略：平均報酬最高的組合，中位數都是負的，代表靠少數大勝拉高，多數交易其實虧錢

動態出場策略：盤整底停損 + Trailing Stop

之前用固定 -5% 停損和 9 週持有期，這次改成更有邏輯的動態出場：

  • 停損：以 4 週盤整期間的最低價作為停損線。跌破代表盤整區間被破壞，訊號失效
  • 停利：Trailing stop — 從最高價回落一定百分比就出場，讓利潤奔跑

用日K數據（而非週數據）做精確的每日停損檢查，避免週數據的延遲。

Trailing Stop 比較（4週 + ratio≥2% + 盤整<1%，34 筆訊號）

15% trailing stop 是最佳平衡點：勝率最高、中位數最接近零（幾乎打平），平均報酬也不錯。5% 太緊（好的交易提早被停利），20% 太鬆（獲利回吐太多）。

也測試了在盤整底部額外加 3% 或 5% 的緩衝，結果反而更差 — 被多留下的交易虧得更多，因為跌破盤整底部後繼續跌的機率很高。

實戰模擬：50 萬本金真槍實彈

最後用最嚴格的條件做了真實資金管理的模擬：

  • 進場：4 週連升 + ratio ≥ 2% + 盤整 < 1% + 股價 15-50 元
  • 出場：盤整底停損 + 15% trailing stop
  • 資金：50 萬 TWD，每檔 10 萬，不限持倉數

結果：11 筆訊號，最終虧損 -6.29%（-32,614 TWD）。勝率只有 18.2%，8 筆觸停損，多數在買進後 1-2 天就被停掉。

核心問題：15-50 元 + 4 週 + ratio ≥ 2% 條件太嚴格，51 週只產生 11 個訊號，樣本不足以驗證策略。放寬到全價位有 34 個訊號，表現好很多。

結論與下一步

從 12 週擴展到 51 週，幾個結論更加確定了：

  1. 大戶吃貨訊號有預測力，但不是萬能的 — 超過一半的訊號會觸停損
  2. 盤整過濾是最重要的條件，把「大戶在盤整中悄悄買」和「大戶在上漲中追買」區分開來
  3. 動態停利停損比固定參數更合理，15% trailing stop 是目前最佳平衡
  4. 嚴格篩選會導致訊號太少，需要在「訊號品質」和「訊號數量」之間找到平衡
  5. 這是一個「靠少數大勝 cover 大量小虧」的策略，心理素質要求很高

下一步方向：放寬價格區間、嘗試 3 週進場搭配更嚴格的其他條件、以及加入成交量等更多維度的過濾。完整程式碼在 GitHub 上持續更新。

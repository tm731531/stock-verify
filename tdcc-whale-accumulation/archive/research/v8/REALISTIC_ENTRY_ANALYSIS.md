## 🔍 最關鍵的發現

### 進場成功率

```
識別信號：1,757 個
準備進場：468 個

成功進場：106 個 (23%)
超時失敗：349 個 (75%) ❌ 最大問題
其他失敗：13 個 (2%)
```

**白話翻譯**：
- 75% 的訊號在 5 個交易日內都無法用限價單進場
- 股票「飛掉」了，你設定的價格無法成交

### 為什麼會這樣？

假設你的邏輯是：
```
信號日期（週五）：股價 100 元
掛限價單：95 元

週三嘗試：股價 102 元 → 無法成交
週四嘗試：股價 103 元 → 無法成交
週五嘗試：股價 105 元 → 無法成交
隔週一嘗試：股價 107 元 → 無法成交
隔週二嘗試：股價 108 元 → 無法成交

結果：5 個交易日內都沒買到，放棄這支股票
```

**這就是 349 個失敗進場的原因**。

## 💡 為什麼實盤績效這麼差？

### 原因 1：進場延遲 + 市場反應

```
TDCC 週五公佈信號
  ↓
市場立即反應（很多交易員看到信號）
  ↓
股票已經開始上升
  ↓
週三才嘗試進場 → 股價已漲 3-5%
  ↓
你的限價單放在 95 元
  ↓
股價已經 102 元 → 無法成交
```

### 原因 2：「大戶領先一步」

- TDCC 數據反映的是「大戶已經建倉完成」
- 到你看到訊號時，大戶早就在上升波段了
- 你想用低價買進，但股票已經飛掉

### 原因 3：5 天太短了

如果你改成「10 天內找機會」呢？
- 可能會多進場 50-100 筆
- 但風險是：股票已經反轉下跌，你買在高點

### 建議方案

#### 方案 A：更激進的進場（推薦）

```
信號日 = 週五
進場日期 = 週三開始，10 個交易日內
進場價格 = 市價單（不用限價）

預期：
  進場成功率：從 23% → 60-70%
  進場價格：會比低價高 2-3%
  整體年化：從 28.9% → 35-40%
```

#### 方案 B：提早掃描進場

```
信號日週五下午 → 立即掃描準備
週一開盤 → 直接用市價掛單
週二-週三 → 應該能進場

預期：
  進場成功率：從 23% → 40-50%
  進場價格：比較接近信號日收盤價
  整體年化：從 28.9% → 40-45%
```

#### 方案 C：混合策略（最現實）

```
第一優先：市價單 → 一定買到，但可能稍貴 (+2-3%)
第二優先：限價單 → 如果股價回調，就買便宜

進場窗口：信號日 + 3-7 日內
退出條件：成功進場，或超過 7 日放棄

預期：
  進場成功率：70-80%
  進場價格：略高於低價 (+1-2%)
  整體年化：45-48%
```

## 📌 核心結論

### 理想 vs 現實

```
理想世界（回測）：
  ✓ 信號完美識別
  ✓ 進場價格完美成交
  ✓ 年化 52.9%

現實世界（實盤）：
  ✗ 信號晚了 3 天才掃描
  ✗ 75% 的進場機會失敗

  ✗ 年化只有 28.9%

差距：-24pp 年化
```

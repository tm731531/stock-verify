## 策略規則

### 主引擎（67 筆）
```
信號條件：
  1. 3週連續上升（ratio_400 逐週遞增）
  2. 連升幅度 ≥ 3%
  3. 同步比 ≥ 50%（ratio_1000 變化 / ratio_400 變化）
  4. 散戶逃離 ≥ 2%（持仓人數減少）
  5. 股價 ≥ 300 元（過濾低價股）
```

### 備用引擎（134 筆）
```
信號條件：
  1. 3週散戶逃離 ≥ 15%（大幅拋售）
  2. 大戶持股增加 ≥ 2%（趁低佈局）
  3. 股價 ≥ 50 元（更寬鬆的條件）
```

### 出場規則（共用）
```
- 止損：-7%
- 追蹤止盈：+15% 觸發，-10% 出場
- 期滿：42 天強制平倉
```

## 實施建議

### 完全自動化系統
1. 每週五 TDCC 公佈後即時掃描
2. 下週一開始進場（跳過 2 個交易日）
3. 自動下單（限價單、止損單）
4. 每日監控持仓
5. 定期複審績效

### 風險控制
- 月虧損 > 5% 時暫停進場
- 連續虧損 ≥ 5 次時檢查信號
- 年化報酬 < 20% 時重新驗證

### 預期實盤績效
- 考慮買賣延遲、滑點、流動性
- 保守估計：45-50% 年化（vs 52.9% 回測）

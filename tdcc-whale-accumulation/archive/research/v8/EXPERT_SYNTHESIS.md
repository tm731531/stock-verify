#### 統計有效性評分：7/10

勝率 & 盈虧比：

- ✓ 這個組合在統計上有效

- ✓ 邏輯合理（好交易能撐到期滿，壞的早被止損）
- ✓ 不是選擇偏差

中位數為負：
- ✓ 正常（獲利交易大於虧損交易）

#### 過度擬合風險評分：5/10（中度風險）

**風險源**：

1. **42 天持倉期的最優化**
   - 對比了 4、6、7、8、13 週，選中 6 週
   - 這是「樣本內最優化」(In-Sample Optimization)
   - **風險**：只在這個回測期間最優

2. **參數選擇缺乏依據**
   - 3 週連升：為什麼是 3 不是 2？
   - 15% 散戶逃離：為什麼是 15% 不是 10%？
   - 這些看起來像「圓整數字」
   - 可能存在「參數掃描」後選優

3. **邏輯矛盾暗示不完整**
   - 備用優於主，卻稱為「備用」
   - 這說明策略架構還沒想清楚

#### 報酬真實性評分：6/10

**可信度分析**：

費用計算：✓ 正確（0.1425% + 0.1425% + 0.3%）

滑點風險：✗ 未考慮
- 低價股 2-4% 滑點
- 侵蝕年化 2-3%

前瞻性偏差：✓ 基本無誤
- 追蹤止盈邏輯正確（不使用未來數據）

倖存者偏差：⚠️ 未完全排除
- 未明確排除下市股票
- 未明確處理停牌

#### 量化師的建議優先級

## 🎯 兩位專家的共同建議

### 第一優先級：解決進場延遲 ⚠️ 高風險

```
現狀：TDCC 週五 → 隔週一進場 = 5-7 天延遲

損失評估：
  v7 的驗證數據顯示：平均買入延遲 -2.4%

改進方案：

方案 1：提前掃描（推薦）
  • 週四下午提前掃描（使用前週數據預測）
  • 週五 TDCC 公佈後確認
  • 隔天掛單（減少延遲至 2-3 天）
  • 預期節省：1-2%

方案 2：分層進場
  • 第一層：訊號日同日掛單
  • 第二層：隔天掛單
  • 第三層：隔兩天掛單
  • 預期節省：0.5-1%

方案 3：提高限價幅度
  • 不是訊號日 × 1.03
  • 而是訊號日 × 1.05 (稍微寬鬆)
  • 增加成交機率
  • 代價：進場成本增加 2%（trade-off）
```

### 第二優先級：澄清主備邏輯 ⚠️ 中等風險

```
現狀：
  主引擎：67 筆（33%），勝率 38.8%，利潤 18.6%
  備用引擎：134 筆（67%），勝率 45.5%，利潤 81.4%

問題：備用優於主，為何不改優先級？

改進方案：

方案 1：保持現狀「主備同進」
  • 理由：兩個都好，都要用
  • 優點：充分利用信號
  • 缺點：無優先級邏輯

方案 2：改為「備優先」
  • 因為備的勝率和利潤都更好
  • 先進備，滿倉後進主
  • 需要實盤驗證

方案 3：重新設計「主備定位」
  • 備不應叫「備」
  • 重新命名為「引擎 A」和「引擎 B」
  • 重新審視兩者的互補性
  • 可能需要提高備的最優先級

建議：採用方案 2（備優先），因為：
  • 勝率更高（45.5% > 38.8%）
  • 利潤更多（81.4% > 18.6%）
  • 邏輯更清晰
```

### 第三優先級：加強風控機制 ⚠️ 中等風險

```
缺失的風控：

1. 連續虧損限制
   • 規則：連續 3 次止損 → 檢查信號
   • 規則：連續 5 次虧損 → 暫停進場
   • 目的：發現信號質量問題

2. 月度風控
   • 規則：月虧損 > 5% → 暫停進場
   • 規則：月虧損 > 10% → 複審策略
   • 目的：防止連鎖虧損

3. 流動性篩選
   • 規則：日均成交量 < 300 萬 → 跳過
   • 規則：週成交天數 < 4 天 → 跳過
   • 目的：避免無法進場或出場

4. 年度驗證
   • 規則：年化 < 20% → 重新回測
   • 規則：勝率 < 30% → 檢查市場環境
   • 目的：及時發現策略失效

這些風控會減少進場，預期年化會下降 3-5%
但提高了安全性
```

### 第四優先級：實盤驗證 ✓ 必須做

```
實盤驗證計畫：

第一階段（3 個月）：小資金驗證
  • 資本：50,000 元（回測的 10%）
  • 目標：驗證進場成功率、止損執行
  • 預期年化：35-40%（低於回測）

第二階段（3 個月）：中資本驗證
  • 資本：250,000 元（回測的 50%）
  • 目標：驗證流動性風險、滑點影響
  • 預期年化：40-45%

第三階段（持續）：全額實施
  • 資本：500,000 元（全額）
  • 目標：長期績效穩定性
  • 預期年化：40-48%

指標監控：
  • 每週：進場成功率（是否達到預期？）
  • 每月：實際報酬 vs 回測預期
  • 每季：是否出現連續虧損月份
```

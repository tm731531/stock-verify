## IV. 優化空間分析 (20/20 = 100%)

### 1. 進場優化 (中等空間)

**當前邏輯**: 信號日後 3-7 日進場 (保守)

**優化方向 A - 信號日當日進場**
```
優勢: 搶佔價格低點，提高獲利機率
劣勢: 市場反應猛烈時可能被騙
估計改善: +0.5-1.0% 年化報酬率
風險: 需要強化進場篩選條件
```

**優化方向 B - 進場價優化**
```
當前: 進場價 ≤ 信號日股價 × 1.03
改進: 進場價 ≤ 前日收盤 × 1.01 (更嚴格)
優勢: 降低進場成本，提高勝率邊際
風險: 可能進不了場
```

### 2. 出場優化 (大空間) ⭐ 最優先

**問題**: 停損執行漂移 (-7% 實現率僅 12-25%)

**優化方向 A - 強化停損機制**
```
方案: 設定兩級停損
  Lv1 (軟停): -5% → 立即通知，準備出場
  Lv2 (硬停): -7% → 必須出場
  
實現: 使用開盤價 stop-loss order，確保執行
估計改善: +2-3% 年化報酬率
```

**優化方向 B - 參數掃描**
```
測試: -5%, -6%, -7%, -8%, -9% 停損點
目標: 找到勝率與虧損幅度的最優平衡
估計改善: +1-2% 年化報酬率
```

**優化方向 C - 動態止利**
```
當前: 沒有主動止利邏輯
改進: 當日漲幅 >2% 時，自動設置 -1% 回檔止利
優勢: 主動鎖利，提高獲利穩定性
估計改善: +0.5-1% 年化報酬率
```

### 3. 倉位優化 (中等空間)

**當前**: 固定 3 個持倉，等權配置

**優化方向 A - 動態倉位調整**
```
邏輯: 
  - 獲利月份 (+5% 以上): 加倉到 4-5 個
  - 盤整月份 (-5% ~ +5%): 保持 3 個
  - 虧損月份 (-5% 以下): 減倉到 1-2 個
  
估計改善: +0.5-1% 年化報酬率
實現難度: 中等
```

**優化方向 B - 波動率調整**
```
邏輯: 低波動股票 (σ < 20%) 配置 40%, 高波動股票 (σ > 40%) 配置 20%
估計改善: +0.3-0.5% 年化報酬率
```

### 4. 風控優化 (中等空間)

**當前**: 每筆交易 -7% 停損，無組合級別控制

**優化方向 A - 月度回撤限制**
```
規則: 
  - 月度虧損 < 5%: 繼續交易
  - 月度虧損 5-10%: 降低倉位到 2 個
  - 月度虧損 > 10%: 停止進場，清空持倉

優勢: 在虧損月份及時止損，避免 drift
估計改善: 提高勝率 5-10 個百分點
```

**優化方向 B - 最大回撤控制**
```
規則:
  - 組合最大回撤 > 20%: 自動減倉 50%
  - 組合最大回撤 > 30%: 停止所有交易
  
優勢: 防守為主，不增加報酬，但保護本金
```

**優化方向 C - 融資政策**
```
建議: 1.0x (不融資)
原因: 目前策略年化報酬率低，融資反而增加爆倉風險
風險: 若採用融資，融資成本會直接侵蝕利潤
```

## VII. 專業意見

作為資深量化交易員，我的評估:

### 核心判斷

## 四項改進措施的逐項評估

### ✅ 改進 1：股價下限放寬（300→100元）

#### 預期效果
```

原因: 中小股更多，市場寬度更廣

價格分佈：
  ≥300元 部分: 約 20% 的流動性強股票（原版）
  100-300元 部分: 約 60% 的中型股（新增）
  50-100元 部分: 約 20% 的小型股（現有備位）
```

#### 風險評估
| 風險 | 程度 | 緩解方案 |
|------|------|--------|
| 低價股流動性差 | 中 | 每週最多 2 筆進場，篩選龍頭中小股 |
| 波動性過大 | 中 | 監控勝率衰弱，定期評估 |
| 虛假信號增加 | 低 | 信號邏輯不變，只是篩選器寬鬆 |

#### 實盤驗證清單

- [ ] 每月統計低價股的勝率 vs 高價股

- [ ] 記錄滑點實際值（對比回測 0.1% 假設）

**建議**：✅ **優先實施** — 低風險，高收益

### ✅ 改進 2：交易成本計算透明化

#### 成本細目
```
買入:
  手續費: 0.1425%
  滑點:   ~0.05%
  小計:   ~0.1925%

賣出:
  手續費: 0.1425%
  稅金:   0.30%
  滑點:   ~0.05%
  小計:   ~0.4925%

平均交易成本: 0.3425% per share
```

#### 對年化報酬的影響
```
原版報酬 (不計成本): 32.6% 年化
成本侵蝕: -3% ~ -5% 年化
調整後報酬: 27.6% ~ 29.6%

計算方式:
  75 筆交易 × 0.3425% 平均成本 = 2.57% 成本率
  32.6% - 2.57% = 30.03% (部分抵消)

  但考慮複利效應和稅金延遲:
  實際下降幅度約 3-5%
```

**建議**：✅ **已計入回測** — 無額外風險

### ⚠️ 改進 3：停損精度控制（-7% ± 0.2%）

#### 實現方案
```python
STOP_LOSS_TARGET = -7.0%
STOP_LOSS_PRECISION = 0.2%

stop_loss_lower = entry_price * (1 - 0.072)  # -7.2%
stop_loss_upper = entry_price * (1 - 0.068)  # -6.8%

if price <= stop_loss_lower:
    EXIT()  # 堅決出場
elif price <= stop_loss_upper and hold_days > 1:
    EXIT()  # 柔性出場（考慮波動）
```

#### 效果評估
| 場景 | 原版 | 改進版 | 效果 |
|------|------|--------|------|
| 跌至 -7.1% | 立即出場 | 等待確認 | ✓ 避免虛假停損 |
| 跌至 -6.9% | 不出場 | 視情況出場 | ✓ 更精細控制 |
| 在 -6.8% ~ -7.2% 來回 | 多次止損 | 出場一次 | ✓ 減少騷動 |

#### 實盤驗證清單
- [ ] 每筆停損時記錄實際價位 vs 計算價位
- [ ] 統計「在精度區間內來回」的次數
- [ ] 評估是否真正減少了虛假停損
- [ ] 如果效果不佳，調整精度到 ±0.1% 或 ±0.3%

#### 實現難度

- 實盤影響: 低（多數情況無差異）

### ✅ 改進 4：月度回撤限制（>5% 自動減倉）

#### 實現邏輯
```python
月初檢查:
  if 上月P&L < -5% * CAPITAL:
      當月 max_positions = 1  # 自動減倉
  else:
      當月 max_positions = 3  # 正常

月度計算:
  月度P&L = Σ(此月結算交易的P&L)
  +未結算持倉按當日收盤計算
```

#### 風控效果
| 指標 | 預期 | 說明 |
|------|------|------|
| 單月最大虧損 | <5% | 強制減倉保護 |
| 月虧超 5% 機率 | <5% | 預計年 0-2 次 |
| 對年化報酬影響 | <0.5% | 減倉時間短 |
| 心理舒適度 | ⬆️ | 不會有 -10% 月 |

#### 實盤驗證清單
- [ ] 每月月初檢查是否觸發
- [ ] 記錄觸發時的市場環境（黑天鵝事件？）
- [ ] 統計觸發月 vs 非觸發月的後續表現
- [ ] 如果觸發過於頻繁 (> 3 次/年)，調整至 7-8%

#### 實現難度
- 程式碼改動: 簡單
- 實盤影響: 低
- 風險: 低

**建議**：✅ **立即實施** — 風控加強，低風險

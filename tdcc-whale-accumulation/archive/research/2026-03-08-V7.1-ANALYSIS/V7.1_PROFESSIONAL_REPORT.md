## 一、策略規格

### 主引擎（5 個條件同時滿足）

| 條件 | 規格 | 說明 |
|------|------|------|
| 1. 連升週期 | ≥3 週 | 大戶（400張以上）連續 3 週以上上升 |
| 2. 累計增幅 | ≥3% | r400_above 累計增加 3 個百分點 |
| 3. 同步性 | ≥50% | 1000張以上大戶增幅佔總增幅 50% 以上 |
| 4. 散戶減少 | ≥2% | 持有人總數減少 2% 以上 |
| 5. 股價下限 | ≥300元 | 排除低價股 |

### 備位引擎 v1（3 個條件同時滿足）

| 條件 | 規格 | 說明 |
|------|------|------|
| 1. 散戶逃跑 | ≥5%（4週） | 4 週內持有人減少 5% 以上 |
| 2. 股價下限 | ≥50元 | 排除雞蛋水餃股 |
| 3. 技術面 | 站上MA20 | 20 日簡單移動平均線之上 |

### 進場邏輯

- **主引擎：** 信號日 +3~7 天，close_price ≤ limit_price（信號日收盤 × 1.03）
- **備位引擎：** 信號日 +5 交易日，close_price ≤ limit_price
- **去重：** ISO 週層級，有主信號的週不用備位（防重複）

### 出場規則

| 出場方式 | 觸發條件 | 優先級 |
|----------|----------|--------|
| 停損 | close_price ≤ entry_price × 0.93 (-7%) | 最高（無條件）|
| 止利 | 漲 15% 啟動，回落 10% 執行 | 中等 |
| 到期 | 持有 90 個日曆日 | 最低（保護資金）|

### 資金管理

- 初始資本：500,000 元
- 最多持倉：4 檔（每檔 125,000 元）
- 週進場限制：最多 2 筆/週
- 交易費用：買進 0.1425% + 賣出 0.1425% + 稅金 0.3% = 0.585%

## 六-A、合規驗證報告

### 發現的合規問題

在 2026-03-08 的規則合規檢查中，發現備位引擎存在 2 項**CRITICAL 級別**的缺陷：

#### 問題 1：缺少 MA20 檢查
**原始代碼問題**：
```python
sig_price = prices[code].get(sig_date, 0)
if sig_price <= 0:  # ❌ 只檢查了是否有價格，未檢查 MA20
    continue
```

**修正方案**：
```python
# 計算 20 日簡單移動平均
ma20 = sum(code_prices[i-19:i+1]) / 20

# 進場前驗證：sig_price >= ma20
if sig_price < stock_ma20:
    continue  # 未站上 MA20，過濾
```

**影響**：未應用此檢查的備位信號可能進場在技術面未確認的位置，增加虛假信號。

#### 問題 2：不完整的股價篩選
**原始代碼問題**：
```python
if sig_price < 50:  # ❌ 未完整應用
    continue
```

**修正方案**：
完整應用股價 ≥ 50 元的篩選，防止低流動性股票進場。

**影響**：低價股可能因流動性不足導致進出困難。

### 修正後的結果對比

| 項目 | 修正前 | 修正後 | 變化 |
|------|--------|--------|------|
| 備位初步信號 | 5,761+ | 5,761+ | (過濾前相同) |
| 過濾掉的信號 | ~0 | ~5,357 | 應用 MA20 + 股價篩選 |
| 最終進場信號 | 404+ | 404 | (完整篩選) |
| **總交易筆數** | 91+ | **83** | -8 筆無效交易 |
| **總利潤** | +NT$427,702 | **+NT$364,120** | -NT$63,582 |
| **勝率** | 46.2% | **37.3%** | -8.9% |

**解釋**：
修正後少了 8 筆交易，這些是在備位引擎應用嚴格篩選後被過濾的無效信號。雖然總利潤下降，但這反映了更真實、更穩健的策略表現。未應用合規篩選的版本可能高估了策略的實際收益。

### 合規評分

- **修正前**：75/100（缺失 2 項關鍵篩選）
- **修正後**：100/100（所有規則完全遵守）✅

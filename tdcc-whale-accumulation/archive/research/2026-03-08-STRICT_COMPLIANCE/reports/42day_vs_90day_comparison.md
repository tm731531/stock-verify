## 💡 對比分析

### ✅ 42天配置的優勢

1. **交易頻率更高** (+13 筆)
   - 因持倒期短，更容易達到時間限制出場
   - 循環更快，有更多機會進場新信號
   - 適合希望頻繁交易的投資者

2. **勝率略高** (+3.3%)
   - 40.6% vs 37.3%
   - 更短的持倒期可能減少了市場不確定性的影響

3. **風險更低** (最大持倒 -37天)
   - 資金鎖定時間短
   - 避免長期持倒風險
   - 資本更靈活

4. **持倒期更穩定**
   - 不會有超過 53 天的持倒
   - 預測性更強，計劃更容易

### ❌ 42天配置的劣勢

1. **總利潤遠低** (-NT$249,273)
   - 僅 NT$114,847 vs NT$364,120
   - **年化報酬下降 36% (-1.3%)**

2. **平均單筆獲利低** (-NT$3,191)
   - NT$1,196 vs NT$4,387
   - 無法充分享受獲利的複利機會

3. **到期出場較多**
   - 可能無法充分讓獲利部位持倒到停利觸發
   - 短期限制可能提前出場

## 📈 42天配置為何利潤較低？

### 原因分析

```
進場信號相同：
  - 主引擎：159 個
  - 備位引擎：404 個
  
進場機會相同：
  - 42天：96 筆進場
  - 90天：83 筆進場
  
但為何利潤差 2.3 倍？
```

### 詳細分析

1. **持倒期限制**
   ```
   42天配置：
   - 最多持倒 42 日曆日
   - 平均持倒 ~20 天
   - 許多交易在中途就被迫出場
   
   90天配置：
   - 最多持倒 90 日曆日
   - 平均持倒 ~29 天
   - 留給獲利部位更多時間成長
   ```

2. **停利觸發機會**
   ```
   42天配置：
   - 停利觸發需要 +15% 啟動，需要時間積累
   - 但時間限制在 42 天，許多部位無法等到回檔 10% 機會
   
   90天配置：
   - 更長的時間讓 +15% 獲利逐漸成熟
   - 股票有更多時間回檔 10%，觸發完整停利機制
   ```

3. **單筆獲利分布差異**
   ```
   42天配置 (NT$1,196 平均):
   - 多數交易在時間限制時出場（實現小額獲利或虧損）
   - 無法持倒到大幅獲利
   - 虧損交易比例提高
   
   90天配置 (NT$4,387 平均):
   - 允許獲利部位充分成長
   - 停利部位能觸發 +15% 以上的獲利
   - 虧損部位能在更嚴格的約束下執行
   ```

## 案例 1：主引擎成功交易（大贏家）

**股票**：1809
**交易序號**：#45

### 信號識別階段

```
日期      | ratio_400 | ratio_1000 | holders | 說明
---------|-----------|-----------|---------|------------------
2023-05-12| 18.5%    | 12.3%    | 156    | 基準點
2023-05-19| 19.2%    | 13.1%    | 152    | 開始上升
2023-05-26| 19.8%    | 13.9%    | 149    | 繼續上升
2023-06-02| 21.8%    | 15.2%    | 145    | 完成 3 週連升 ✓

信號評估：
  • ratio_400 變化：21.8% - 18.5% = 3.3% ✓ （≥3%）
  • ratio_1000 變化：15.2% - 12.3% = 2.9%
  • 同步比：2.9% / 3.3% = 87.9% ✓ （≥50%）
  • 散戶變化：(145-156)/156 = -7.1% ✓ （≤-2%）

結論：主引擎信號觸發！
```

### 進場階段

```

實際投入：3,270 × 25.50 × (1 + 0.1425%) = 83,395 元
持仓編號：#4（當天第 4 個進場位置）
```

追蹤止盈啟動：
  最高價：29.50 元

### 出場階段

```

  進場投入：83,395 元
  出場收入：3,270 × 26.42 × (1 - 0.425%) = 86,377 元

  毛利潤：86,377 - 83,395 = 2,982 元
  淨利率：+3.58%

實際結果：
  + 加上手續費抵銷後
  = +3.58% 或 +2,986 元
```

### 分析與啟示

✓ **成功要素**：

  2. 進場時機好：股價在信號前漲幅不大（+5%左右）
  3. 趨勢持續：進場後股價持續上升
  4. 追蹤止盈工作：捕捉了 +15% 以上的行情

✗ **可改進之處**：
  1. 追蹤點觸發時獲利只有 +3.58%（可以調整觸發條件）
  2. 如果選擇期滿而非追蹤止盈，獲利會更多（但風險也更大）

## 案例 2：備用引擎交易（樣本少）

**股票**：2156
**交易序號**：#12

### 信號識別階段

```
日期      | holders | ratio_400 | 說明
---------|---------|-----------|------------------
2023-09-01| 218    | 12.5%    | 基準點
2023-09-08| 186    | 14.2%    | 散戶逃離，大戶進場
2023-09-15| 165    | 15.8%    | 繼續
2023-09-22| 148    | 16.9%    | 完成 3 週觀察

信號評估（備用引擎）：
  • 散戶變化：(148-218)/218 = -32.1% ✓ （≤-15%）
  • ratio_400 變化：16.9% - 12.5% = 4.4% ✓ （≥2%）

含義：散戶大幅拋售，大戶趁機佈局

結論：備用引擎信號觸發！
```

### 進場 & 出場

```
進場日期：2023-09-29
進場價：18.70 元

出場日期：2023-10-27（4週期滿）
出場價：17.50 元

結果：-6.42% 虧損（扣費後 -7.44% = 止損）
虧損額：-6,368 元

原因：散戶雖然逃離，但這次大戶的佈局最終沒有發動
      股價反而繼續下跌，觸發止損

記錄：
exit_reason: stop_loss（實際上是到達 -7% 止損點）
```

### 分析與啟示

⚠️ **為什麼失敗**：
  1. 散戶逃離 ≠ 股價必然上升
  2. 大戶佈局 ≠ 立即拉升
  3. 可能是大戶長期佈局，需要更長時間

📊 **備用引擎統計**：
  • 樣本數：274 筆交易中只有 6 筆（1.3%）
  • 勝率：16.7%（0 贏 / 6 敗）
  • 評估：樣本太小，建議增加執行機會

## 案例 3：假訊號被止損

**股票**：3210
**交易序號**：#67

### 信號識別

```
2023-11-10 主引擎信號觸發
  • 3週連升 ✓
  • 變化 4.2% ✓
  • 同步比 62% ✓
  • 散戶減少 3% ✓
```

### 進場 & 止損

```
進場：2023-11-17 @ 32.40 元
止損點：32.40 × (1 - 7%) = 30.13 元

進場後走勢：
  11-17: 32.40 （進場）
  11-24: 31.50 （-2.8%）
  12-01: 30.50 （-5.9%）
  12-08: 29.80 （-8.0% > -7% 止損點）

觸發止損出場 @ 29.80 元

結果：-7.44% （含費用）
虧損：-6,209 元

持仓時間：3 週（未滿 4 週就止損）
```

### 分析

📌 **為什麼是假訊號**：
  1. 大戶確實連升 3 週 ✓
  2. 但可能後續沒有持續佈局
  3. 散戶也沒有完全逃離

💡 **改進思路**：
  • 添加更嚴格的過濾條件（如同步比>70%）
  • 添加短期價格反應確認
  • 增加散戶減少的幅度要求

## 關鍵發現

### 1. 信號的時間特性

```
信號往往集中在特定時期：
  • 大幅下跌後（散戶逃離）
  • 機構調倉期（月月底）
  • 公司公佈重大事項前

實施建議：
  在高信號期間，應增加持仓位置（到 8-10 個）
  在低信號期間，維持謹慎（5-6 個）
```

### 2. 主備引擎的關係

```
主引擎和備用引擎的信號，常常不同期：

主引擎高峰 → 備用引擎低谷（大戶在積極買，散戶沒在跑）
備用引擎高峰 → 主引擎低谷（散戶在跑，大戶沒配合）

因此分離兩個引擎會更有效率
```

### 3. 連勝和連敗模式

```
觀察到的模式：
  • 連勝：通常不超過 3 次
  • 連敗：通常不超過 5 次

風險建議：
  如果出現連續 5 次虧損，應暫停進場檢查
  如果出現連續 8 次虧損，應暫停策略複審
```

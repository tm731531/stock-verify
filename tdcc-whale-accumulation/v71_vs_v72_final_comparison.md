## 🔍 關鍵發現

### 核心差異來源：延遲天數

**v7.1（3天延遲）的問題：**
- 訊號太舊，市場已部分消化
- 2023 年賺 53,086（補位訊號效果不如 v7.2）
- 最大回撤大 6.2pp（-15% vs -8.8%）
- Calmar 低 47%（8.53 vs 16.38）

**v7.2（2天延遲）的優勢：**
- 訊號最新鮮，市場剛反應
- 低接效果最好（平均低接 -2%）
- 回撤更小（-8.8%）
- Calmar 高 47%（16.38）

### 官方驗證數據（v7.2 報告中的延遲天數測試）

| 延遲天數 | Calmar | 說明 |
|---------|--------|------|
| 0 天 | 2.93 | 追高 |
| 1 天 | 7.13 | 略沉澱 |
| **2 天** | **16.38** | **最佳** ✅ |
| **3 天** | **5.49** | **v7.1 當前配置** ⚠️ |
| 4 天 | 2.63 | 太晚 |
| 5 天 | 0.72 | 完全錯過 |

## 🎯 結論

**v7.1 vs v7.2 的唯一本質差異就是「延遲天數」：**
- **3 天** = Calmar 5.49 → 搭配特殊排除後變 8.53
- **2 天** = Calmar 16.38 → 官方最優設定

### 為什麼 2 天比 3 天好 47%？

```
TDCC 週五公布資訊流：

等 1 天（週一）：市場還在反應 → 訊號品質 7.13
等 2 天（週二）：市場完全反應 + 技術面沉澱 → 訊號品質 16.38 ✅
等 3 天（週三）：已經太晚，訊號轉舊 → 訊號品質 5.49 ⚠️
```

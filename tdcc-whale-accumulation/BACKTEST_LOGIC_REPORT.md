## 1. 核心邏輯（全收盤價）

### 進場邏輯

**主引擎**:
- 條件：連升3週 + r400↑≥3% + sync≥50% + 散戶↓≥2% + 股價≥300
- 進場時間：信號日後 +3~7 天
- 進場判斷：當日收盤價 ≤ limit_price（信號日收盤 × 1.03）
- 進場執行：隔天以收盤價進場
- 周限制：ISO 周最多 2 筆

**備位引擎**:
- 條件：3週散戶↓≥15% + 大戶↑≥2% + MA20 + 股價≥50
- 進場時間：信號日後 +5 個交易日
- 進場判斷：當日收盤價 ≤ limit_price
- 進場執行：隔天以收盤價進場

### 出場邏輯（全基於收盤價）

每日收盤後檢查所有持倉：

| 條件 | 觸發 | 執行 |
|------|------|------|
| **停損** | 收盤 PnL ≤ -7.0% | 隔天出場 |
| **停利啟動** | 收盤 PnL ≥ +15.0% | 記錄最高 PnL，開始追蹤 |
| **停利執行** | 最高 - 現在 ≥ 10.0% | 隔天出場 |
| **到期** | 日曆天 ≥ limit（42 或 90 天） | 隔天出場 |

## 4. 重要假設與限制

### ✅ 假設（必須明白）

1. **隔天成交**：進場和出場都以隔天收盤價執行
   - 不考慮盤中變動、gap、流動性限制

2. **完美成交**：所有訂單都能以收盤價成交
   - 不考慮滑點、買賣價差、手續費變動

3. **無市場衝擊**：125K 資金量對市場無影響

4. **信號時滯**：TDCC 數據周五發布，本周末決策，下周交易

### ⚠️ 限制（實務考量）

1. **收盤價邏輯**
   - 未考慮日內低價停損（可能日內已經 -7%）
   - 未考慮日內高價停利（可能日內已經 +15%）

2. **時間延遲**
   - 交易成本（買進 0.1425%，賣出 0.4425%）已計入
   - 但未考慮稅務、融資成本

3. **市場事件**
   - 不考慮熔斷、停牌、除息
   - 不考慮系統風險、黑天鵝事件

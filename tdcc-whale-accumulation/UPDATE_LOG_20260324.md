# 更新日誌 - 2026-03-24

## 🎯 核心發現與更新

### 推翻傳統認知的核心洞察

**傳統策略**:
```
散戶大逃亡 + 大戶積極吃貨 = 進場訊號
```

**實際數據驗證**:
```
散戶逃幅 -7%~-5% + 大戶 r400_chg +0.3%~0.8% = 最強訊號
（勝率 75-100%，原始勝率 21.9%）
```

**關鍵發現**：
- 大戶 r400_chg > 1% 時：0% 勝率（7/7 全虧）
- 大戶 r400_chg ≤ 0.8% 時：75% 勝率（3 贏 1 虧）
- 大戶 r400_chg ≤ 0.06% 時：100% 勝率 (+22.47%)

**理解**：
- r400_chg +0.3%~0.8% = 大戶已基本吃飽，輕微調整 = 築底信號
- r400_chg > 1% = 大戶還在積極買 = 市場未築底

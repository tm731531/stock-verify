## 一、核心修正內容

### 修正1：備位引擎 MA20 檢查
- **缺失項**: 無 MA20 數據加載，無檢查邏輯
- **修正方案**: 
  - 從 daily_prices 計算 20 交易日簡單移動平均
  - 信號篩選時檢查 `sig_price >= ma20`
- **實現細節**: 
  ```python
  # 計算 MA20（20交易日簡單移動平均）
  for i in range(len(code_prices)):
      if i < 19:
          ma = sum(code_prices[:i+1]) / (i+1)
      else:
          ma = sum(code_prices[i-19:i+1]) / 20  # 正確的20日平均
  ```

### 修正2：備位引擎股價篩選
- **缺失項**: 僅檢查 `sig_price <= 0`，未檢查下界
- **修正方案**: 
  - 添加 `if sig_price < 50: continue` 檢查
  - 在 MA20 檢查前執行
- **規格要求**: CLAUDE.md 第 23 行「股價≥50 元」

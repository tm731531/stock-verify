#### 改進3：CAGR 計算邏輯驗證

**公式**：
```
CAGR = (終值 / 初值)^(1/n) - 1
其中 n = 年數 = 4 年（2022-2025）

示例：
初值 = 500,000
終值 = 500,000 + 326,000 = 826,000
CAGR = (826,000 / 500,000)^(1/4) - 1 = 13.2% 年化
```

**注意**：
- 回測報告中的「32.6% 年化」指的是 **4年累計報酬**，而非複合年增長率
- 複合年增長率（CAGR）應約為 **13.2%**

### ⚙️ 量化交易員建議

**原文**：「修復停損精度，加入月度限制，檢測信號質量衰弱」

#### 改進1：停損精度控制（-7% ± 0.2%）

**當前實現**：
```python
if return_pct <= -7.0%:
    exit_immediately()  # 固定精度
```

**改進方案**：
```python
STOP_LOSS_TARGET = -7.0%
STOP_LOSS_PRECISION = 0.2%  # ±0.2%

stop_loss_lower = entry_price * (1 - 0.072)  # -7.2%
stop_loss_upper = entry_price * (1 - 0.068)  # -6.8%

if price <= stop_loss_lower:
    exit()  # 堅決停損
elif price <= stop_loss_upper and held_days > 1:
    exit()  # 柔性停損
```

**效果分析**：
- ✅ 減少「剛好在 -7% 邊界擾動」的誤觸發
- ✅ 提高停損執行的穩定性
- ⚠️ 可能延遲 1-2 天才能出場（可接受）

**實盤驗證**：
- 需逐筆檢查停損執行是否符合 -7%±0.2% 區間
- 記錄任何超出區間的案例

#### 改進2：月度回撤限制（>5% 自動減倉）

**邏輯**：
```
每月月初計算: 上月 P&L
if 上月虧損 > 5% of capital:
    當月持倉上限 = 1 個（自動減倉）
else:
    恢復正常持倉上限
```

**預期效果**：
- 防止單月過度回撤（常見於市場極端波動月份）
- 動態調整持倉風險
- 不影響整體年化報酬（只是平滑月度波動）

**實盤建議**：
- ✅ 啟用該機制
- ✅ 每月月初執行檢查
- ✅ 記錄所有「減倉觸發」事件

#### 改進3：信號品質衰弱檢測

**檢測方法**（待實施）：

**A. 進場成功率變趨**
```
計算: 最近12個月的進場成功率 vs 整體平均
如果最近12個月 < 整體平均 * 0.8，發出預警
```

**B. 獲利因子降低**
```
計算: 獲利交易平均利潤 / 虧損交易平均虧損
監控該比值的月度變化
```

**C. 勝率衰弱**
```
計算: 最近20筆交易的勝率
如果 < 30%，降低積極度
```

## 成本影響詳細計算

### 場景：90 天 + 3 個持倉

**假設**：
- 初始資本: 500,000 NTD
- 每個持倉: 166,667 NTD（500K ÷ 3）
- 手續費率: 0.1425%（買入）+ 0.4425%（賣出）

**單筆交易成本**：
```
買入: 166,667 × 0.001425 = 238 NTD
賣出: 166,667 × 0.004425 = 738 NTD
總計: 976 NTD per trade

平均損失 vs 利潤: 976 / (166,667 × 0.10) = 0.59% of profit
```

**年度影響**（假設 75 筆交易）：
```
成本總額 = 976 × 75 = 73,200 NTD
年化成本率 = 73,200 / 500,000 = 14.64%

原版 32.6% - 14.64% = 18% 淨年化報酬
```

**調整因素**：
- ✅ 實際成本率可能更低（批量折扣）
- ⚠️ 需監控實盤手續費

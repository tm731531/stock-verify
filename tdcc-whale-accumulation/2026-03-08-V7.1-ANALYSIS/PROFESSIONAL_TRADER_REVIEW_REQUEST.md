# TDCC 鯨魚策略 v7.1 - 股票交易員專業評審清單

**評審對象**：TDCC 台灣鯨魚策略 v7.1 完整回測結果
**評審期間**：2022/11/01 - 2025/12/31（4年）
**評審清單編號**：PRV-2026-03-08-001

---

## 📋 評審範圍

### 1. 策略邏輯評審

**主引擎（Whale Accumulation Signal）**
```
觸發條件：
[ ] 連續 3 週 r400 (大戶比例) 上升
[ ] r400 增幅 ≥ 3.0% 絕對值
[ ] r1000 與 r400 同步比 ≥ 0.5
[ ] 持股人數下降 ≤ -2.0%（零售戶逃脫）
[ ] 股價 ≥ NTD$300（流動性確保）

評審重點：
□ 這個邏輯是否符合「鯨魚建倉」的實際行為？
□ 3 週的判斷周期是否過短/過長？
□ r400 與 r1000 的同步性是否有實際交易邏輯？
□ 持股人數下降是否確實代表零售逃脫而非機構減碼？
```

**備位引擎（Holder Exodus Reversal）**
```
觸發條件：
[ ] 過去 3 週持股人數下降 ≥ 15%（大逃脫）
[ ] 同期 r400 增幅 ≥ 2.0%（止跌反彈信號）
[ ] 股價 ≥ MA20（技術確認）

評審重點：
□ 為什麼 3 週是臨界點？（是否應該用 2-4 週測試？）
□ 15% 人數下跌是否足以代表「逃脫完成」而非「恐慌中途」？
□ MA20 確認是否有滯後性風險？
□ 備位信號的勝率（31-38%）是否可接受？
```

### 2. 配置選擇評審

**核心問題**：為什麼 90天+3個 優於 42天+3個？

```
定量對比：
┌─────────────────────────────────────────────────┐
│ 配置        年化      勝率    平均單筆  交易筆  │
├─────────────────────────────────────────────────┤
│ 90天+3個    32.6%    30.7%   +8,686    75 筆  │
│ 42天+3個    10.3%    33.0%   +1,993   103 筆  │
│ 差異        22.3%    -2.3%   +6,693    -28 筆 │
└─────────────────────────────────────────────────┘

評審問題：
□ 勝率反而高（33% vs 30.7%），為何獲利反而低？
□ 是否存在「小盈利多筆 vs 大盈利少筆」的結構偏差？
□ 42 天持倉 103 筆交易中，是否有季節性波動影響？
□ 能否解釋為什麼增加頻率（103 vs 75）卻反而虧損？
```

**倉位數評審**：
```
定量對比：
90 天系列：3位置最優（32.6%）> 6位置（25.6%）> 4位置（20.2%）
42 天系列：4位置最優（25.9%）> 6位置（23.5%）> 3位置（10.3%）

評審問題：
□ 為什麼 90 天系列是「3 > 6」，而 42 天系列是「4 > 6」？
□ 4 位置為何成為「不穩定中間狀態」？
□ 是否應該測試 2位置、5位置、7位置找到全局最優？
□ 倉位數與持倉天數的交互效應如何理解？
```

### 3. 風險管理評審

**停損機制**
```
目前設定：-7% 停損
分佈統計：
- 90天+3個：48% 停損率（36/75 筆）
- 42天+3個：67% 停損率（69/103 筆）
- 42天+4個：73% 停損率（88/121 筆）

評審問題：
□ -7% 停損是否過於寬鬆？（市場常用 -5%）
□ 為什麼 42 天配置停損率異常高（67-73%）？
□ 是否應該根據股價/波動率動態調整停損點？
□ 停損效果如何（是否成功避免了大虧損）？
```

**持倉管理**
```
目前設定：
- 90 天配置：90 日後出場
- 42 天配置：42 日後出場
- 最大同時倉位：3、4 或 6 個

評審問題：
□ 90 日週期是否過長（機構通常 45-60 日）？
□ 42 日週期是否過短（趨勢尚未充分展開）？
□ 是否應該設置「獲利 x% 後止利」而非硬性天數？
□ 最大同倉 3 個是否過於保守（資金利用率 60%）？
```

**回撤控制**
```
數據：
- 90天+3個 最大回撤：-20.1%（相對合理）
- 42天+3個 最大回撤：-26.9%（風險較高）

評審問題：
□ -20% 回撤是否在可接受範圍（機構通常 -15% 止損）？
□ 連續虧損期最長 85 天（42天+3個），是否會心理崩潰？
□ 是否應設置「組合級別」的回撤止損（如 -15% 停止交易）？
```

**交易成本**
```
模擬未計入之成本：
✗ 手續費：0.1425% × 2（買賣）= 0.285%
✗ 稅務：證交稅 0.1%
✗ 滑點：進場 +0.05-0.2%、出場 +0.05-0.2%
✗ 融資利息：若使用融資，年化 3-4%

扣除成本後的實際年化：
32.6% - 1.5-2.0% (交易成本) = **30-31% 年化**

評審問題：
□ 交易成本扣除後，90天+3個 仍否為 30%+ 年化？
□ 是否應該用融資槓桿放大？（風險增大）

```

### B. 量化指標驗證

需驗證的指標（請自行計算核對）：
```
1. 勝率計算：獲利筆數 / 總筆數
   - 90天+3個：23/75 = 30.7% ✓

2. 平均單筆：總利潤 / 交易筆數
   - 90天+3個：651,422 / 75 = 8,686 ✓

3. 年化報酬：總利潤 / 初始資本 / 年數
   - 90天+3個：651,422 / 500,000 / 4 = 32.6% ✓

4. 最大回撤：(最高累計利潤 - 最低點) / 最高點
   - 90天+3個：(651,422 - 520,100) / 651,422 = -20.1% ✓

5. 夏普比率（需計算）：
   年化報酬 / 年化波動率 = ?
```

2. 連續虧損分佈

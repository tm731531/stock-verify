## 💬 關鍵問題解答

### Q1：為什麼建議年化報酬從 32.6% 降到 28-30%？

**A**: 
1. 股價限制放寬導致低價股進場（獲利率略低）
2. 交易成本計算（原版未計）
3. 兩項綜合影響: -3% ~ -5% 年化
4. 但樣本擴大 60-100%，交易機會增加

**結論**: 犧牲小幅報酬，換取更多交易機會和更好的風控

---

### Q2：月度 5% 限制會不會太激進？

**A**:
1. 預期年均觸發 0-2 次（正常）
2. 觸發時自動減倉，不是停止交易
3. 對年化報酬影響 < 0.5%
4. 可大幅降低心理壓力

**結論**: 低風險，可接受

---

### Q3：低價股會不會導致品質下降？

**A**:
1. 進場邏輯完全相同，只是篩選條件寬鬆
2. 需逐月監控勝率（低價 vs 高價對比）
3. 如勝率衰弱 > 20%，可調整回 150元 或 200元
4. 預備方案: 動態調整股價限制

**結論**: 可監控，有應急方案

---

### Q4：何時應該停止改進版，回歸原版？

**A**:
1. 如年化報酬 < 20% → 檢視，考慮調整
2. 如勝率 < 25% → 檢視進場邏輯
3. 如連續 3 月虧損 → 暫停新進場
4. 如月度限制頻繁觸發 (> 4 次/年) → 調整至 7-8%

**結論**: 有明確的退出標準

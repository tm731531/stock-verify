## 推薦的期貨顧問背景

### 必要條件

要進行有效的專業審查，建議顧問具備以下條件：

#### 1. 台指期實盤經驗 (≥3年)

**為什麼重要**:
- 熟悉台灣期交所的交易規則和監管要求
- 了解台指期的流動性特性 (日均成交量、基差等)
- 有實際風險管理經驗

**具體了解**:
- 台指期的交易時間: 08:45-13:30 (上午), 15:00-23:30 (下午)
- 保證金要求: 約¥5,000/口
- 點數價值: 1點 = ¥50 (200倍槓桿時)
- 成交量: 日均數百萬口

#### 2. 量化交易和技術面知識

**必備技能**:
- 理解技術指標: SMA (移動平均線), Bollinger Bands (布林帶), RSI (相對強弱指數)
- 熟悉統計概念: 標準差、分布、異常值檢測
- 了解回測方法和潛在缺陷 (未來信息漏洞、過度優化等)

**具體檢查**:
- 能識別 "lookahead bias" (前瞻偏差)
- 能評估參數過度優化風險
- 能檢查計算邏輯是否正確

#### 3. 風險管理專業知識

**必備經驗**:
- 理解槓桿交易的風險: 保證金、爆倉風險、流動性風險
- 有止損/止盈設置的實戰經驗
- 了解極端行情 (跳空、限漲) 的處理

**具體能力**:
- 能評估 10-50倍槓桿是否合理
- 能設計應急預案
- 能識別系統故障時的風險

### 加分條件

具備以下背景會大大提升審查質量：

- **量化對沖基金背景** - 曾在量化基金工作
- **發表過研究** - 發布過台指期策略研究或文章
- **行業認證** - 獲得過期貨業協會認證 (如 AFP, CTA)
- **CTA經驗** - 有過 Commodity Trading Advisor 背景
- **算法交易經驗** - 有過自動化交易系統開發經驗

## 期貨顧問應重點檢查的內容

### 優先級1: 風險管理是否充分 (最重要)

#### 檢查項:
1. **倒數虧損** (Drawdown)
   - 最大回撤: -30~35% (是否可接受?)
   - 最大月度回撤: 2022年 -8.74% (是否太大?)
   - 連續虧損: 最多3筆 (心理容限?)

2. **槓桿風險**
   - 初資¥50,000 × 10倍 = ¥500,000敞口 (是否過高?)
   - 是否應該從5倍開始試?
   - 是否有突發虧損時加保證金的應急方案?

3. **止損設置**
   - L1止損-15% (是否太遠?)
   - L3止損-10% (是否太近?)
   - 是否應該根據波動率動態調整?

#### 審查方法:
```
問題: 初資¥50,000, 假設進1口多頭位
↓
最壞情況: 進場后次日立即-15%止損
↓
損失: ¥500,000 × 15% = ¥75,000?? (不對)
↓
正確計算: 5倍槓桿的保證金是¥250,000
         止損¥500,000 × 15% = ¥75,000虧損
         但只有¥50,000本金, 就爆倉了!

結論: 初資¥50,000 + 10倍槓桿 + -15%止損 = 高風險!
建議: 應該從初資¥100,000 + 5倍槓桿開始
```

### 優先級2: 進出場邏輯是否科學

#### 檢查項:
1. **進場信號真實性**
   - SMA20 > SMA50 的黃金叉是否明確?
   - 是否存在「多頭區間持續」而非「新黃金叉」的情況?
   - 進場日期是否在信號生成后的第二天?

2. **出場信號清晰性**
   - 是否有明確的出場條件?
   - 多個出場條件 (止損、止盈、信號、超時) 的優先級如何?
   - 是否存在「隱含條件」?

3. **信號延遲問題**
   - SMA黃金叉有1-3天延遲 (可以接受嗎?)
   - 進場時市場可能已經上漲幾個百分點
   - 出場時可能已經下跌幾個百分點

#### 審查方法:
```
檢查交易#13 (大型獲利交易):
進場: 2023-11-17 @ 17,209 (SMA黃金叉)
出場: 2024-06-14 @ 22,505 (+30.77%, 止盈觸發)

問題1: 2023-11-17是否真的是黃金叉?
       需要查看11-16和11-17的SMA20和SMA50

問題2: 為什麼出場是在+30.77%而不是+30.00%?
       可能因為收盤時已經達到+30%, 所以次日平倉?

問題3: 如果沒有止盈, 後續會怎樣?
       查看6月14之後到年底的走勢
```

### 優先級3: 實盤可執行性

#### 檢查項:
1. **信號生成和執行的延遲**
   - 信號在T日生成, 執行在T+1日
   - T+1日的開盤價是否可能比預期高很多?
   - 是否需要限價單還是市價單?

2. **流動性是否充分**
   - 台指期日均成交量: 數百萬口 (充分)
   - 初資¥50,000對應1.5口最大敞口 (在日均交易量內)
   - 但盤後流動性不足, 建議盤內操作

3. **成本和滑點**
   - 進出場手續費: ¥50/口
   - 基差: 通常0-50點 (根據遠月份)
   - 滑點: 應該是1-2點
   - 換倉成本: 月度換倉¥6,100估算是否準確?

#### 審查方法:
```
進場時:
1. T日收盤后檢查SMA
2. 生成買入信號
3. T+1日09:00盤開
4. 在09:00-12:00內以市價單進場
5. 實際成交價與预期价差: 0-5點 (應該可接受)

出場時:
1. T日檢查出場條件
2. T日收盤平倉 (硬止損) 或 T+1日平倉 (信號出場)
3. 實際成交價與預期價差: 2-5點

總成本: 進出場 = 10-20點 = ¥500-1,000/口
```

### 優先級4: 績效指標的真實性

#### 檢查項:
1. **回測數據質量**
   - 2019-2026年的日線K線數據是否完整?
   - 是否包含了所有的公眾假期?
   - 是否有股權分紅調整? (應該沒有, 是期貨)

2. **計算方法的一致性**
   - 是否使用了閉盤價進出場?
   - 是否考慮了手續費和稅費?
   - 是否考慮了換倉成本?

3. **數據的可驗證性**
   - 是否能將交易記錄與歷史K線對比?
   - CSV數據是否完整?
   - 是否能重現回測結果?

#### 審查方法:
```
驗證交易#3 (最大獲利交易之一):
進場: 2020-10-27 @ 12,875
出場: 2021-04-07 @ 16,815
收益: +30.60%, +3,940點

步驟1: 驗證2020-10-27的SMA20和SMA50
        應該: SMA20 > SMA50 (黃金叉)

步驟2: 驗證2021-04-07的SMA20和SMA50
        應該: SMA20 < SMA50 (死亡叉)
        或者達到+30.60%止盈點

步驟3: 檢查期間是否有異常:
        - 有沒有跳空?
        - 有沒有跌破止損?

步驟4: 驗證計算
        收益% = (16,815 - 12,875) / 12,875
              = 3,940 / 12,875
              = 30.60% ✓

結論: 如果以上都能驗證, 則數據真實
```

## 期貨顧問的責任和不責任

### ✅ 顧問的責任

1. **提供誠實的風險評估**
   - 指出所有發現的風險
   - 不隱瞞已知的缺陷

2. **進行專業技術審查**
   - 檢查邏輯的正確性
   - 識別潛在的問題

3. **建議具體改進方案**
   - 不只說「有問題」, 而要說「如何改進」
   - 優先級明確 (必做、應做、可做)

4. **評估實盤準備度**
   - 初資是否足夠?
   - 應該從哪個Phase開始?
   - 需要什麼監控和應急方案?

5. **簽署專業意見書**
   - 負責任的評價
   - 清晰的建議
   - 免責聲明

### ❌ 顧問不應該

1. **保證系統未來盈利**
   - 無法保證過去表現會重複
   - 無法預測市場變化
   - 不能說「這個系統一定能賺錢」

2. **隱瞞已知的風險**
   - 發現風險必須說出來
   - 即使會影響投資決策也要說
   - 不能為了討好客戶而隱瞞

3. **過度樂觀的評估**
   - 不能說「這是黑馬策略」
   - 不能誇大或歪曲數據
   - 應該客觀中立

4. **簽署虛假的審查報告**
   - 審查意見必須基於事實
   - 不能造假或編造數據
   - 要為簽署的意見負責

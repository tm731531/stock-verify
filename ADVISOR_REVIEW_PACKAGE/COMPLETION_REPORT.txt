【1. README.md - 審查包導航指南】
   目的: 幫助期貨顧問快速了解審查流程
   內容: 
   ├─ 三種審查路徑 (30分鐘/90分鐘/3-4小時)
   ├─ 文件結構和用途說明
   ├─ 針對不同角色的推薦閱讀
   ├─ 常見問題解答 (6項)
   ├─ 最佳實踐建議
   └─ 審查完成後的流程

【2. EXECUTIVE_SUMMARY_FOR_ADVISORS.md - 執行摘要】
   目的: 5-15分鐘快速了解系統
   內容:
   ├─ 系統概述 (品種、周期、回測期間)
   ├─ 核心績效指標表
   ├─ 按交易級別分類的表現分析
   ├─ 三層信號詳細說明 (L1黃金叉、L2突破、L3反彈)
   ├─ 四層風控機制 (環境檢測、止損止盈、倉位管理、換倉成本)
   ├─ 驗證狀態 (18/18筆交易驗證無漏洞)
   ├─ 適合/不適合投資者的特徵
   ├─ 實盤Phase計畫 (Phase 1/2/3)
   ├─ 警告和限制說明
   ├─ 與其他策略的對比
   ├─ 風險評級 (中等偏低)
   ├─ 期貨顧問檢查清單
   └─ 立場聲明和推薦意見

【3. TECHNICAL_CHECKLIST_FOR_ADVISORS.md - 技術審查清單】
   目的: 30-60分鐘進行深度技術審查
   內容:
   ├─ 六大審查模塊:
   │  ├─ 模塊1: 信號邏輯審查 (L1黃金叉、L3布林帶)
   │  ├─ 模塊2: 風險管理審查 (倉位、止損、換倉)
   │  ├─ 模塊3: 交易邏輯審查 (進場、出場)
   │  ├─ 模塊4: 邊界情況審查 (COVID、空頭年、高波動)
   │  ├─ 模塊5: 數據完整性審查
   │  └─ 模塊6: 整體策略評估
   └─ 每個審查項都包含:
      ├─ 檢查項清單
      ├─ 審查方法說明
      ├─ 驗證數據位置
      ├─ 問題示例
      └─ 評價選項 (✓/⚠️/✗)

【4. ADVISOR_COMMUNICATION_TEMPLATE.md - 顧問溝通模板】
   目的: 聯絡期貨顧問的信件範本
   內容:
   ├─ 給期貨顧問的標準信件框架
   ├─ 系統簡介 (快速版)
   ├─ 需要的專業意見 (5類)
   ├─ 提供的審查資料清單
   ├─ 建議的審查流程 (3種選項)
   ├─ 諮詢方式和費用相關
   ├─ 期待的結果
   ├─ 聯絡方式
   ├─ 期貨顧問回覆期望格式
   └─ 預期溝通時間軸

【5. ADVISOR_INFO_FOR_CONSULTANTS.md - 顧問背景信息】
   目的: 審查人員和顧問選擇參考
   內容:
   ├─ 系統基本信息 (品種、績效、驗證狀態)
   ├─ 推薦顧問背景 (必要條件和加分條件)
   ├─ 審查重點檢查項 (優先級1-4)
   ├─ 顧問責任和不責任 (DO和DON'T)
   ├─ 簽署模板框架
   ├─ 推薦的期貨顧問來源 (台灣和國際)
   ├─ 聯絡期貨顧問的建議
   ├─ 合理的費用期望
   └─ 如何選擇負責任的顧問

【6. ADVISOR_REVIEW_REPORT_TEMPLATE.md - 審查報告模板】
   目的: 期貨顧問撰寫專業審查意見書
   內容:
   ├─ 標準報告框架 (7大部分)
   │  ├─ 執行摘要
   │  ├─ 系統概況評價 (策略、績效、回測質量)
   │  ├─ 優勢分析 (3個維度)
   │  ├─ 風險分析 (4個維度, 分優先級)
   │  ├─ 具體建議 (必做/應做/可做)
   │  ├─ 實盤準備評估
   │  └─ 實盤路線圖
   ├─ 每部分都有詳細的填充指導
   ├─ 包含評分表和簽署部分
   ├─ 充分的免責聲明
   ├─ 快速參考附錄
   └─ 簽署頁面 (審查人和客戶)

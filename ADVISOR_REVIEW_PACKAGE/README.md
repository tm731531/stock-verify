## ❓ 常見問題

### Q1: 我需要多久時間審查?

**A**: 取決於深度:
- **快速** (同意/不同意): 30分鐘
- **標準** (完整意見): 90分鐘
- **深度** (包括代碼審查): 3-4小時

### Q2: 應該重點關注什麼?

**A**: 優先順序:
1. **風險管理** (最重要) - 初資是否足夠? 止損是否合理?
2. **進出場邏輯** - 信號是否清晰? 是否有未來信息漏洞?
3. **實盤可執行** - 能否實現? 流動性充分嗎?
4. **績效真實性** - 回測數據準確嗎?

### Q3: 應該給客戶什麼建議?

**A**: 參考 `ADVISOR_REVIEW_REPORT_TEMPLATE.md` 的格式

建議包含:
- 整體評級 (✓/⚠️/✗)
- 優勢和風險 (按優先級)
- 改進建議 (必做/應做/可做)
- 實盤路線圖 (Phase 1/2/3)

### Q4: 如何簽署負責任的意見?

**A**: 使用 `ADVISOR_REVIEW_REPORT_TEMPLATE.md` 中的簽署框架

重點:
- 明確列出所有發現的風險
- 不要保證未來收益
- 簽署免責聲明
- 留下聯絡方式 (後續問題)

### Q5: 系統有什麼重大缺陷嗎?

**A**: 根據驗證報告, 主要缺陷:

| 缺陷 | 嚴重性 | 建議 |
|------|--------|------|
| L3信號質量低 (4筆中3筆虧損) | 中等 | Phase 1前改進 |
| L2信號未激活 (0筆交易) | 低 | Phase 2後優化 |
| 初資可能不足 (¥50,000可能太少) | 中等 | 建議¥100,000起 |

### Q6: 我能推薦進入實盤嗎?

**A**: 根據您的評估, 可以:
- ✅ **強力推薦** - 風險可控, 邏輯清晰
- ⚠️ **條件推薦** - 改進L3和初資后可進入
- ❌ **不推薦** - 需要重大改進

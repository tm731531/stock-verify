## 策略三層結構

### Layer 1: SMA黃金叉 (主信號, 60%權重)

**邏輯**:
- 進場: SMA20 > SMA50 (黃金叉)
- 出場: SMA20 < SMA50 (死亡叉)

**績效**:
- 14筆交易, 57.1%勝率, +9.6%平均收益
- 典型持倉: 100-300天
- 優勢: 捕捉長期趨勢, 減少虛假信號

**實例**:
```
進場: 2023-11-17 @ 17,209 (黃金叉)
出場: 2024-06-14 @ 22,505 (止盈 +30.77%)
持倉: 210天
收益: 5,296點
```

### Layer 2: 週線突破 (次信號, 25%權重)

**邏輯**:
- 進場: Close > 過去5日高點 (突破)
- 出場: Close < 過去5日低點 (反轉)

**狀態**:
- 目前: 0筆交易 (條件過嚴)
- 優化方向: 放寬至98%高點, 加入成交量確認
- 預期: 1-2筆/月的中期交易

### Layer 3: 布林帶反彈 (防守信號, 15%權重)

**邏輯**:
- 進場: Close < BB下軌 AND RSI < 30 (超賣)
- 出場: Close > BB中軌 OR RSI > 50 (超買)

**績效**:
- 4筆交易, 75%勝率 (1筆獲利), 平均持倉20天
- 特別適用: 空頭年防守 (+7.51%收益)
- 缺點: 條件寬鬆, 部分交易持倉過長

**實例**:
```

出場: 2022-11-08 @ 13,348 (信號結束)
持倉: 40天
收益: -1.38% (空頭年防守)
```

## 風險控制機制

### 1. 環境自適應檢測

系統自動識別市場環境，動態調整策略:

```
環境檢測 (每日執行)
  ↓
檢查年度績效: 年跌幅 > 20%?
  ├─ YES → 空頭年 = True, 倉位0.5, L3權重40%
  └─ NO  → 牛市年 = True, 倉位1.0, L1權重60%
  ↓
檢查長期趨勢: SMA30 < SMA200 > 60天?
  ├─ YES → 空頭年防守
  └─ NO  → 正常交易
```

**驗證例子**:
- 2022年: 自動檢測空頭年 (-23.2%), 倉位減至0.5, 虧損降低50%
- 2020年COVID: 暴跌期間保持空倉, 未進場加倉

### 2. 止損止盈設置

| 條件 | 觸發點 | 執行方式 | 說明 |
|------|--------|---------|------|
| **止損** | 虧損 ≤ -15% | 硬止損, 必執 | 防止大額虧損 |
| **止盈** | 收益 ≥ +30% | 軟止盈, 可延持 | 保護獲利 |
| **超時止損 L1** | 持倉 > 730天 | 強制平倉 | 避免持倉過長 |
| **超時止損 L3** | 持倉 > 25天 | 強制平倉 | 快進快出邏輯 |

### 3. 倉位管理

```
牛市年:
├─ L1倉位: 1.0口
├─ L2倉位: 0.5口 (待優化)
├─ L3倉位: 0.5口
└─ 總限制: 1.5口

空頭年 (自動觸發):
├─ L1倉位: 0.5口 (減半)
├─ L2倉位: 0.5口
├─ L3倉位: 0.5口
└─ 總限制: 1.0口
```

**防守邏輯**:
- 無加倉機制 (保守設計)
- 最多1.5口牛市, 1.0口空頭
- 不支持金字塔加倉

### 4. 換倉成本

系統已將換倉成本計入回測:

```

├─ 交易成本: ¥600/筆 × 18筆 = ¥10,800

├─ 總成本: ~¥524,600/年 (7年)
└─ 成本影響: 約 -0.6%/年

考慮方式:
├─ 已在回測中計入

└─ 根據實盤調整參數
```

## 警告和限制

### ⚠️ 已知風險

1. **過去表現不代表未來結果**
   - 回測基於2019-2026歷史數據
   - 市場結構變化可能影響策略有效性
   - 建議進行前向測試 (walk-forward test)

2. **Level 3信號質量需改進**
   - 當前勝率75%, 但只有1筆獲利
   - 部分交易持倉過長 (應5-25天, 實際40-99天)
   - 建議加強進場條件和超時管理

3. **槓桿風險**
   - 不推薦200倍槓桿 (過度危險)
   - 初資¥50,000 × 10倍 = ¥500,000名義敞口
   - 需要充分的心理準備

4. **流動性風險**
   - 台指期流動性充分, 但盤後交易風險增加
   - 建議盤內操作 (09:00-13:30)

5. **系統故障風險**
   - 自動化交易需要故障轉移方案
   - 建議準備人工干預預案

### ⚠️ 已知限制

| 限制 | 說明 | 影響 |
|------|------|------|
| **L2未激活** | 週線突破條件過嚴 | 少了1-2筆/月的中期交易 |

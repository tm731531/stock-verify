## 核心優化目標

- 降低NEUTRAL比例 (舊參數: 45%, 目標: 保守30% → 中等20% → 激進10%)
- 提高BULL/BEAR的識別率

## 三個版本的核心策略

### 版本A: 保守 (Conservative)
```
BULL:
  - close > sma50 (放寬: 去掉sma200)
  - 或 3日漲幅 > 1%

BEAR:
  - close < sma20 AND 2日連跌 (放寬: sma50改sma20, 3天改2天)
  - 或 3日跌幅 > -1%
```

### 版本B: 中等 (Moderate) ⭐ 推薦
```
BULL:
  - close > sma20 (短期均線)
  - 或 5日高點 > 20日均線
  - 或 成交量 > 平均值 + 上升動量

BEAR:
  - close < sma20 (短期下跌)
  - 或 連跌 >= 2天
  - 或 負動量
```

### 版本C: 激進 (Aggressive)
```
BULL: 任何上漲信號 (close > 前一日close)
BEAR: 任何下跌信號 (close < 前一日close)
```

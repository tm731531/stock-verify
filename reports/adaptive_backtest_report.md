## 執行摘要

本報告呈現一套**完全不涉及未來信息**的自適應交易系統。系統每天執行以下流程：

1. **環境檢測**: 基於過去數據判斷當前市場環境 (BULL/BEAR/RANGE/NEUTRAL)
2. **策略選擇**: 根據環境動態選擇最適合的策略
3. **信號執行**: 按信號進行買賣交易
4. **成本計算**: 計入換倉成本和佣金

## 1. 市場環境分析

### 1.1 環境分佈統計 (2019-2026年)

```
BULL     環境 (牛市上升)     :  613 天 (36.4%)
BEAR     環境 (空頭防守)     :  312 天 (18.5%)
RANGE    環境 (震盪區間)     :    50 天 ( 3.0%)
NEUTRAL  環境 (不確定)       :  757 天 (45.0%)
─────────────────────────────────────────
合計                          : 1732 天 (100%)
```

**解讀**:
- 超過 1/3 的時間處於**明確牛市** (BULL環境)
- 近 1/2 的時間是**不確定狀態** (NEUTRAL) — 系統保持空倉或極小倉位
- **真正的震盪機會較少** (RANGE 只佔 3%) — 高低突破策略觸發機會有限
- **空頭環境佔 1/5** (BEAR) — 均值回歸策略有充足的活躍機會

### 1.2 環境判斷邏輯

環境檢測基於以下 5 個信號 (僅使用過去數據):

| 信號 | 判斷標準 |
|------|---------|
| **價格位置** | 當前收盤價 vs SMA50/SMA200 |
| **趨勢強度** | 30 日高低點波動幅度 |
| **成交量強度** | 近 20 日平均成交量 vs 250 日平均 |
| **連跌天數** | 最近 5 天中負收益的天數 |
| **動量** | 20 日動量 (收益率變化) |

**決策規則**:
```
IF 收盤價 > SMA50 AND 收盤價 > SMA200 AND 趨勢強度 > 0.05 AND 動量 > 0.02
  → BULL 環境 (適合趨勢跟蹤)

ELSE IF 收盤價 < SMA50 AND 近期連跌 ≥ 3 天
  → BEAR 環境 (適合均值回歸)

ELSE IF 30日波動 < 2%
  → RANGE 環境 (適合突破策略)

ELSE
  → NEUTRAL 環境 (空倉)
```

## 2. 策略配置

### 2.1 環境 ↔ 策略 映射表

| 市場環境 | 選中策略 | 核心信號 | 適用場景 |
|---------|---------|---------|---------|
| **BULL** | SMA趨勢 | SMA20 ⊗ SMA50 (黃金叉/死亡叉) | 明確上升趨勢，追漲 |
| **BEAR** | 均值回歸 | 布林帶下軌 + RSI < 30 | 超賣反彈，防守型 |
| **RANGE** | 高低突破 | 20日高點/低點突破 | 區間震盪，捕捉邊界 |
| **NEUTRAL** | 空倉 | 無 | 不確定，等待確認 |

### 2.2 策略詳細說明

#### SMA趨勢策略 (適合 BULL)
```
買入信號:  SMA20 由下向上穿越 SMA50 (黃金叉)
賣出信號:  SMA20 由上向下穿越 SMA50 (死亡叉)

特性:
- 追隨明確的上升趨勢
- 減少假信號干擾
- 適合 BULL 環境的強勢行情
```

#### 均值回歸策略 (適合 BEAR)
```
買入信號:  Close < BB_Down AND RSI < 30 (過度超賣)
賣出信號:  Close > BB_Up OR RSI > 70 (過度超買)

特性:
- 在空頭環境中尋找反彈機會
- 布林帶 + RSI 雙重確認
- 降低虛假反彈的損失
```

#### 高低突破策略 (適合 RANGE)
```
買入信號:  Close 突破 20日最高點
賣出信號:  Close 跌破 20日最低點

特性:
- 捕捉區間突破
- 簡單明確的執行規則
- 適合震盪市場
```

## 6. 系統特性評估

### 6.1 優勢 ✓

1. **完全無未來信息漏洞**
   - 每天的環境判斷只基於過去 50+ 天的歷史數據
   - 不存在「事後諸葛亮」的回測陷阱

2. **環境自適應**
   - 在不同市場狀態下切換策略
   - BULL 環境用趨勢跟蹤，BEAR 環境用防守

3. **風險控制**
   - 45% 的時間保持空倉 (NEUTRAL)
   - 避免不確定環境下的無謂交易

4. **長期趨勢捕捉**
   - 成功捕捉 2020-2021 年的長期牛市
   - 單筆收益達 34.40%

### 6.2 劣勢 ✗

1. **年化收益偏低 (4.75%)**
   - 低於台指數年均 7-8% 的表現
   - 空倉時間過長，錯失了很多收益機會

2. **最大回撤巨大 (-53.44%)**
   - 2020 年 COVID 期間承受 53% 的虧損
   - 並非由交易信號導致，而是持倉期間的單邊下跌

3. **交易頻率過低**
   - 8 次交易在 7 年內太稀疏
   - 大部分時間都在等待

4. **Sharpe 比率較低 (0.31)**
   - 風險調整後的收益 performance 一般
   - 說明系統波動過大

### 6.3 改進方向 (建議)

| 問題 | 原因 | 建議改進 |
|------|------|---------|
| 年化收益低 | 空倉比例高 | 降低 NEUTRAL 環境的判斷門檻 |
| 回撤大 | 無止損機制 | 加入固定止損 (如 -10% 自動平倉) |
| 交易少 | 環境檢測過嚴格 | 放鬆環境判斷參數 |
| Sharpe 低 | 持倉周期長 | 加入期望值篩選，非所有信號都交易 |

## 8. 結論

### 8.1 系統評估

自適應多策略系統在**理論上**是合理的：
- ✓ 環境檢測邏輯清晰
- ✓ 策略選擇匹配環境
- ✓ 無未來信息漏洞
- ✓ 完整的交易記錄

但在**實踐績效上**顯示了侷限：
- ✗ 年化 4.75% 低於大盤
- ✗ 53% 最大回撤太深
- ✗ 交易機會稀少

### 8.2 關鍵洞見

1. **市場環境分佈不均**
   - BULL 環境 36.4%，BEAR 僅 18.5%
   - NEUTRAL 環境過多 (45%) — 系統頻繁空倉

2. **策略適配度有差異**
   - BULL 環境的 SMA 策略: 34.40% (非常有效)
   - BEAR 環境的均值回歸: 8.56% 平均 (尚可)
   - RANGE 環境的突破策略: 無機會 (3% 佔比太小)

3. **單筆大行情的重要性**
   - 2020-2021 年牛市的單筆 34.40% 占了總收益的 103%
   - 其他 7 筆交易累計 -0.76%
   - **說明**: 大行情的捕捉能力是決定成敗的關鍵

4. **風險管理不足**
   - 系統缺乏止損機制
   - 長期持倉期間承受大幅虧損 (COVID 期間 -53%)

### 8.3 建議使用方式

| 場景 | 推薦度 | 說明 |
|------|-------|------|
| 保本為主 | ⭐⭐⭐ | 適合風險厭惡者，可減少交易次數 |
| 穩健增長 | ⭐⭐ | 年化 4.75% 不夠理想 |
| 高收益追求 | ⭐ | 不推薦，回撤太大且收益低於大盤 |
| 學術研究 | ⭐⭐⭐⭐⭐ | 完整的無未來信息系統設計，適合教學 |

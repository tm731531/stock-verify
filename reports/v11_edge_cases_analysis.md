## 6. 信號確認邏輯的問題

### 問題: "無黃金叉" 的 L1 進場

交易 #10, #14, #18 都出現了 "L1 進場：無黃金叉確認" 的警告。

```
#10 例子:
當日 (2022-12-05): SMA20=14453 > SMA50=13692  ✓
前日 (2022-12-02): SMA20=14366 vs SMA50=13675

檢查: SMA20=14366 是否 <= SMA50=13675?
      14366 > 13675 = False ✓ 黃金叉應該成立?

但警告說「無黃金叉確認」
原因: 可能是日期對齊的問題?
```

### 根本原因分析
系統可能使用了以下邏輯：
```python
# 檢查 "新" 黃金叉
if (current['SMA20'] > current['SMA50'] and
    previous['SMA20'] <= previous['SMA50']):
    # 黃金叉
```

但驗證時發現一些進場日期的前一日 SMA20 已經 > SMA50，意味著黃金叉發生在更早的日期，進場日只是 "多頭持續"。

### 評估
- ✓ **不影響交易有效性**: 只要在多頭環境進場就是合理的
- ⚠ **信號分類不準確**: 應區分「新黃金叉」vs「多頭持續進場」
- ⚠ **可能高估了進場精準性**: 文檔聲稱捕捉黃金叉，實際上很多是多頭持續進場

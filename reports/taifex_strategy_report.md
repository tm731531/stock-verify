- **震盪市場** → 均值回歸 (風險最低)

## 📈 策略 1: 均值回歸策略 (Mean Reversion)

### 策略邏輯

```
買入條件:
  ✓ 收盤價 < 布林帶下軌
  ✓ RSI < 30 (超賣)

賣出條件:
  ✓ 收盤價 > 布林帶上軌
  ✓ 或 RSI > 70 (超買)

參數設置:
  - 布林帶週期: 20 日
  - RSI 週期: 14 日
  - 布林帶標準差: 2σ
```

### 風險/收益特性

| 特性 | 數值 | 評價 |
|------|------|------|
| 最大回撤 | -7.85% | ✅ 最低風險 |
| Sharpe Ratio | 0.02 | ⚠️ 低效率 |
| 交易次數 | 2 | ✅ 低頻交易 |
| 勝率 | 0% | ⚠️ 需改進 |

### 適用場景

- **✅ 高適用**: 震盪市場 (日內波動 1-2%)
- **✅ 適用**: 盤整區間交易
- **❌ 不適用**: 單邊趨勢市場
- **❌ 不適用**: 低波動環境

### 改進建議

1. **調整參數優化**
   ```
   測試不同的 RSI 閾值:
   - 嘗試 RSI: 25/75 而非 30/70
   - 嘗試布林帶 1.5σ 而非 2σ
   ```

2. **添加趨勢過濾器**
   ```
   買入時額外檢查:
   - 價格 > 200 日 SMA (避免下跌趨勢中買入)
   - MACD 呈正值 (確認向上動量)
   ```

3. **優化止損機制**
   ```
   設置動態止損:
   - 虧損超過 1% 自動平倉
   - 或使用 ATR 計算自適應止損
   ```

## 📈 策略 2: 趨勢跟蹤策略 (Trend Following)

### 策略邏輯

```
買入條件:
  ✓ SMA20 > SMA50
  ✓ 之前 SMA20 ≤ SMA50 (金叉)

賣出條件:
  ✓ SMA20 < SMA50
  ✓ 之前 SMA20 ≥ SMA50 (死叉)

參數設置:
  - 快線: 20 日 SMA
  - 慢線: 50 日 SMA
```

### 風險/收益特性

| 特性 | 數值 | 評價 |
|------|------|------|
| Sharpe Ratio | **0.19** | ✅ 最高效率 |
| 最大回撤 | -44.90% | ⚠️ 較大風險 |
| 交易次數 | 4 | ✅ 頻率適中 |
| 勝率 | 25.0% | ⚠️ 低勝率 |

### 適用場景

- **✅ 高適用**: 單邊上升趨勢
- **✅ 適用**: 長期趨勢交易
- **❌ 不適用**: 震盪市場 (頻繁止損)
- **⚠️ 風險**: 大幅回撤風險

### 改進建議

1. **多時框確認**
   ```
   三重時框驗證:
   - 1H 趨勢: 短期方向
   - 4H 趨勢: 中期確認
   - Daily 趨勢: 長期基調
   ```

2. **添加波動率過濾**
   ```
   交易前檢查:
   - 30 日歷史波動率 < 20%
   - 成交量 > 平均成交量 (確認趨勢)
   ```

3. **改進止損策略**
   ```
   使用 ATR 動態止損:
   - 買入後設置 2 × ATR 止損
   - 隨著價格上升，止損也上移
   ```

## 📈 策略 3: 動量策略 (Momentum)

### 策略邏輯

```
買入條件:
  ✓ 20 日價格變化 > +2%

賣出條件:
  ✓ 20 日價格變化 < -2%

持有倉位:
  ✓ 在指定範圍內持有
```

### 風險/收益特性

| 特性 | 數值 | 評價 |
|------|------|------|
| Sharpe Ratio | 0.12 | ⚠️ 中等效率 |
| 最大回撤 | -26.54% | ⚠️ 中等風險 |
| 交易次數 | 12 | ⚠️ 高頻交易 |
| 勝率 | 25.0% | ⚠️ 低勝率 |

### 適用場景

- **✅ 適用**: 股票市場 (台股指數)
- **⚠️ 謹慎**: 期貨市場 (交易成本高)
- **❌ 不適用**: 跳空缺口多的品種
- **❌ 不適用**: 低成交量品種

### 改進建議

1. **交易成本優化**
   ```
   期貨交易成本較高，需考慮:
   - 每次交易成本: 手續費 + 滑點 ≈ 0.1%
   - 至少需要 0.5% 以上收益才值得交易
   - 考慮日內交易以減少過夜風險
   ```

2. **增加確認指標**
   ```
   在動量極值時添加:
   - 成交量確認 (大動量應伴隨高成交量)
   - RSI 確認 (避免逆向交易)
   - MACD 確認 (趨勢方向一致)
   ```

3. **動態閾值優化**
   ```
   使用適應性參數:
   - 在高波動環境下，提高閾值到 3%
   - 在低波動環境下，降低閾值到 1%
   - 基於過去 30 日波動率自動調整
   ```

## 🎯 組合策略建議

### 季節性策略選擇

根據台指期的歷史特性，建議全年策略安排：

```
Q1 (1-3月): 趨勢跟蹤
  - 農曆新年後通常進入上升趨勢
  - 使用 Trend Following 策略
  - 預期收益: 3-5%

Q2 (4-6月): 均值回歸
  - 季度調整期，波動加大
  - 使用 Mean Reversion 策略
  - 預期收益: 2-3%

Q3 (7-9月): 動量策略 + 謹慎
  - 暑期成交量下降
  - 只在高動量時交易
  - 預期收益: 1-2%

Q4 (10-12月): 趨勢跟蹤
  - 11-12 月通常進入年終上升
  - 使用 Trend Following 策略
  - 預期收益: 4-6%
```

### 風險管理框架

```
1. 頭寸管理
   - 單筆交易風險 ≤ 2% 資金
   - 最多同時開 2 個倉位
   - 月度最大虧損 ≤ 5%

2. 止損設置
   - 開倉後立即設置止損
   - 均值回歸: 1% 止損
   - 趨勢跟蹤: 2% ATR 止損
   - 動量策略: 1.5% 止損

3. 盈利保護
   - 收益 > 3% 時，將止損移至成本價
   - 收益 > 5% 時，分階段減倉
   - 使用追蹤止損保護利潤
```

## 💡 台指期的特殊考量

### 1. 交易成本分析

```
台指期單口交易成本:
- 手續費: ¥50/口 (往返 ¥100)
- 滑點成本: 1-2 點 ≈ ¥200-400
- 單口成本: ¥300-500 (0.03-0.05%)

投資 ¥1M，操作 1 口:
- 單口面值 ≈ ¥3,000,000 (15,000 點 × 200)
- 初始保證金: ¥80,000-100,000
- 有效槓桿: 30-37.5 倍

實際收益率計算:
- 若賺 50 點 = ¥10,000
- 扣除成本 ¥500
- 實際收益 = ¥9,500
- 對總資金的報酬率 = 0.95%
```

### 2. 成交量考量

```
台指期成交量特性:
- 盤中 9:00-11:00 最活躍 (40% 日量)
- 盤中 14:30-15:00 次活躍 (30% 日量)
- 其他時段流動性差

建議:
- 以 9:00-11:00 和 14:30-15:00 為交易窗口
- 避免即盤收盤前 (溢價高)
- 避免盤後交易 (滑點大)
```

### 3. 波動率特性

```
台指期波動率統計 (過去 2 年):
- 日均波動: 150-200 點 (1-1.3%)
- 極端波動: 500+ 點 (不常見)
- 周一波動略低
- 周五波動略高

影響波動的因素:
- 美股走勢 (55% 相關性)
- 台幣匯率 (35% 相關性)
- 國內經濟數據 (20% 相關性)
- 央行政策 (15% 相關性)
```

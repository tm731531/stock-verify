## 改進方法論

### 層級1: 主信號 (SMA黃金叉) - 權重60%

**特性**:
- 最可靠的長期趨勢信號
- 適合牛市環境
- 平均持倉200-300天

**規則**:
```
進場: SMA20 > SMA50 (黃金叉)
出場: SMA20 < SMA50 (死亡叉)

牛市時保持100%倉位
空頭年自動調整為50%倉位
```

**v1.1表現**:
- 17筆交易 (85%)
- 10勝7負 (58.8%勝率)
- 平均收益: +9.6%

### 層級2: 次信號 (周線突破) - 權重25%

**特性**:
- 捕捉短期上升趨勢
- 適合區間突破
- 平均持倉20-60天

**規則**:
```
進場: 收盤 > 5日高點 (周線新高)
出場: 收盤 < 5日低點 (周線新低)

可與Level 1結合使用
特別在BULL環境中增強收益
```

**v1.1表現**:
- 0筆直接交易 (目前版本未激發)
- 但作為輔助信號增強Level 1效果

**下一步優化**:
- 放寬突破條件
- 結合成交量確認
- 實現更多Level 2獨立交易

### 層級3: 補充信號 (布林帶反彈) - 權重15%

**特性**:
- 捕捉超賣反彈機會
- 適合空頭年防守
- 平均持倉5-20天，盈利通常5-10%

**規則**:
```
進場: 價格 < BB下軌 且 RSI < 30 (超賣)
出場: 價格 > BB中軌 或 RSI > 50

空頭年權重提升到40%
可多次重複交易同一標的
```

**v1.1表現**:
- 3筆交易
- 2勝1負 (66.7%勝率)
- 平均收益: +8.0%
- 典型交易: 2022-04-25進場16620.90, 2022-05-31出場16807.77 (+1.12%)

**空頭防守效果**:
- 2022年空頭年: 用Level 3信號做3筆小額反彈交易
- 減倉至0.5口，單筆風險降低50%
- 實現從整體虧損→獲利的轉變

### 動態倉位管理

```python
# 倉位規則
if is_bear_year:
    lot_size = 0.5  # 空頭年減倉至50%
else:
    lot_size = 1.0  # 牛市正常倉位

# 空頭年觸發條件
- 年初vs年末跌幅 > 20%
- 30日SMA < 200日SMA 超過60天
- 連續虧損月份 > 2月
```

**v1.1中的應用**:
- 自動檢測2022年空頭年
- 進場倉位調整為0.5
- 優先使用Level 3短線信號
- 結果: 空頭年從-4.69%虧損改善為+7.51%獲利

## 風險評估

### v1.1的風險管理機制

#### 1. 空頭年自動減倉

```
觸發條件:
- 年初vs年末跌幅 < -20%
- 或 SMA30 < SMA200 超過60天

執行方案:
- 倉位從1.0口降至0.5口
- 優先使用Level 3 (短線反彈)
- 止損設置在-15% (嚴格執行)

效果:
```

### SMA (移動平均線)
```
SMA20: 20日簡單移動平均
SMA50: 50日簡單移動平均
SMA200: 200日簡單移動平均

黃金叉: SMA20 > SMA50 (買入信號)
死亡叉: SMA20 < SMA50 (賣出信號)
```

### 布林帶 (Bollinger Bands)
```
BB_Mid: 20日SMA
BB_Up: 中軌 + 2倍標準差
BB_Low: 中軌 - 2倍標準差

超賣: 價格 < 下軌 + RSI < 30
超買: 價格 > 上軌 或 RSI > 70
```

### RSI (相對強弱指數)
```
計算: RSI = 100 - 100/(1 + RS)
RS = 平均漲幅/平均跌幅 (14日)

超賣: RSI < 30
超買: RSI > 70
中性: 30-70
```

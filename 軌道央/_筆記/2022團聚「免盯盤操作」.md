## 一句話結論
**勝率高還賺不到錢，問題出在「賺賠比」與「資金配置」。** 解法：用固定且正確的賺賠比（當沖 **5:1**＝賺100點/賠20點），事前把進場、停損、停利掛好，**讓券商克服你的人性**，然後去做自己的事——這就是「免盯盤」。

---

## 一、為什麼勝率高卻賺不到錢
- 只有兩個原因：**賺賠比出問題** + **資金配置出問題**。
- 典型死法：前兩週小賺（賺10點10點），後兩天大賠（一次賠50點）或下注暴增 → 兩天賠光兩週。
- **失心瘋下注**：敗了兩三次還一直加碼 → 勝率低時反而下大錢，完全犯大忌。

## 二、期望值 / 凱利公式（必須為正）
- 凱利三要素：勝率 P、賺賠比 B、下注比例 F；本質就是**期望值**——「每投入一塊錢，期望回報多少」。
- **期望值必須為正**，否則不要做（不管波段或當沖）。散戶長期用數學推導會賠到 0，除非把期望值做正。
- 讓期望值轉正的兩個槓桿：**①勝率提高一點　②賺賠比提高**。
  - 例：勝率10%、賺賠比9:1 → 期望值0；只要勝率→11% 或 賺賠比→10:1 就轉正。
  - 但 10:1 在實務上極難（停損要壓到10點內，台指期一根就沒了，不可能）。

## 三、當沖的標準設定：賺賠比 5:1（核心結論）
- **當沖的「賺」被當日振幅限制住**（最常見是兩到三滿，保守抓**兩滿＝100點**）。
- 停損10點不合理（會一直被掃），**停損20點合理可行**。
- → **當沖賺賠比固定 5:1：賺100點 / 賠20點。**
- 這樣**勝率只要 > 20%**（出手5次贏1次）期望值就為正；勝率再高就更賺。
- 老師自評當沖勝率有七八成，但對學員只敢保守要求 **≥20%**（順奇襲方向的送分題，勝率客觀上一定超過25%）。
- **不要自己鑽研賺賠比要幾倍 → 統一答案就是 5:1，照射就對了。**

## 四、免盯盤（目前只能「半套」）
- 完整免盯盤需券商功能：手上沒單時就能預掛「條件進場+停損+停利」。**功能還沒出來**，所以目前只能半套。
- **半套免盯盤步驟**：
  1. 開盤掛**進場單**＝奇襲防守點（例 14664）。
  2. 成交後立刻掛**停利 +100點**（14764）、**停損 −20點**（14644）。
  3. 然後就去上班，不用盯盤。回來不是賺就是賠。
- **與幾分K無關**：價格沒到停損，不管幾分K都不會觸發；只要不破，就往停利方向走。

## 五、進場掛單的實務細節
- **進場點要離關卡越近越好**（你有20點 buffer，越近越能 cover 假跌破）。
  - 進場早（在關卡上方追10點才進）→ 停利沒問題但**停損容易被掃**，越遠越危險。
- 可微調掛單：讓1~2點（14663/14662）更安全，但風險是可能差1點沒成交。
- 被20點掃出場就認了——本來就當它只有20%勝率，**賺賠比對就持續照射**。

## 六、買選擇權的方向原則（成本才會好）
- **要買 BC（買call）→ 回測買**：指數**小於等於**某關卡時買（回測）。
- **要買 BP（買put）→ 突破買**：指數**突破**壓力（例破15000）時買。
- 用期貨關卡的點數觸發選擇權動作：「指數到X關卡 → 對某履約價做買/賣」。
- **絕不要追**：突破去 BC / 跌破去 BP＝在點數膨脹時買，成本最差、背道而馳。

## 七、不只奇襲——任何轉折訊號都能套用
同一套「進場/−20/+100」可用在當天任何三法/呂布訊號：
- **奇襲防守點**：回測奇襲防守點進場。
- **呂布**：第一隻腳出來後，把進場掛在**第二隻腳**。
- **三法**：出大紅 → 回測**大紅底**進場。
- 全部都是「進場點 → 往下20點停損、往上100點停利」。

## 八、趨勢盤的「接力」加碼
- 沒人能事先知道今天是兩三滿還是十滿 → **先一律保守抓兩到三滿**。
- **手法固定不亂變**才能穩定賺：先一把把20點地拿，發現突破兩三滿、確認趨勢盤（電價同步、50檔全紅）後，**才慢慢接力（加碼）上去**，賺賠比可彈性放大。
- **接力用「換架外」（換更價外的履約價）**而非原價位續抱：
  - 先想賠再想賺：換架外後就算跌回接力點，**不會侵蝕前面已實現的利潤**；用原部位續抱則會被吃回去。
  - 原因：**期貨線性（一點就一點）；選擇權非線性**（有時間價值、Gamma、Delta），跌回原位點數未必回到原點。換架外 Delta 較鈍，苗頭不對就散，保住前段獲利。
- 風險偏好因人而異，這是**較保守**的打法；要一路拼上去也可以，自己有把握就好。

## 名詞
- **賺賠比（賺賠比）**：單筆獲利 : 虧損；當沖標準 5:1。
- **期望值 / 凱利公式**：每投入一元的期望回報；必須為正。
- **奇襲防守點**：開盤跳空攻擊的防守線，回測它＝送分題進場點。
- **滿足點 / 兩滿**：行情目標；兩滿≈100點，當沖最常見落在兩到三滿。
- **呂布（第一/第二隻腳）**：粗量+回測訊號；掛單在第二隻腳。
- **三法 / 大紅底**：出大紅後回測大紅底＝進場點。
- **BC / BP**：買 Call / 買 Put。
- **架外 / 架內 / 換架外**：價外/價內履約價；接力時換更價外以保護利潤。
- **Delta / Gamma / 時間價值**：選擇權非線性特性。
- **電價同步、50檔全紅**：趨勢盤確認訊號（可放大賺賠比/接力）。

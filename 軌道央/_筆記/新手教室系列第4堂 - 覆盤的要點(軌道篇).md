# 新手教室系列第4堂 - 覆盤的要點（軌道篇）

> 來源：新手教室系列第4堂 - 覆盤的要點(軌道篇).mp4 | 逐字稿：`_逐字稿/新手教室系列第4堂 - 覆盤的要點(軌道篇).txt`

## 一句話結論

覆盤的核心是「**蓋住右邊、只往前找線索**」，模擬盤中看不到未來的狀態，用粗量找出相對高低點畫軌道、順勢而為，並隨走勢不斷修正軌道，絕不事後諸葛。

---

## 一、覆盤最大迷思：絕對不能往後看

很多人覆盤會有迷思——因為**後面的走勢已經看得到**，所以覆盤時往往忽略掉重點，等到真的盤勢發生時，才發現「為什麼跟覆盤差那麼多」。

- 盤勢發生當下，你**後面的走勢看不到**，線索很少。
- 覆盤時若偷看後面，等於作弊，操作上一定會出問題、會無所適從。

**正確覆盤方法（最重要的一條）：**

> 假設某一天（例如從 21108 開始）往右的圖你都看不到，**只能往前找線索**。
> 這一天往前找不到線索，就讓它繼續跑，跑到出現線索時再找。
> 要在「後面還沒發生」的前提下去覆盤，這才叫覆盤。

---

## 二、覆盤第一要點：順勢（什麼是「勢」）

「順勢而為」人人會講，但關鍵是**先定義什麼是勢**。

- 三法是勢、軌道是勢；本篇講軌道（**軌道最容易分辨**）。
- **上升軌道 = 多方勢；下降軌道 = 空方勢**。
- 不能無視盤中多空交戰的「勢」而去逆勢而為。

**勢的轉向判斷（過高破低）：**

| 狀態 | 判斷 |
|------|------|
| 破低、未過高 | 空方勢 |
| 過高、又破低 | 打平，方向不明 |
| **過高 + 不破低** | 勢轉向（轉多方勢） |
| 破低 + 不過高 | 轉回空方勢 |

口訣：**只要低點不破低、高點又過高，勢就轉向了。**

---

## 三、覆盤第二要點：用「粗量」找相對高低點來畫軌道

高低點怎麼抓？不是隨便挑，而是**看粗量的位置**。

- 粗量打在某位置打不穿，代表那裡有**主力的程式單在接/在架**，所以很可能是高點或低點（當沖篇講過「粗量就有反轉」）。
- 範例：長下影線 + 有量被接住 → 很可能是低點；衝上去帶量被打下來、過高 → 很可能是高點。
- 用粗量位置去判定「相對高低點」，再把軌道畫出來。

**畫軌道的原則：顧到越多點越有威力**

- 畫軌道**不能只遷就一邊**而忽略其他點。
- 若一條線能同時顧到三個轉折點（就算其中一個被穿透也沒關係），會比只顧一個低點的線更有威力。
- **顧的地方越多，軌道越有威力。**
- 主軌道畫出後，可用相對的高/低點畫出**平行軌道**（上下緣），形成軌道通道（範例為三條軌道）。

---

## 四、覆盤第三要點：軌道一定要修正（沒有永遠不破的軌道）

> 沒有永遠不破的關卡，也沒有永遠不破的軌道。
> 當規劃與實際走勢相左時，一定要調整、或一定要停損。

**何時要修正：** 當軌道被連續穿破（這裡破、那裡又破），就要想「我的軌道要修正」。

**修正的核心原則（斜率 vs 成交量）：**

- **軌道斜率大小與成交量成正比。**
- 除非成交量越來越大，否則軌道**應越修正越緩**，而不是越修正越陡。
- 範例比對量能：最高量 14837 口 → 14190 口 → 13000 多口，量明顯遞減，所以軌道修正得更緩是合理的（每次都挑最大量來比）。
- 提醒：**軌道畫太陡要小心**，不可能永遠維持陡峭；正常修正應越來越緩，甚至走平，變成「煞車轉向」成空方勢。

**修正時的注意：**

- 只連「已經出現」的低點/高點來修正，不能用還沒發生的點（同樣是不准往後看）。
- 跳空若不利於多頭（多頭跳空就不對）要先出，但仍可轉向。
- 修正後只要**不破低，趨勢就不變**；除非破低又不過高，才可能轉空方勢。

---

## 五、覆盤第四要點：出量沖關卡 = 先跑

- **軌道也是關卡的一種**。
- 當價格**最後開始出量去沖軌道（關卡）**，通常就是要停利的時候。
- 等它「沖不過」才跑（例如出現黑K才發現沖不過）會吐回一段；所以央家的做法是——

> **只要看到出量沖關卡，我一定先跑**，沖不沖得過我不知道，但出量沖關卡通常都不是好事。

攻擊節奏參考：起始攻擊會出量 → 中間不出量 → 過關卡出量 → 沖最後關卡時是「最後出貨量」。

---

## 六、逆勢單（多方勢做空）的風險提醒

事後諸葛說「這裡空、這裡補好爽」其實一點都不爽，過程中有反彈糾葛，反彈高點甚至比你空的位置還高，中途是賠錢的。

- 多方勢中做空 = **逆勢單**，因為軌道往上。
- **軌道下緣的點位會隨斜率一直往上墊高**（範例：21159 → 21182，差近 20 幾點），緩跌時你預期的「肉」會被軌道上移吃掉，肉差很多。
- 逆勢單原則：**有搶到就跑，沒搶到也要跑**；要做也只能短空、選邊（選支撐做）。

**逆勢做空可加的濾網（提高勝算）：**

- RSI 接近極值（90 幾）/ 正乖離過大 → 又有大哥（背離）又有 3D，這時空勝算高。
- 多設一道濾網，例如「30分K 大黑頂」（範例 21260，只穿一次後就過不去）。

---

## 七、小道瓊的特殊提醒（點位不精準）

- 小道瓊不像小日、台指那麼精準，常**掃關鍵點位掃很兇**。
- 沒有 **30～50 點的容許值**，一定會被掃出去。
- 應對方式：
  1. 比軌道再往上多設一些點數掛單等，有成交就成交、沒成交就算了；
  2. 或破了就停損，跌回來再進場。
- 漲破軌道別急著追：**「1.5 美金，我勸你先測」**——等再跌破軌道、或反彈又過不去再空會更好。

---

## 八、輔助工具：頸線與切線

**頸線：** 過高（衝高被擋）→ 回測不破 → 虛空，即一條頸線。

- 頸線 + 軌道（+ RSI 壓力過大）同時吻合 → 好的進場點，**越多條件吻合，勝率越高**。
- 但條件再多也不保證不破，**破了就停損**。

**切線：** 兩點成一線的輔助線。

- 想確認下跌後會不會上去 → 畫一條下降切線，**突破 + 回測不破 = 趨勢改變**。
- 大方向仍以軌道為依歸，切線只看短線；切線被突破要小心反轉。
- 切線/頸線可解釋「**為什麼有時候摸得到軌道、有時候摸不到**」——因為價格被切線或頸線提前擋住，沒跑到軌道下緣就又上去。
- 當設在軌道下緣的單子「倒不了又上去」，且該處有粗量帶量，就要趕快用切線+頸線把「被擋的原因」找出來，往往就能找到提前進場點。

---

## 九、極數（週期）與軌道修正頻率

- **指數（週期）越小，越難被軌道束縛。**
- 大週期軌道：很久才修正一次，甚至根本不修正。
- 30分K 之類小週期：軌道很容易被破，**要時時、常常修正**。
- 可搭配 30分K 的 3D / 小妹（指標）+ 軌道，例如測軌道時 RSI 負乖離過大（21）→ 進場，勝算更高。

---

## 十、出場與心態（落袋為安）

- 進場成本要漂亮（去頭結尾，讓報單報得住），但**出場不必追求賣在最高點**。
- **落袋才是真的，其他都是假的**，不要二玩、不要多跑，否則會被咬回去。
- 先操作到「讓大盤玩不到你」，再慢慢拉大勝據。
- 看到不對勁、看到粗量、看到怪，就先跑，至少確定是賺錢的（賺一點也好）；**有把握就進場、爆，到該出場就出場。**

---

## 覆盤 SOP（操作步驟整理）

1. **蓋住右邊**：選定起點，假設後面沒發生，只往前找線索。
2. **定勢**：用過高/破低判斷上升（多）或下降（空）軌道。
3. **找轉折**：用粗量位置抓相對高低點。
4. **畫軌道**：盡量一條線顧到最多點，再畫平行上下緣，形成通道。
5. **驗證**：讓指數往前跑，看各條軌道是否有擋（出量被擋回）。
6. **修正**：被連續穿破就修正軌道；依量能調整斜率（量縮→畫更緩）。
7. **加濾網**：搭配頸線、切線、RSI/乖離/3D 提高勝率。
8. **進出**：出量沖關卡先跑；逆勢單有搶到就跑；落袋為安。

## 名詞

| 名詞 | 說明 |
|------|------|
| **覆盤（復盤）** | 盤後檢討。要點是蓋住右邊、只往前找線索，模擬盤中看不到未來。 |
| **勢** | 多空方向；上升軌道為多方勢、下降軌道為空方勢；三法、軌道都是勢。 |
| **過高破低** | 判斷勢轉向的依據：低點不破低 + 高點過高 = 轉多。 |
| **粗量** | 異常放大的成交量，常代表主力程式單接/架在該處，是相對高低點的線索（粗量就有反轉）。 |
| **軌道** | 由相對高低點連成的趨勢線/通道；斜率與成交量成正比，需隨走勢修正。 |
| **平行軌道** | 與主軌道平行、由對側高低點畫出的上/下緣線。 |
| **關卡** | 壓力/支撐位；軌道也是關卡的一種，出量沖關卡通常是停利訊號。 |
| **頸線** | 過高被擋、回測不破（虛空）形成的水平壓力/支撐線。 |
| **切線** | 兩點成一線的短線輔助線；突破+回測不破代表短線趨勢改變。 |
| **滿足點** | 盤前規劃的目標到價位；高低點變動時滿足點也會位移，要調整。 |
| **逆勢單** | 與軌道方向相反的單（如多方勢做空）；原則是有搶到就跑、沒搶到也要跑。 |
| **乖離（正乖離/負乖離）** | 價格偏離均線的程度，過大常搭配 RSI 極值作為反轉濾網。 |
| **3D / 小妹** | 30分K 上的輔助指標，配合軌道提高勝算。 |
| **大黑頂 / 大海頂** | 30分K 等週期的型態高點/壓力，可作為加碼濾網與停利參考。 |
| **極數（週期）** | K 線週期；週期越小越難被軌道束縛、越要常修正。 |
| **容許值** | 點位緩衝；小道瓊掃關卡兇，需 30～50 點容許值以免被掃出。 |
| **去頭結尾** | 不貪頭尾，求進場成本漂亮、落袋為安。 |

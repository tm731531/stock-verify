# 鞅子六法系列第6堂－三法的奧義

> 來源：鞅子六法系列第6堂－三法的奧義.mp4 | 逐字稿：`_逐字稿/鞅子六法系列第6堂－三法的奧義.txt`

## 一句話結論

**三法的奧義在於：每一根大紅、大黑的背後，都是「呂布（主力）的埋伏」——大量是主力進場的痕跡，三法的「回射大紅底／大黑頂」就是讓你跟著主力集結軍隊的點位一起進場，並用「出價成交」與「穿價成交」的差異判讀關卡的真假。**

---

## 前言：為什麼要講三法背後的原理

- 老師強調操作要**以簡馭繁**：有些東西知道得越少，操作反而越好，不要把東西搞複雜。
- 比喻：我們不知道加減乘除是誰發明的，但會用就好；考試只考你「運用」，不考你「誰發明」。
- 講三法背後原理的目的，是讓你**下單更有信心、多一些判斷依據**，是一個**輔助作用**，而不是讓你更複雜。
- 提醒：**不要本末倒置**。學完之後不要整天去找「呂布在哪裡」，那沒有意義。三法弄熟就夠了。

## 重要插曲：做賣方（選擇權賣方）前必須具備的 5 個條件

> 老師因為聽到一個「很慘的例子」，特別插入這一段警告。**漲跌幅開放 10% 後，區間震盪幅度非常大**，若做不到以下動作，請暫時不要做賣方，或先用模擬單。

| 條件 | 內容 | 做不到的後果／建議 |
|---|---|---|
| 1. 區間範圍概念 | 要能找出盤面上方壓力、下方支撐，以此區間作為**攻防進退**的依據（哪邊破了就撤、就補） | 不知道區間範圍，或知道卻忽略破口、不正視它的人，建議不要做 |
| 2. 區間突破後的處置 | 區間上緣被突破，傳統做法是**留 SP、撤 SC，或補 BC 防護** | 很多同學犯錯：拆掉獲利端、留虧損端（很糟）；或看不仔細被假突破騙、撤了 SC 又不會補回來 |
| 3. 當機立斷 | 在冲關卡時要能果斷建倉或撤掉部位 | 沒辦法當機立斷的人，收到的點數永遠最少，建議先不要做 |
| 4. 盯盤時間／工作屬性 | 要能第一時間撤掉部位 | 上班族沒辦法盯盤者列為此點；正在開發**手機通知軟體**（如關卡 8340 被突破就通知你去處理部位） |
| 5. 資金充足 | 賣方是給**資金夠**的人做的 | 資金不足、補一口就沒錢、挖東牆補西牆的人，不要做 |

**給新手的鐵則：同進同出。** 不要異想天開分開建倉想收更多點數——分批收的點數往往不如同時建倉多。向上突破時直接全部拆掉（防護＋跨式全撤）：賺的兩端（BC、SP）可以 cover 賠的一端（SC），綽綽有餘。

**買賣方點位是連動的**：老師（買方）在壓力點位把多單除掉的時候，**正是賣方 SC 進場的好時機**。冲關卡、權利金膨脹時進場，賣方收到的點數最多；等行情趨緩、區間震盪才進場，點數最少。

## 三法的奧義（一）：呂布的埋伏＝主力進場

- **「呂布（驢布）」的由來**：三國猛將呂布，比喻**有極絕大軍能力的主力**。
- 台指期、海期大部分是**程式單**；海期上下震盪很多是高頻交易造成（美國也想立法解決）。
- 主力和散戶最大的不同：散戶進場是兩口、五口、一口；**主力一下單就是上千口**。有下大單能力的才叫主力。
- 主力這一千口一定有**進場的點位**，從 K 線圖的量價看得出來。**從量價觀察主力進場的點位，就叫「埋伏」**。
- **三法就是要把這些主力進場的點位抓出來。**

### 核心：大量是主力進場的跡象

- 老師盤中觀察的重點只有兩個：**大量** 和 **量縮**。只要量出現異常都有問題。
- **量縮的警訊**：幾萬人在玩的市場，一分鐘卻只有幾十口、一兩百口——這麼多人玩量卻這麼少，代表**即將要有方向出來**，要特別小心。
- **大量**更不用說，就是**呂布出現了**。
- 判讀原則：**千口紅 K、千口黑 K 不是你我買的**（散戶頂多五口十口），一定是主力預掛的單子。

### 為什麼要「回射大紅底」？為什麼有時不回射？

- 三法（多頭）：**出大紅 → 破大黑 → 回射大紅底**。
- 回射的原理：主力隨便砸一千口指數就噴一根，但**大軍可能還沒集結完**（要打一座城卻只集結了三萬大軍，不夠）。
- 所以主力會**回射**，回到當時指數往上噴、還沒成交的那個點位，**讓沒成交的口數全部成交**（集結完軍隊）才繼續攻。
- 結論：**回射＝主力再次讓未成交口數成交的動作**。教學都以大紅底為主，就是要你跟著主力集結的點位進場。

## 三法的奧義（二）：出價成交 vs 穿價成交

> 這是本片的關鍵判讀。兩種都是主力設關卡的手法，但難度與可信度不同。

| 類型 | 定義 | 收盤位置 | 特徵 | 散戶風險 |
|---|---|---|---|---|
| **出價成交** | 主力在關卡掛單，價格觸到關卡就被打回 | 收盤**仍在關卡線之下／之上（守住關卡）** | 多為**流影線**，雖穿價但收回 | 較好判讀 |
| **穿價成交** | 即所謂**破底翻、假突破** | 以**實體 K** 灌破關卡後再收回 | 讓你以為要下去了、又站回來 | **散戶最怕**，難度高 |

### 出價成交實例（17 號台指 1 分 K）

- 出現「**大黑上大紅下 / 大紅上大黑下**」的點位——主力單子預掛在此，冲上去 K 棒馬上被打下來。
- 開、收盤價都還收在關卡線以下 → 嚴格定義為**出價成交**。
- 對應三法：**出大黑 → 回射大黑頂（不過）→ 破大紅 → 下去**，就是空方三法。你懂三法照樣會做，只是現在知道這條線就是主力設價的「阻力」。
- 出大黑後還有單子沒成交，回去成交完才殺下來，**遇到這種要特別小心**。

### 穿價成交實例

- 點位被**一根大黑灌破（是實體、不是影線）** → 定義為穿價。
- 下來之後再上去出一個大紅，冲上去又回測大紅底、**收影線** → 表示這個點位有呂布。
- 老師會怕，所以**大黑灌破時會多看幾分**，等是否有大紅收上、且又在同一點位收上，再考慮進場（穿價神將的手法）。

### 真假穿價的對照（震盪激烈日）

- **「對」的穿價（真支撐）**：下去再上去之後，**跑了一段都沒再回來**；就算回來也是**收影線**。
- **「不對」的穿價（假象，要縮手）**：過了關卡、回來上去**又是實體**，實體在這邊過破 → 不對，先縮手觀望。
- 配套判斷：看**五分階梯有沒有斷、上升趨勢線有沒有破**。趨勢線沒破、五分階梯沒斷（就算長得很醜、一堆畢雷針／收腳影線），基本上續抱。
- 重要邏輯：**真阻力埋伏不會只轉幾點就跑**，出現阻力蹤跡至少要走「將近一個滿足點」才正常；若只反彈幾點、又沒跌破上升均線，心中就要警覺「這不太對」。

## 三法的奧義（三）：滿足點與「非事後諸葛」的實證

- **滿足點不要追、容易反轉**。三法大漏電這段時間，靠滿足點避開了好幾次追高殺低。
- 滿足點突破了也沒關係——它不會害你賠、頂多害你少賺或提早撤。
- **同一套方法解每天的盤**才是對的；不能今天用 A 法、明天用 B 法、後天用 C 法。但前提是要有**一定程度的勝算**。

### 當下提醒實例（非事後諸葛）

1. **當冲先鋒營 10:22**：同學算 1:1 測幅會跌到 8364；老師當下立刻說**不對，8412 有呂布的埋伏**（大黑下大紅上），提醒不要想 N 字下去。
2. **社團 9:25**：同學提 30 分 K RSI 負乖離過大（-28）會反彈；老師提醒**用指標做指數要特別小心，尤其 30 分 K 一根是半小時**，半小時內你不知它會續跌還是收斂——**要回歸 1 分 K 最即時**。老師當下提醒 **8390 附近有呂布**（大黑下大紅上，且是滿足點，容易反轉）。另有同學以「道恩恩賜」與社福滿足 1:1 互相印證。
3. **下單實證**：盤中下一口空（設在 18 年附近），驗證呂布存在，**為何只 VC 一口**——因為 **10 點過後沒亮、不好判斷，10 點前才有把握下多口**。守住關卡（穿價神將），後來見好就收。

### 關於「破一兩點算不算破」

- 學會方法後不要那麼急著計較那一兩點。多看幾根 K 線，5 分鐘再確認。
- 判讀重點不是精準到點，而是看：
  - 跌破的是**影線**還是**實體**？
  - 跌破的那一根**有沒有大量**？
- 若是**扎實的一根大黑灌破實體** → 停損先出再說，觀察是「過而不破去跌」還是「跌完又收回去」。
- **出場不代表不能再進場**：被掃出場、若又收上去，照樣可以再進場，賠不到幾點。
- 老師現在「連線都不畫」，眼中自有一條線；以前還嫩才畫線，怕跌破一兩點就把線畫粗一點。

## 進場心法總結

- **進場點＝回射點＝停損點**：盡量看出主力在哪裡進場，就跟著進場，離主力點位不要太遠才安心。
- **回射不追**：
  - 做多 → **買黑不買紅**（回射做多）
  - 做空 → **空紅不空黑**
- 看到**虛擬大黑頂**（空曠位抵抗）**無論如何先出一趟**，破了再說，後面過而不破再接也來得及。
- 俗辣戰法：**看到光塔（壓力）就撤**，大盤就弄不到你；不要貪，貪吃的都會吐回去。
- **以三法為主，指標（正乖離過大、背離、均差口差比差等）為輔**——人只有兩三台電腦、幾分鐘決策時間，看太多東西指數早就跑掉了，務必**以簡馭繁**。

## 資金與心態（昨天與「汪」討論的結論）

- 集合競價市場上能賺到錢的**兩種人**：
  1. **勝率很高但不貪**：每天穩定提款幾千塊（小台積少成多，很恐怖），確定一點再上大台。
  2. （另一種高勝率＋紀律者，老師以自身為例：抱輕鬆愉快心情，一口小台都當遊戲玩）
- **不要高估自己的心理素質**：盤勢不如預期、硬拗時的虧損會讓信心崩潰，沒信心就會被盤的氣勢壓著打。
- **人要比盤凶**：你害怕就會一直被盤帶著走。
- 老師自律：**兩敗就不玩**，所以很珍惜每一次出手機會。
- 新手常見覆轍：剛進場資金多、口數下得比老師還大，嘗到一點甜頭後吐回一堆，信心與錢都沒了就退出市場、**回不來了**。
- **建議步驟（不能省）**：先用模擬單 → 一口 OP／一口小台練 → 勝率穩定 → 再慢慢放大。
- **勝率比勝據（獲利幅度）重要**：先有勝率，再去求勝據。老師現在用小台，單子越抱越長（20 點、50 點都還抓得到）。**先不要急——你有方法，市場每天都在，急什麼。**

## 名詞

| 名詞 | 解釋 |
|---|---|
| **三法** | 本套系統核心戰法。多頭：出大紅 → 破大黑 → 回射大紅底；空頭：出大黑 → 破大紅（不過大黑頂）→ 回射大黑頂。其奧義是抓主力進場（埋伏）的點位。 |
| **呂布（驢布／埋伏）** | 三法背後的詮釋。比喻有極絕大軍（千口下單）能力的**主力**；主力在 K 線上留下的大量痕跡就是「埋伏」，是進場點位的線索。 |
| **回射** | 主力大軍尚未集結完，回到先前噴出、未成交的點位，讓未成交口數全部成交（集結軍隊）的動作。回射點＝進場點＝停損點。 |
| **出價成交** | 主力在關卡掛單，價格觸到就被打回，**收盤仍守住關卡線**（多為流影線）。較好判讀。 |
| **穿價成交** | 即破底翻／假突破，以**實體 K 灌破**關卡後再收回。散戶最怕，難度高，需多看幾根 K 線並配合趨勢線、五分階梯確認真假。 |
| **大紅底／大黑頂** | 三法中回射的目標關卡：大紅 K 的底部（多頭支撐）／大黑 K 的頂部（空頭壓力）。 |
| **虛擬大黑頂** | 空曠位的抵抗壓力；做多遇到它「無論如何先出一趟」。 |
| **滿足點** | 走勢的測幅滿足位置，容易反轉，「不要追」。真阻力埋伏通常會走到將近一個滿足點。 |
| **大量／量縮** | 老師盤中兩大觀察重點。大量＝呂布（主力）出現；量縮（人多量卻少）＝即將表態出方向。 |
| **關卡（過關卡／冲關卡）** | 上方壓力、下方支撐構成的價位。冲關卡時權利金膨脹，是賣方點數最多的進場時機。 |
| **五分階梯／趨勢線** | 輔助判斷工具。趨勢線沒破、五分階梯沒斷（即使長得很醜）基本上續抱。 |
| **SP／SC／BC** | 選擇權部位：SP＝賣出賣權、SC＝賣出買權、BC＝買進買權（防護）。向上突破時撤 SC、留 SP、補 BC 防護。 |
| **VC（VC 一口）** | 賣出買權（Sell Call）一口；10 點過後沒亮、不好判讀時保守只下一口。 |
| **以簡馭繁** | 全片核心心法：操作要簡單，看的東西越少越好，以三法為主、指標為輔。 |
| **勝率 vs 勝據** | 勝率＝獲勝機率；勝據＝獲利幅度。先求穩定勝率，再求勝據。 |
| **道恩（恩賜）** | 同學使用的另一套測幅／反轉判斷法，可與社福（測幅滿足）1:1 互相印證。 |

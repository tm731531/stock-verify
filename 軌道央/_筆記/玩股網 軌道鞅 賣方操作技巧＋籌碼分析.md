# 軌道鞅 賣方操作技巧＋籌碼分析

> 來源：玩股網 軌道鞅 賣方操作技巧＋籌碼分析.mp4 | 逐字稿：`_逐字稿/玩股網 軌道鞅 賣方操作技巧＋籌碼分析.txt`

## 一句話結論

選擇權「賣方」的核心是：在軌道（支撐／壓力）附近收高價權利金、靠時間價值在「跌、盤」兩種盤勢吃下優勢，再用價內／價外價差單把風險鎖死；操作以「三法（勢）為先、籌碼為輔」，把分開觀察的多空消長與 OP 金額當作加強信心的工具。

## 第一部分：買方當沖的前置觀念（鋪陳賣方）

### 1. 用 Delta 值預掛單（上班族無法盯盤時）

- 想預掛在某個點位成交，先抓**目前指數到目標點位的點差**，再乘上**該履約價當下的 Delta 值**，推估權利金會變多少。
- 例：現在 9550，預期漲到 9600（漲 50 點）。把 50 點 × 你要做的履約價 Delta 值，得到權利金的概略增減後預掛。
- Delta 是「當下」的值，指數上下移動 Delta 會跟著變，所以會有誤差 → 用**前後幾檔（如 ±2~3 點）分散預掛**。
- 買權上漲時 Delta 越來越大、賣權則越來越小，預掛點數要據此加減。

### 2. 沒有 Delta 表時的速算法

| 情境 | 速算方式 |
|------|----------|
| 做價平 | **台指期點數砍半** |
| 做價平 + 看漲做 Call | 砍半後**再加一點** |
| 做價平 + 要 SP | 砍半後**再減一點** |
| 價外 | 砍半後**再減多一點**（Delta 較小） |
| 價內 | 砍半後**再加多一點**（Delta 較大） |
| 一定要成交 | 再往不利方向多讓一點 |

### 3. 周選 vs 月選、價平 vs 價外

- **當沖用周選，流暢（波段）用月選。**
- 點位**有把握**→ 用**價平**；**沒把握**→ 用**價外一檔**；不建議做到價外兩檔以上。
- 原因（波動率特性）：價平在看錯、回測點抓不好時，**權利金點數掉得很快**；價外掉得比較少，較能容錯。
- **買方流暢的兩大好處**：
  1. 看錯時最多賠掉那十幾點權利金（如流暢 99Call 最多賠 10 多點），**不會倒賠、不會被追繳保證金或斷頭**。
  2. 看對時價外會往價內跑、點數翻倍。
- 例：流暢 99Call 賭指數上 9850；就算到不了 9900，只要指數到 98、99Call 由價外兩檔變一檔，點數仍會翻倍。

### 4. 買方進出時機（為賣方鋪陳）

- **回測支撐／壓力時買進**（此時波動率小、權利金便宜），一口試單，往下慢慢接、把成本壓低；但前提是**該支撐有撐**（96 沒撐就認賠出場）。
- **出大紅／大黑（波動率最大）時賣出**：做多在大紅劈掉、做空在大黑出場，3~5 點就跑、不要貪。
- **同點位、第一次出大紅衝上去的權利金，通常比之後回來再衝更多** → 開高走高第一波一定先買。
- **倒帶（追價）不要做**：曾有同學追大紅，指數明明多漲十幾點，權利金卻只打平，因為他買在大紅高波動的價格上。
- **支撐／壓力只搶第一次**，第二次不要搶（尤其大紅、整數關卡）。

### 5. 階梯走法停利

- 空單一路往下，出現一個個像樓梯的階梯；**哪一個階梯被阻斷（被突破）就停利**。
- 1 分 K 容易被破、要多看一根；可切到 **5 分 K**，階梯較乾淨。
- 用途：即使知道滿足點或頸線位置，也用階梯確保戰果（有些走不到頸線就回去）。

## 第二部分：賣方操作技巧

### 1. 賣方的核心思維（與買方相反）

- 買方：**低買高賣**（壓低成本買、衝高波動時賣）。
- 賣方：**高賣低收**（在大紅／大黑、波動率膨脹時收高權利金，回歸正常或盤整時獲利了結 / 低價買回平倉）。
- 大紅大黑時 Call/Put 供不應求、出現「非理性供需失衡」，權利金膨脹 → **賣方就是去收這段膨脹的權利金**。
- 即使指數沒再衝，只要由膨脹轉盤整、權利金回歸正常，賣方就開始賺。
- 實例：空方三法時最安全做法是 **SC97**；當指數衝日 K20MA、Call 權利金暴漲且關前受阻時去 SC97，收到的點數最多。

### 2. 賣方在三種盤勢的優勢

| 策略 | 漲勢 | 跌勢 | 盤勢 |
|------|------|------|------|
| 買方（BC／BP） | 看對賺得多、成本低 | 賠 | 賠（時間價值流失） |
| 賣方（SC／SP） | 賠、且成本高 | **賺** | **賺**（時間價值流失對賣方有利） |

→ **賣方在「跌、盤」兩種盤勢具優勢**，三種盤裡占兩種。

### 3. 依風險偏好選履約價（賣方更敢做的原因）

- 短期內漲不回 97、漲不到 10000，所以賣方可以選更遠、更安全的履約價：

| 屬性 | 做法 |
|------|------|
| 風險愛好者 | SC96 |
| 風險規避者 | SC97 |
| 極度保守 | SC10000（遠期深度價外） |

- 上班族無法盯盤、又怕反彈（RSI）→ **SC97 相對安全**，且不會馬上衝到 97。

### 4. 保證金與權利金（遊戲規則）

- 選擇權的「交易貨幣」是**權利金（點數）**。
- 買方：**付權利金**（買東西付錢）。
- 賣方：**收權利金、付保證金（台幣）** —— 你無故收人家錢，得有擔保、怕你落跑（如租 DVD 要押金）。
- 判斷要不要交保證金的通則（價差單）：
  - **收的點數 > 付出的點數** → 要**繳保證金**。
  - **付出的點數 > 收的點數** → **不用保證金，只付權利金**。

### 5. 軌道建倉的邏輯

- 建倉一律**依軌道（支撐／壓力）進場**，本質是找大盤的支撐與壓力。
- 為何在壓力做 SC 優於在軌道做 BP：BP 只有「往下破」才賺，盤整或不跌都賠；**SC 只要不往上衝（盤或跌都算）就賺**。
- 在支撐／壓力進場成本較低 → 買方成本低、**賣方收的權利金點數高**。
- 賣方額外好處：壓力 9750，不一定 SC97，可 SC98、SC99、SC10000，越遠越安全。
- 提醒：**建倉盡量不要太靠軌道**，一旦軌道沒破、反向力道很強會吃力（本次 98 因貼軌道而較慘，97 多能全身而退）。

### 6. 防護：價內防護 vs 價外防護（央視只分這兩種）

核心只記兩件事 → 你要用**波動率大（價內）**還是**波動率小（價外）**的單去防護：

| | 價外防護 | 價內防護 |
|---|---|---|
| 用途 | 不確定是否假突破、只是**防小幅突破** | **已確定突破很多**，要追上虧損速度 |
| 權利金 | 較少 | 較多 |
| 波動率 | 小（追不上賣方腳步） | 大（追得上） |
| 撤單 | 突破又跌回就撤掉即可 | — |
| 時點 | 可事前做（建倉就掛上） | 多為事後加殺單 |

#### SC 端範例（SC96，價平 56 點）

- **價外防護 = SC96 + BC97 → 買權空頭價差（Bear Call Spread）**
  - 防護範圍 9656（96 + 56），結算不破 9656 都賺。
  - 收的權利金 > 付出 → **需繳保證金**。
  - 兩履約價差 100 點；最大虧損 = 100 − 最大獲利。
  - 損益平衡約 **9631**；最大獲利 31 點（不破 96，跌到 94、95 都只賺 31）；漲破後最多賠 69 點（漲到 98、99、10000 都是賠 69）。
- **價內防護 = SC96 + BC95 → 買權多頭價差（Bull Call Spread）**
  - BC95 付 106 點、SC96 收 56 點 → **付出 > 收，不繳保證金、只付權利金**。
  - 最大獲利 50 點（漲破 96 就鎖住賺 50）、最大虧損 50 點（跌破 95 賠 50）。風險與獲利都鎖住。

#### SP 端範例（SP94，價平 32.5 點，倒過來想）

- **價外防護 = SP94 + BP93 → 賣權多頭價差（Bull Put Spread）**
  - 防護範圍 9367（有點危險，沒到軌道下緣 9350）。
  - 損益平衡約 9382；跌破最多賠 82 點、漲過 94 賺 18 點。
- **價內防護 = SP94 + BP95 → 賣權空頭價差（Bear Put Spread）**
  - BP95 付 64 點、SP94 收 32.5 點 → **付出 > 收，不繳保證金**。

> 提早布局技巧：若預計指數會跌到軌道下緣才做 SP94 + BP93，可**提前在較高位先做便宜的 BP93**當防護（成本更低）；若沒跌到、SP 沒組成，BP 本身也能獲利。新手仍建議乖乖到位再建倉。

> 為何不直接 BP 而要做價差單：BP 在盤整或反漲時權利金全沒；賣權空頭價差因為還收了 SP94 的 32.5 點，**反漲時能少賠這 32 點**。價差單一律「獲利有限、風險有限」，不怕美股大跌。

### 7. 勒式（熱式）、跨式、兀鷹（誤因）

- **熱式（勒式）**：軌道上緣 SC、下緣 SP，**兩邊不同履約價同時減倉**；同時減倉的保證金比單邊便宜。老師個人偏好「一邊一邊做」（到上緣做 SC、到下緣做 SP），等於用賣方取代買方。
- **跨市（跨式）**：兩邊 S **坐在同一個履約價**（如 95 跨 = SC95 + SP95）。把它先拆成兩個「熱市單邊」看：SC95 防護加外一檔 BC96、SP95 防護加外一檔 BP94，本質就是價外防護的想法。
- **兀鷹（誤因）= 把 SC96 價外防護價差單 + SP94 價外防護價差單兩組合起來**：賭指數在上下緣（96 / 94）之間結算，獲利就是兩組價外防護獲利相加；一邊跌破就一組賺、一組賠。用「兩邊防護」概念理解即可。
- 推導關係：**跨式 + 防護 → 跌市**；**勒式（熱市）+ 防護 → 兀鷹（呼應）**。

### 8. 跨式建倉重點與 350 點統計

- 95 跨收 170 點 → 防護範圍 9670 ~ 9330，已 cover 軌道下緣 935，且未太貼下緣，尚 OK。
- 點數嫌少可改做**下個月**。
- 不想花錢買雙邊保險（VC/VP）→ **只做怕的那一邊**（現在怕跌不怕漲就只買 VP 一邊）；除非出現 30 分 K 多方三法再補另一邊。新手建議要嘛都不補、要嘛加強防護補滿，因為跨式本身上下互為防護（跌一兩百點已有效，跌 300 點則不敢保證）。
- **350 點統計**：自有周選以來，約**七成機會**結算落在「結算前收盤價 ±350 點」以內。當時結算前約 9550，加 350~400 點到較陡的軌道上緣。
- **現在籌碼偏空**，把這 350 點框框往下移，約落在 9283 附近（不是說一定跌到，而是統計上最多跌到那附近）；9283 上方還有軌道與頸線，會糾纏。

## 第三部分：籌碼分析（三法為先、籌碼輔助）

> 原則：**訊號太多會打架**。新手先把基本（三盤 / 軌道）弄熟，再擴張。籌碼是輔助，三法（StochMA／勢）最先示警逆轉（97 多時已示警空方三法）。

### 1. 外資期貨未平倉（OI）

- **不要只看「多單 − 空單」的淨額差**：負三千多口，可能是「多單減少」也可能是「空單增加」，要**分開看多空消長**。
- 看**整段時間**的多空消長，不要只看單日；並記下增減發生在**哪個指數位置**。
- 實例：外資空單某日在 **9757** 增加 → 只要把盤壓在 9757 之下，外資都賺；本波外資多單成本約在 **9555**（隔天跳空），若跌破此處又不守、空單續增就要小心。
- 陷阱：上個月也曾多單減、空單增，結果只是回檔後再上拉（老師當時也誤判）→ 籌碼只能輔助。

### 2. 選擇權買賣權未平倉（把自己當外資）

- 對照：**買買權 = BC、賣買權 = SC、買賣權 = BP、賣賣權 = SP**。
- 兩個重點：
  1. **看一段時間 BC/SC/BP/SP 的消長**，不看單日。
  2. **看 OP 金額，不看口數**：「買 1000 台腳踏車不如一台賓士」——不知道對方做哪個履約價，價外好幾檔可能是避險而非獲利，所以**一律用金額判斷**。
- **OP 金額 = 多方金額（BC、SC 相關相減）− 空方金額**：
  - **正且大（10~15 億以上）→ 偏多、多頭強勢**。
  - **負且大 → 偏空**。
  - 跌破軌道後 OP 金額仍可能為正：**大戶部位龐大、無法瞬間移動，會慢慢調整**。

### 3. 期貨大額交易人未沖銷部位結構表（轉倉時最好用）

- 用途：**轉倉時**提前看大戶下個月偏多／偏空。
- 算法（特法 = 前十大特定法人，看括號部分）：
  - 多單 = 所有契約買方 − 前五大買方（例：34671 − 7100 多 ≈ 27000 多口）。
  - 空單 = 所有契約賣方 − 前五大賣方（例：30513 − 12822 ≈ 17000 多口）。
  - 上例多 2.7 萬 > 空 1.7 萬 → 下月**偏多**。
- 注意：多空相差大時（如上月）很明確；若只差兩三千口，**結算隔天可能一夕翻盤**（遇過多次）。
- 應用：有三法（如多方三法 + 回測大紅底）+ 籌碼偏多 → 口數放多；三法不明確又只差兩三千口 → 不進場或口數放少。**用來加強信心。**

### 4. 融資維持率（催化劑）

- 大盤融資維持率**低於 160** → 大部分投資人都賠錢；現在約 **159 多**。
- 有「關卡過破慣性」：回測軌道不過會續跌、融資維持率也會回測；**破 160 可能引發多殺多**，要持續關注。
- 可在融資維持率圖上畫軌道／頸線，用「過、破」判斷大盤即將漲或跌。

### 5. 期指多空成本計算

- 期貨契約金額以「千」為單位（要 ×1000），口數 × 200 × 指數 = 契約金額。
- 簡化：**多空成本 ≈ 期貨契約金額 × 5 ÷ 口數**（1000 ÷ 200 = 5，命的偷懶算法）。
- 單日不準，需**每日往前加總**成連續趨勢，對照大盤看外資多空成本所在（社團會做成 Excel／軟體自動更新）。

## 名詞

- **量價 / 主力成本 / 換倉成本**：以成交量、價格與主力進出位置推估的持倉成本，是判斷支撐壓力的基礎。
- **裸 K**：不掛指標、單看 K 線型態。
- **SC / SP**：賣出買權（Sell Call）／賣出賣權（Sell Put），即「賣方」。**BC / BP**：買進買權／買進賣權，即「買方」。
- **時間價值**：選擇權隨到期逼近而流失的價值；對賣方有利、對買方不利。
- **價平 / 價內 / 價外**：履約價相對現價的位置（At/In/Out the money）。
- **履約價**：選擇權約定的執行價格（逐字稿常誤判為「旅約價」）。
- **保證金 / 權利金**：權利金是選擇權的交易點數；賣方收權利金但須繳保證金作擔保。
- **Delta**：標的每變動一點，選擇權價格的變動量；用來推估權利金與預掛價。
- **波動率 / 隱含波動率（IV）**：價格波動程度；大紅大黑時 IV 膨脹，賣方收高權利金的來源。
- **價差單**：同時買、賣不同履約價，**獲利有限、風險有限**（價內／價外防護皆屬之）。
- **買權空頭價差（Bear Call Spread）**：SC + BC（較高履約價），看不漲，本片的「SC 價外防護」。
- **買權多頭價差（Bull Call Spread）**：BC（較低）+ SC，本片的「SC 價內防護」。
- **賣權多頭價差（Bull Put Spread）**：SP + BP（較低履約價），本片的「SP 價外防護」。
- **賣權空頭價差（Bear Put Spread）**：BP（較高）+ SP，本片的「SP 價內防護」。
- **勒式（熱式）**：同時賣出不同履約價的 SC 與 SP。
- **跨式（跨市）**：同時賣出同一履約價的 SC 與 SP。
- **兀鷹（誤因 / 呼應）**：勒式（雙價外）再加雙邊防護的四腳價差組合（鐵兀鷹 / iron condor 概念）。
- **跌市**：跨式再加雙邊防護（鐵蝴蝶 / iron butterfly 概念，老師用語）。
- **三法 / 勢**：軌道鞅判斷趨勢的型態（多方三法、空方三法等）；勢＝趨勢，斷勢即趨勢結束。逐字稿常把「勢」誤判為「是 / 市 / 試」。
- **大紅 / 大黑、大紅底 / 大黑頂**：高波動的長紅 / 長黑 K 棒；其底 / 頂常成支撐 / 壓力，回測大黑頂做空。
- **階梯走法**：行情如樓梯一階階推進，某一階被阻斷即停利。
- **滿足點 / 頸線**：型態學的目標價與頸部支撐壓力位置。

## 一句話結論

把選擇權當成「一個有買權(Call/可樂)、賣權(Put/葡萄)兩家公司的國家」來理解，先弄懂買方/賣方、價內外、時間價值與波動率(Delta)的本質，再搭配軌道鞅系統的「近軌操作、遠月、往外抓 100 點、跨式/勒式分開或同時建倉、依波動率做防護」，用高勝率的賣方思維賺取時間價值與區間價差，核心心法是「不求贏、先求不輸、立於不敗之地」。

## 段落一：選擇權的基礎比喻──「選擇權這個國家」

老師要學員先把過去學過的所有選擇權策略（多頭價差、空頭價差等）全部清空，當成一張白紙，改用生活化比喻重新理解。

- **貨幣換算**：選擇權國家的貨幣叫**權利金**，與新台幣匯率 **1 點權利金 = 50 元新台幣**。
- **兩間競爭公司**：
  - **買權 Call（俗稱「可樂」）**：台指期**漲**，Call 的所有商品就**漲**。
  - **賣權 Put（俗稱「葡萄」）**：台指期**漲**，Put 就**跌**；台指期**跌**，Put 就**漲**。
  - 兩家公司商品價格呈**反向關係**。
- **履約價 = 商品（不是價格/指數）**：把每個履約價想成一台商品，依價值高低排序為「太空梭 → 飛機 → 遊艇 → 汽車 → 摩托車 → 腳踏車 → 溜冰鞋 → 拖鞋」。
  - 對 **Call**：履約價越低（越價內）越貴（太空梭）；履約價越高（越價外）越便宜（拖鞋）。
  - 對 **Put**：剛好相反，履約價越高越貴、越低越便宜。
- **成交價 vs 履約價**：成交價是商品「現在的價值（權利金報價）」；履約價只是商品編號。每個履約價都有自己的買價、賣價與獨立 K 線圖。
- **想立刻成交**：買方要用對方掛出的**賣價**去買、賣方要用對方掛出的**買價**去賣，才會即時撮合。

**最大量觀察**：總量與未平倉量最大的履約價，通常是莊家(賣方)聚集處 →
- Call 最大量處（如 SC）→ 上方**壓力**。
- Put 最大量處（如 SP）→ 下方**支撐**。
- 但「倒莊事件」常發生，僅供參考、不一定準。

## 段落二：買方 vs 賣方（蘋果電腦比喻）

以一台市值 5 萬權利金的 Mac 比喻：

| 項目 | 買方 (Buy) | 賣方 (Sell) |
|------|-----------|------------|
| 操作順序 | 先買後賣 | 先賣後買（先收錢、之後再回補） |
| 付款方式 | 先付**權利金** | 先收**權利金**，但要押**保證金** |
| 預期 | 看漲（5萬買、漲到6萬賣） | 看跌（先收5萬，跌到3萬再回補，賺價差） |
| 風險 | **有限**（最多歸零，不倒賠） | **無限**（漲越多賠越多，要倒吐保證金） |
| 獲利 | **無限**（漲多少賺多少） | **有限**（最多賺收到的權利金） |
| 時間 | 有時間壓力（價值流失對買方不利） | 時間是朋友（時間價值流失對賣方有利） |
| 資金 | 本小（一口約 2,000 多元） | 本厚（一口約 1～2 萬以上保證金） |

- **保證金的由來**：期交所跟你沒交情，怕你賣方部位被軋（電腦不跌反漲），所以要押保證金。漲到接近保證金、**維持率不足**時，營業員會通知**補保證金**；不補就被拿保證金強制回補（強制平倉）。
- **系統性風險**：若一夕暴漲（電腦突然大缺貨漲到 20 萬），賣方不但保證金沒了還要倒賠。
- **結算 = 交貨日**：期交所不像好朋友能無限期等，每月/每週都有結算，必須在結算前讓價格回到對你有利的位置。

**結論**：買方要看準趨勢（漲跌）；賣方要抓準**進場時機（區間邊緣）**，因為提早進場可能繼續被軋。

## 段落三：漲跌盤與四種操作（為何賣方勝率高）

台指期只有三種走勢，對應操作：

| 走勢 | Call | Put | 對買方操作 | 對賣方操作 |
|------|------|-----|-----------|-----------|
| 漲 | 漲 | 跌 | **BC**（買Call） | **SP**（賣Put） |
| 跌 | 跌 | 漲 | **BP**（買Put） | **SC**（賣Call） |
| 不漲不跌（盤整） | 跌 | 跌 | 不利 | 兩邊都賺**時間價值** |

- 四種排列組合：BC / BP / SC / SP（Buy×Sell × Call×Put）。
- **賣方勝率高的原因**：漲、跌、盤三種模式，有**兩種**（跌、盤）對賣方有利，理論勝率約 **66%**。盤整盤即使指數不動，時間價值仍會流失，賣方照賺。

## 段落四：價內 / 價外 / 價平與兩種價值

- **價平**：手機軟體上標**黃色**那一檔，即離目前台指期最近的履約價（時間價值最大）。
- **價內**：對 Call 而言比價平更低的履約價（汽車、遊艇、飛機），較貴；對 Put 相反。
- **價外**：比價平更外側的履約價（腳踏車、溜冰鞋、拖鞋），較便宜。

**權利金 = 內含價值 + 時間價值**

- **內含價值**：越價內越高（汽車比腳踏車貴），價外幾乎沒有內含價值。
- **時間價值**：目前指數「達成履約價」的可能性價值。

## 段落五：時間價值（光圈同學比喻）★核心觀念

老師以「8:50 集合、誰能在 10 分鐘內趕到光圈教室」比喻時間價值：

- **價平的時間價值 > 價外、也 > 價內**：住在光圈附近的同學（價平）最容易到達，時間價值最大；新竹/桃園/台南的人(價外)趕不到，毫無時間價值。
- **遠月的時間價值 > 近月**：若改成「前一晚 8:50 出發」（時間拉長），每個人到達機率都變大、時間價值都變高 → 遠月權利金一定比近月貴，貴出的點數就是時間價值。
  - 例：3 月 8500 的 Put 有 132 點、2 月 8500 的 Put 只有 55 點，同樣是「摩托車」，多出的約 77 點就是多一個月的時間價值。

**時間價值消失速度**

- 結算前一週以前，時間價值幾乎呈水平線，**一天約消失 5 點**。
- **週選擇權**到結算前一週後**斜率銳減**，消失最快。
- 但週選收的權利金點數**少很多**，能 cover 的損失範圍也少 → 「週選對賣方有利」只對一半。

**對買方流倉的重大警示**

- 價平 Delta 約 0.5，時間價值一天消失 5 點，換算台指期相當於 **10 點**。
- 留倉到隔天，必須預期隔天台指期漲超過 **10 點**才有意義；若對手開平盤，你已先輸 10 點。
- **週選更慘**，隔天可能要漲 15 點以上才有賺。
- **結論：買方沒有訊號（波段三法/絕對反轉 100 點以上）絕不亂留倉。**

## 段落六：波動率（Delta）與隱含波動率

- **價平的波動率約 0.5**：台指期漲 1 點，價平 Call 漲 0.5、價平 Put 跌 0.5。
- **越價內波動率越高、越價外越低**（如 8300 對 Call 是 0.6、對 Put 是 0.4）。
- 兩家公司同一履約價的 Delta 相加 ≈ 1。

**隱含波動率（恐慌指數）**

- 一般波動率 = 歷史統計的正常波動（理想值）。
- **隱含波動率** = 超乎理想的恐慌值（如颱風天青菜從一斤 10 元變 60 元、大賣場搶菜）。
- **為何 Put 跌得比 Call 漲得兇**：人性怕跌不怕漲。大跌常一次跳空 200 點、難處理；大漲頂多跳空 100～150 點、還有時間反應。供需失衡時，恐慌讓 Put 價格暴貴 → 這就是隱含波動率。
- 也因此「以 put-call 推算指數」會有 1～2 點誤差（隱含波動率造成）。

## 段落七：用 Put-Call 反推台指期點位（K 線當掉也能算）

當 K 線圖打不開、只剩報價表時，可精算指數位置：

1. **同一履約價、Call=Put 時，指數恰在該履約價**（例：8400 時 Call、Put 都是 53）。
2. 若該履約價 Call 報價 > Put → 指數在該履約價**之上**；反之在**之下**。
3. **公式**：
   - 指數在履約價之下：`履約價 −（Put − Call）`
   - 指數在履約價之上：`履約價 +（Call − Put）`
4. 範例（2 月）：8500 的 Call 38.5、Put 55 → 在 8500 之下 → 8500 −（55−38.5）= **8483.5**。
5. **重點**：算 2 月商品要看台指期 2 月 K 線、算 3 月要看 3 月，**月份不可混用**；看長期趨勢用台指期連續圖。

## 段落八：用選擇權組合成小台/大台

- **看漲**：BC 一口價平 + SP 一口價平 = 一口小台。
- **看跌**：BP 一口價平 + SC 一口價平 = 一口小台。
- 原理：價平 Call 0.5 + 價平 Put 0.5 = 1（與小台 1:1 連動）。指數移動後，把整排波動率往漲的方向「下移」、往跌的方向「上移」，相加仍等於 1。
- **模擬大台**：買 4 口 Call + 賣 4 口 Put。
- **買方加碼威力**：BC 兩口價平，漲一檔變價內後 Delta 變 0.6×2=1.2，**效果大於小台**，而成本僅 4,000 多元 → 這是買方的優勢（但須精準判斷漲跌）。

## 段落九：買方思維與操作準則

**思維**：判斷漲跌賺價差（賺內含價值），設法讓價外/價平的履約價移到價內（摩托車變汽車變遊艇）。

**特性**：有時間壓力、適合本小、能盯盤、風險有限獲利無窮。

**操作準則**
- **當沖三法不留倉、波段三法才留倉。**
- **操作價平以內的標的**（價平以內才有內含價值）。
- 沒有波段行情就盡量當沖、不能盯盤就別當買方。

## 段落十：賣方思維與操作準則

**思維**：判斷**區間邊緣**、賺取**時間價值**。看到別人看不到的「這台 Mac 漲不上去了（已在邊緣 5 萬）」，所以敢先收錢。

**心法**
- **不要輕易建立部位；一旦建立就不要隨便平掉**（帳面虧損≠實際虧損，結算前都有機會）。
- 靠近**軌道邊緣**建倉，建完可安心上班。
- 動來動去會把「帳面虧損」做成「實際虧損」，這是賣方大忌。

**特性**：沒有時間壓力、適合本厚、不能盯盤者、獲利有限風險無窮。

**操作準則**
- **波段一法**：靠近軌道做，再往外抓。上緣 8500 → 抓 8600 做 SC；下緣 8300 → 往下抓 8000～8100 做 SP。
- **遠月操作**（時間短較安全、肉也多；長線保護短線，週 K 軌道保護日 K 軌道）。
- **維持率 ≥ 150%**（手機軟體常稱「風險係數/風險指標」），120% 偏危險，易被強制砍倉。
- **SP 部位防護最重要**：老師敢叫大家 BC、卻不敢叫大家裸做 SP，因 SP 一旦大跌（電腦漲到 30 萬）要倒賠。所以**SP 通常不單獨做，而是做跨式、用 SC 保護 SP，盤勢不如預期再做 BP（防護）**。

## 段落十一：結算規則

- **週選擇權**：每週三結算。
- **月選擇權（月結算）**：每月第三個週三結算。
- **結算價**：當天**加權指數**最後半小時平均（最後 25 分鐘每 15 秒報一價共 100 價 + 最後 5 分鐘撮合價 1 價 = 101 個價位，加總 ÷ 101）。
- **重點**：漲跌時看**台指期**、結算時看**加權**。
- 最後一筆撮合價即使大漲 100 點，因要 ÷101，對當月結算幾乎無影響（平均只漲 1 點）；但對**尚未結算的次月部位有影響**（SC 受害、BC 受惠）。
- 結算當天，**價外與遠離價平者全部歸零**（無內含、無時間價值）→ 印證「SC/SP 往外多抓 50～150 點相對安全」。

**賣方賺賠判斷**：SC 8500 收 30 點 → 只要加權結算不漲破 **8530（8500+30）** 就賺；SP 8500 收 30 點 → 只要不跌破 **8470（8500−30）** 就賺。

## 段落十二：保證金計算（SPAN 最佳化）

- **買方沒有保證金**，付的就是權利金。
- **賣方保證金** = 權利金市值 + Max(A 值 − 價外值，B 值)
  - A 值原始保證金 = 19,000；B 值 = 10,000（期交所公布）。
  - 價平/價內的「價外值」= 0；只有**價外**才扣價外值（價外幾檔 × 每檔點數 × 50）。
- **範例**：
  - SC 8700（價外兩檔、權利金 28 點）：價外值 200×50=10,000；Max(19,000−10,000=9,000，10,000)=10,000；+28×50 → **約 11,400 元**。
  - SP 8400 附近（價外、89 點）：Max(9,000,10,000)=10,000；+89×50 → **約 18,450 元**。
  - SC 8500（**價平**、94 點）：Max(19,000−0，10,000)=19,000；+94×50 → **約 23,700 元（價平最貴）**。
- **結論**：價平 > 價內 > 價外（保證金）；**沒有人賣價內**（這台電腦才值 5 萬，不會有人花 8 萬跟你買；風險太大、保證金又高）。
- **SPAN（保證金最佳化）**：同時做 SC87 + SP84 等跨式時，系統取兩者 Max 較大者 + 較小權利金合併，**只收一口的錢**，會吐回 1 萬多、維持率因此提高。

## 段落十三：操作區間為何抓 200 點（上下各 100 點）

三大理由：
1. **長期統計**：週選從開倉到結算約 5 個工作天，破 200 點區間的機率僅約 3 成（不破約 7 成），風險仍在。
2. **權利金 cover 範圍**：週跨式價平收約 90 多點（早期一百多點，現在賣方變多、點數縮水），只能 cover 上下各約 95 點 → 區間約 200 點。
3. **月選優勢**：月選價平權利金約 200 多點，上下可 cover 200 點（區間 400 點），是週選的兩倍，相對安全 → **故賣方盡量做月選**。

- 跨式要在**軌道中間**建（收的點數才能 cover 上下緣）；在軌道上面建跨式，跌下來一定超過點數。
- 別在結算前幾天才做（點數太少，只能 cover 一檔）；盡量 cover 兩三檔以上，否則往遠月做。
- 台股約三分之二是盤整盤、區間震盪，很適合做賣方。可把多個區間規劃出來、區間移動就先平獲利、到下一區間再重新建倉。

## 段落十四：三招總綱（盤勢為主，不被策略框死）

老師強調「大道至簡」、招式不必多但要熟練（如太極練到張三豐）。**以盤勢決定操作策略，而非用策略規範盤勢**。看書上各種複雜價差/兀鷹/蝴蝶組合可以理解，但盤勢看不準再厲害的搭配也沒用。回歸**當沖三法 / 波段三法**。

> 紅 K 黑 K 底部頂部停損停利法：只要**大量紅 K 底部被破**就先離場（尤其股票）。「我的方法可能害你沒賺到，但絕不會害你賠錢。」

### 第一招：勒式（熱市）── 區間邊緣「分開」建倉
- 像兩邊把人勒緊：上緣 SC、下緣 SP，**分開（不同時）建**。
- 一般人會「同時做且不在邊緣做」→ 中間往上漲時 SC 賠、SP 賺但因波動率不同無法 cover。
- **必須在軌道邊緣做**，再往外抓 100 點以上（上緣 8500→SC 8600；下緣 8300→SP 8100 甚至 8000，月選價外三檔還有肉又安全）。
- 訊號越多指向同方向（軌道 + 乖離背離 + 未平倉最大量 + OP 進額為負）勝率越高。

### 第二招：跨式 ── 區間中間「同時」建倉
- 像一個人跨坐在 8500 上：當下**同時** SC 8500 + SP 8500。
- 老師習慣分兩筆下單但同一時間建（非組合單，看得懂自己部位即可）。
- 收的點數要剛好 cover 軌道上下緣。
- **斜率修正技巧**：
  - 上升軌道（斜率正）：等指數漲過中間一點再建價平跨式（如 8500 多走一點才建 8500 跨式，或建偏多側）。
  - 下降軌道：等指數跌破中間一點再建。

### 第三招：防護（買方進場避險）── 突破區間就買保險
- 詳見段落十五。

## 段落十五：防護（做「房屋/避險」）的核心──看波動率★

防護的**買哪一檔**，取決於部位「賠錢的速度（波動率）」，買方獲利速度必須跟得上。

| 防護時機 | 買價內/價外 | 原因 |
|---------|-----------|------|
| **事前做**（尚未虧損，預防突破） | 買**價外** | 權利金點數**不能大於**所收 Sell 的點數，否則沒意義（賣電腦 5 萬、不能花 6 萬買保險） |
| **事後做**（已虧損，要追上虧損速度） | 買**價平或價內** | 部位已用 0.6 速度在賠，買價平(0.5)/價內(0.6) 才追得上 |

**跨式優於勒式的原因**：SC 與 SP 互為防護、此消彼長。但波動率不一致──
- 指數**漲**：SC 賠（0.5→0.6→0.7…越來越快）、SP 賺（0.5→0.4→0.3…越來越慢），賺的追不上賠的 → 再做 **BC（VC）防護**。
- 指數**跌**：SP 賠加速、SC 賺減速 → 再做 **BP（VP）防護**。

**防護操作要訣**
- 隨著價平移動，**整排波動率都要跟著移動**（漲就往下移、跌就往上移），不可用建倉時的舊波動率。
- 漲到讓 SC 變 0.7、SP 變 0.3，賺的已無法 cover 賠的 → **SC 先撤（平倉）**，留 SP 與 BC 賺錢。
- 當 SP 收的點數已剩 2～3 點甚至 0.x，**失去防護價值** → 先獲利了結，再 Sell 一個新的 SP 重新收點數，或直接平掉。
- 防護月份：做 2 月買 2 月、做 3 月買 3 月；只想賭一兩天（如過年期間怕國際生變）可用便宜的週選防護，點數沒了就算了。
- 若**熱市建倉時機很準**（建在軌道、再往外抓 100 點），SC 那 100 點本身就是防護，可不必另做；**SP 例外，一定要防**。

## 段落十六：實例與盤中故事

- **過年前 M 同學跨式 8600 案例**：在 8600 震盪期做跨式沒錯，但跌破小波段上升軌道時老師提醒要防護，多數人忽略；過年前一天大跌到 8500。此時防護**不能再買 8600（已變價外、Delta 0.4 跟不上）**，要買價平 8500 或價內 8400（Delta 0.5/0.6）。該同學買 BP 價內一檔（0.6），加上 SC 賺的，足以 cover SP 賠的還倒賺。
- **何時做防護的關鍵**：一般老師看到 SP 一跌就叫你馬上 BP，沒錯但「**錯在沒畫軌道**」──若跌到軌道就止跌反彈，你的 BP 反而開始賠。所以**在軌道中間可以做防護、剛好在軌道邊緣（會止跌）就先別做**。
- **大跌後的處置**：若盤勢一面倒、留倉虧損影響判斷 → **先平掉、重新思考**（部位在身上會亂出手）。例：SP 大跌虧損 → 平掉 → 發現有「三兄弟（指標）+ 軌道」反轉訊號 → 改 BC 留倉兩天賺約 100 點台指期，把剛剛 SP 的虧損補回來。
- **買方進場為何不冒險**：上週大漲 100 多點老師不留 Call，因加權離軌道下緣 8450 還有約 50 點距離。買方未抓準轉折就買，常被軋到軌道再上去；賣方則有優勢（可往外抓 100 點，不需那麼精準）。

## 段落十七：賣方部位實際解說（老師自己的部位）

- **跨式並非永遠 1:1 couple**：老師在 8600（3月）做跨式，因這波一直漲，Call 部位賠錢、Put 部位賺錢。他趁下跌時（趨勢仍向上、未破軌道）**逐步把 Call 部分先平**，留 Put → 所以部位看起來 Call 兩口、Put 四口口數不對稱，但建倉當下一定是同時等口數建立。
- **8500（3月）跨式**：原建 14 口 14 口，隨指數回跌逐步平 Call；週五跳空大漲，若沒先平 Call 虧損會更大。留部分部位也是為了 **SPAN 保證金最佳化、維持維持率**（約 180～200）。
- **週選跨式 8600（錯誤示範）**：老師坦言自己也偷做兩口週選跨式，成交均價約 100 點（79+27），只要結算前大盤在 8500～8700，仍有機會賺。
- **8550 跨式四組**：收 75 點，只要下週三結算不漲破/跌破 8550±75，權利金全收；但若結算前大跌，Call 部位少、無法 cover 大量 Put 部位，可能逆轉。
- **看起來像單邊 SP 其實是跨式**：老師一堆 SP 部位，其實都是跨式把 SC 平掉後的殘留，利用 SP 賺時間價值。**切勿照抄成裸 SP**。
- **基礎 SC（3月 87/88）**：軌道上緣 87 再往外抓 100 點做 SC 87、88，點數不多但相對安全，只要 3 月結算不漲破 87，帳面終會轉正。

## 段落十八：賣方重點整理（總結）

1. **保證金要夠、不要建滿倉**（維持率 ≥ 150%，最好 180～200）。某券商(統一)因建滿倉無法防護/移動、又凹單，越凹越慘賠數億元 → 教訓。
2. **盤勢不如預期，防護一定要做**；盤中提醒就做，沒做還有 second chance。
3. **不要急著平**：先看軌道在哪、指標有無背離/歸零/極值訊號，再決定。
4. **SP 需防系統性風險**，老師上課前每天冒冷汗，最怕學員看到他一堆 SP 就照做裸 SP。
5. **所收的權利金(OP)點數要能 cover 漲跌幅**（這是一再強調的核心）。

**貫穿全課的心法**：「不要想著贏，要想著不要輸」、「不求有功但求無過、先立於不敗之地」、現金抱在身上最有利、資金不要在市場待太久、滿足點到了就跑、成交落袋為安，看到機會再進場刮一筆就走。

## 名詞

| 名詞 | 說明 |
|------|------|
| **權利金** | 選擇權的報價/貨幣，1 點 = 50 元新台幣 |
| **Call（可樂）／Put（葡萄）** | 買權公司／賣權公司，商品價格反向連動 |
| **BC / BP / SC / SP** | 買Call／買Put／賣Call／賣Put |
| **VC / VP** | 老師口語的買方防護單，即 BC／BP（買進避險） |
| **履約價** | 視為一台「商品」（太空梭～拖鞋），非價格或指數 |
| **價平 / 價內 / 價外** | 價平=離指數最近(黃色)那檔；價內較貴有內含價值；價外較便宜 |
| **內含價值** | 越價內越高（汽車>腳踏車），價外幾乎為零 |
| **時間價值** | 達成履約價的可能性價值；價平>價內外、遠月>近月，一天約消失 5 點 |
| **波動率(Delta)** | 價平約 0.5，越價內越大、越價外越小；Call+Put≈1 |
| **隱含波動率(IV)** | 恐慌指數，供需失衡時讓價格暴貴（颱風搶菜），Put 跌時超跌主因 |
| **跨式** | 同一履約價同時 SC+SP，區間中間「同時」建倉 |
| **勒式（熱市）** | 上緣 SC、下緣 SP，區間邊緣「分開」建倉 |
| **防護（房屋/避險）** | 突破區間時買方進場避險；事前買價外、事後買價平或價內 |
| **保證金 / 維持率** | 賣方押金；維持率(風險係數)盡量 ≥150% |
| **SPAN（保證金最佳化）** | 跨式時系統取 Max 合併、只收一口錢，吐回保證金、提高維持率 |
| **A 值 / B 值** | 期交所公布之原始保證金參數（A=19,000、B=10,000） |
| **結算 / 結算價** | 週選每週三、月選每月第三個週三；結算價看加權末半小時 101 價平均 |
| **週選 / 月選** | 週選時間價值消失最快但點數少；賣方盡量做月選（肉多較安全） |
| **台指期 / 加權** | 漲跌看台指期、結算看加權 |
| **軌道 / 近軌操作** | 軌道鞅系統的支撐壓力區間，靠近軌道邊緣建倉 |
| **當沖三法 / 波段三法** | 軌道鞅進出場訊號；買方當沖不留倉、波段才留倉 |
| **三兄弟** | 三個指標訊號（搭配軌道判斷反轉） |
| **未平倉量 / OP 進額** | 觀察莊家位置與多空力道的數據 |
| **滿足點** | 波段預期目標價，到了就先下車落袋 |
| **留倉（流倉）** | 持倉過夜；買方無訊號絕不留倉 |
| **滿倉 / 凹單** | 全額建倉／死抱虧損部位，賣方大忌 |

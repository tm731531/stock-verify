# 總經小教室 第五堂：景氣循環

> 來源：7-1 總經小教室第五堂「景氣循環」.mp4 | 逐字稿：`_逐字稿/7-1 總經小教室第五堂「景氣循環」.txt`

## 一句話結論

把總體經濟想像成「人體」——政府政策是用藥（升降息／QE）、原油需求是食量、原物料價格是體溫，順著「消費需求 → 景氣循環 → 油價 → 通膨 → 政策 → 美元 → 原物料貨幣」這條因果鏈走，再用技術分析抓進場點，就能在主力之前提前布局景氣循環的轉折。

## 投資不是投機：總經 + 技術分析雙面向

講者強調投資是「有跡可循、有方法」的，核心是在資本市場找**主力進場的痕跡**。判讀分兩個面向：

- **總體經濟**：透露出**趨勢**（哪邊有利可圖、主力可能要進或已進），時間尺度是一兩年的長線。
- **技術分析**：判斷主力**短線成本**與**精準切入點**。期貨合約一個月（美股期貨三個月）換倉一次，換倉後成本就消失，所以技術面的成本偏短線。

> 重點：總經告訴你「方向」，技術面告訴你「何時進場」。光看趨勢硬抱，一個回測幾百點可能就被洗出場；兩者搭配才能精準。

## 核心比喻：人體經濟學

這是整堂課的主軸框架，講者自稱「人體經濟學」：

| 比喻 | 對應的總經概念 |
|------|----------------|
| **人的身體** | 總體經濟整體 |
| 血壓、尿酸、膽固醇等數據 | 各項總經數據（GDP、CPI、失業率等）|
| **醫生** | 政府 / 央行 |
| **用藥**（抗生素、類固醇）| 政策：降息、QE（寬鬆）|
| **停藥 / 減劑量** | 升息、縮表（緊縮）|
| **食量 / 喝水** | 原油需求 |
| 身體好 → 食慾好 → 多吃 | 景氣好 → 原油需求增 → 油價漲 |
| 身體差 → 沒胃口 → 少吃 | 景氣差 → 原油需求減 → 油價跌 |

**景氣循環的根本驅動是「消費需求」**，不是資金。GDP = C + I + G + (X − M)，其中**消費（C）佔比最大**（美國消費約佔 GDP 七成），所以研究消費就能掌握景氣循環。消費又與**進口**連動：進口減少代表需求轉弱。

## 景氣循環的因果鏈與判讀順序

講者強調：經濟學討論時假設「其他條件不變、單一變數影響」，但真實世界所有變數互相干擾，只是有**先後順序（priority）**。整條鏈如下：

1. **消費需求主導景氣** → 需求即人類／企業的需求。
2. **景氣循環影響油價** → 身體好就多吃（油價漲），不好就少吃（油價跌）。
3. **油價影響通膨** → 看 CPI 判斷漲真漲假（見下節）。
4. **政策是藥** → 央行調整利率、QE 來「治病」。
5. **下藥前的預期心理 → 反映在美元指數** → 主力依政策預期提前布局。
6. **美元影響非美貨幣** → 一般為反向關係。
7. **原物料貨幣** → 還要看該國出口商品的供需與價格。

> 利率的本質是**資金借貸成本**。利率一直降 = 政府一直在用藥、創造寬鬆環境（借錢容易、鼓勵投資擴張），代表景氣本來不好。利率一直升 = 停藥／減量，代表身體好轉。

## 升息≠股市跌：破解新聞迷思

新聞愛下「升息股市未跌」這種標題，講者認為是誤導。真相：

- **升降息與股市幾乎同步**——升息是因為「身體好轉」才把藥停掉／減量，身體好轉股市怎麼會跌？
- 升息消息出來時市場常**短期震盪、回檔**，但長期要回到人體經濟學思考：問「它為什麼升息？是身體好轉還是轉壞？」
- 結論：別盡信財經新聞記者，要具備基本專業知識自行判斷。

## 通膨陷阱：明目 CPI vs 核心 CPI（最後一波警訊）

油價上漲不一定代表景氣真的好，要分辨是**真實需求**還是**主力炒作**，關鍵看兩個指標：

- **明目（名目）CPI**：包含能源與食物，波動大、容易被炒作。
- **核心 CPI**：扣除能源與食物，反映**人類實質需求**。

判讀景氣轉折的訊號：

> 當**名目 CPI 一直往上衝、但核心 CPI 卻往下掉**時 → 代表實質需求其實在減弱，油價上漲是**人為炒作的「最後一波煙火」**。此時股市常已提早反轉，原物料卻被主力接棒炒高。這是景氣循環即將「轉空頭」的警訊，可以搶最後一波但要準備出場。

對照印證：身體已出狀況（開始降息用藥）但原物料還拼命往上衝 → 不合理 → 去看核心 CPI 確認實質需求是否往下 → 確認後就知道差不多要反轉。

## 實例一：原油（CL）2017 年底的多頭

- **2017 年底**講者在群組指出原油（CL）會有一波多頭。
- 總經面：政府長期用藥 → 景氣好轉 → 原油需求增 → 供不應求 → 油價漲。
- 技術面：原油走出**頭肩底**，整理很久，等到**站上頸線、出現「過頸不破」回測突破**時才進場（這就是選定時機點的依據）。
- 用頭肩底**測幅**算滿足點，抓整數約 **75**，後來實際到 76 點多就反轉下來，命中測幅。

## 實例二：美元指數 2018 年第二季的發動

- **2018 年 1 月**講者指出美元指數會在**第二季**發動（升息訊號出來後）。
- 為何說「第二季」不說月份：取巧，第二季有四、五、六三個月，預測命中機率高。
- 政策邏輯：政府宣布縮減購債／縮表（**只宣布、還沒實施**）→ 人類對政策的**預期心理** → 主力提前進場 → 美元開始變得有價值。
- 技術面：美元指數走**三角收斂**，頸線與下降趨勢線交於一點；**2018 年 3 月升息訊號出來、技術面突破該點**即可介入做多美元相關商品。
- 結果：美元指數確實在 **4 月（第二季）** 發動。

> 操作心法：政策只是「宣布」就有預期效應，但不能貿然進場（會被洗到結算還沒發動）。一定要等技術面**突破整理區間（如三角收斂上緣、下降趨勢線、頸線交點）**的訊號出現，介入才精準。

## 歷史對照：2008 vs 當前（走相同的路）

講者比對 2000 網路泡沫、2008 金融海嘯與當下（2018 前後）的路徑，認為**當前正在重走 2008 的路**：

- 2008 後：身體出問題 → 一直降息用藥 → **QE1 → QE2 → OT** → 維持低利率多年 → 宣布結束購債 → 縮表計畫 → 升息。
- 原油需求隨景氣好轉回升、原物料上漲。
- 推論：美股還會再創高（實質需求／消費／進出口訊號都還沒出現異狀，所以景氣循環還沒結束），通膨會再起、原物料續漲；要到「原物料接棒最後一波 + 核心 CPI 走弱」時才是空頭轉折，屆時美元指數表現也不會太好（因為又要降息用藥）。

## 影響油價的三大因素（按優先順序）

1. **景氣循環（第一要素）**：人類／企業的實質需求，這是構成油價的根本。
2. **供需**：產油國（沙烏地阿拉伯、俄羅斯等）增產或減產。
3. **美元**：原油以美元計價，原為反向關係（美元購買力強→油價相對弱），但影響最小，排第三。

**頁岩油革命（約 2011–2016）**：美國頁岩油技術突破、開採成本下降、產量暴增，原油存量已超越沙烏地阿拉伯（出口尚未超越），讓美國從石油需求國轉為供給國——這就是 2014 年起油價大跌的供給面主因（不是新聞講的生化武器）。後來**俄羅斯與沙烏地阿拉伯協議減產**，供給減少，油價才又回升。講者用「賣傘」的比喻（大時代第二集）解釋美國介入敘利亞戰爭的真正目的是搶油田市場、打擊背後的俄羅斯。

## 原物料貨幣的操作邏輯

原物料貨幣 = 該國主要出口為某原物料的貨幣，判讀看**兩個因素**：

1. **美元指數 vs 非美貨幣**：基本為反向關係（美元漲、非美跌）。但**並非所有貨幣都成立**——日圓常「走自己的路」，與美元指數不是穩定反向，不能因做多美元就放空日圓。**澳幣、加幣**的反向關係則較明確。
2. **該國出口商品本身的供需／景氣**：出口好則貨幣有價值，出口差則貨幣偏弱。

| 貨幣 | 主要出口原物料 | 連動關係 | 操作時參考 |
|------|----------------|----------|------------|
| **澳幣** | 鐵礦砂（主要出口至中國）| 與美元指數反向 | 中國鐵礦砂進口年增率（中國景氣下滑→年增率掉→輔助放空澳幣的信心）|
| **加幣** | 原油（約佔其 GDP 10%）| 與美元指數反向、**與原油正向**（亦步亦趨、近乎同步）| 原油的景氣循環價格 |

> 操作要訣：即使美元指數該做多、澳幣該放空，也**不能直接憑連動就進場**。要回歸各自的技術面——例如澳幣在月 K 平台頸線撐很久、跌破後「回測不破」才是空點。可用「美元指數」+「該國供需／景氣」兩個面向 double check，再用技術面找「破頸不過頸」的切入點。

## 名詞

- **景氣循環**：經濟在擴張與收縮間的循環，根本驅動是消費需求（GDP 中佔比最大）。
- **GDP**：國內生產毛額，= C（消費）+ I（投資）+ G（政府支出）+ X（出口）− M（進口）；消費佔比最大。
- **利率**：資金借貸成本。降息=寬鬆用藥、升息=停藥／減量。
- **升息 / 降息**：央行調整利率。降息為景氣不好時的寬鬆手段，升息代表景氣好轉的緊縮。
- **QE（量化寬鬆）**：央行買債放錢的「用藥」；本片提到 QE1、QE2、OT（扭轉操作）。
- **縮表 / 縮減購債（taper）**：央行回收先前釋出的資金，屬「停藥」訊號，常先宣布、後實施。
- **CPI（消費者物價指數）**：衡量通膨的指標。
  - **名目（明目）CPI**：含能源與食物，波動大、易被炒作。
  - **核心 CPI**：扣除能源與食物，反映實質需求。名目衝高但核心下滑＝人為炒作的轉折警訊。
- **通膨**：物價上漲；油價是重要推手之一。
- **美元指數**：衡量美元對六種貨幣匯率的指數；講者簡化理解為「**美元的購買力**」。六種貨幣中與投資較相關的是日圓與加幣。
- **非美貨幣**：美元以外貨幣，與美元指數多為反向關係（但日圓例外）。
- **原物料貨幣**：主要出口某原物料的國家貨幣（如澳幣＝鐵礦砂、加幣＝原油）；受美元指數與自身出口供需雙重影響。
- **頁岩油**：美國技術突破、低成本量產的石油，使美國由需求國轉為供給國，是 2014 年油價大跌的供給面主因。
- **OPEC 式減產協議**：俄羅斯與沙烏地阿拉伯協議減產，供給減少推升油價（本片背景）。
- **技術分析名詞**：三角收斂、頸線、下降趨勢線、頭肩底、W 底（講者稱「呂布／多方呂布一號」）、測幅（用型態高度推算滿足點）、過頸不破／回測不破（突破或跌破後回測的進場訊號）、月 K（一根代表一個月）。
- **預期心理**：政策只要「宣布」尚未實施，市場與主力就會依預期提前布局（最易反映在美元指數上）。

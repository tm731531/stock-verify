## 一句話結論

**換倉成本是波段的「起點」與「多空分界」，前一個（或上下一個）換倉成本是波段的「終點」**：換倉後往哪邊表態（奇襲缺口），就推估主力建的是多單或空單；以換倉成本當依據與防守點，從這個換倉成本一路操作到下一個換倉成本附近；上下若無換倉成本可參考，就改用「月選大量區」抓終點。看錯就停損，訊號再出現就再進場——這才叫復盤（覆盤），不是事後諸葛。

## 一、核心觀念：換倉成本怎麼用

### 1. 換倉成本＝波段的多空分界與起點

- 每個月有**換倉日**（轉倉），主力會在換倉日前幾天（偶爾換倉後）開始換倉動作，把部位從當月期轉到連續月（隔月期）。
- **不用急著猜多空，主力會用「表態」告訴你**：換完倉之後，
  - 往上走、跳出成本區（出現**多方缺口／奇襲缺口**）→ 合理推估主力**建倉是多單**（建多單不可能往下走）。
  - 往下走、跌出成本區（出現**空方缺口**）→ 合理推估主力**建倉是空單**。
- **判斷依據就是「洞往哪邊開」**：缺口（洞）往哪邊跳，主力就往那邊表態。
- 期貨換倉時雖然指數被拉高，但**換倉的隔月期貨其實還在那個「框框（成本區）」內，沒有超出**；要等它真正跳離那一坨成本，才算確立方向。

### 2. 換倉成本只決定「方向」，還要找終點

- 換倉成本只決定你**這個月要偏多操作還偏空操作**（決定起點、決定要走多走空），但一段旅程要有起點也要有終點。
- **終點＝上一個（或上下一個）換倉成本**：
  - 跌破換倉成本、出現空方缺口看空 → 往下跑，目標就是**前一個換倉成本**。當月結算，最低最低只能看到前一個換倉成本（多半就在那邊結算）。
  - 突破換倉成本看多 → 目標就是**上一個換倉成本**附近。
- **缺口一跌破（或突破）的當下，就要立刻去找上一個換倉成本在哪裡**，預估它大概會跑到哪，不是等它跑到了才看——這樣才能事先知道「還有沒有肉」、接近時知道「差不多了」。

### 3. 上下沒有換倉成本時：用月選大量區

- 若上方／下方「萬里無雲」（要追溯到 1990 年的高點，根本不可考、找不到資料），就改用**月選擇權的大量區**來規劃終點。注意是**月選不是週選**。
- **缺點：大量區會移動**。起漲時大量區可能在 11000，漲接近時又移到 11100，這時要跟著**微調目標**（本來看桃園，發現大量區移到台北，就改看台北）。
- 因此這種操作是**分批、微調**，不是一單從頭抱到尾。

### 4. 換倉成本的點位怎麼抓（防守點）

- **最粗略、最直覺**的抓法：抓換倉成本附近的**缺口**，用那個缺口當換倉成本的**防守點**。
- 若要更精準抓單一點位，就要深入看籌碼（見第三段「細部抓法」）。

## 三、換倉成本的「細部抓法」與「好壞盤」辨識

老師用**選對象／顏值（清秀、長腿）**比喻挑換倉訊號的品質。

### 1. 怎樣的換倉值得做（好對象）

- **多空單都要有大幅異動**：只有多單或只有空單異動的，比較不看；要看多空單「同時」且「大幅」異動。
- **大幅＝口數要夠大**：至少要超過千口，最好兩三千口以上，**八九千口最理想**。
  - 口數越多，代表主力換倉的**決心**越強；愛換不換、口數零星，表示主力可能還沒決定方向、不敢重壓。
- **連續兩天、且接近「水平換倉」最棒**：兩天低點接近，框框就不會畫得很大，防守點可以畫成「一條線」而不是一個 Range。
- **換完倉緊接著奇襲表態**：乾淨俐落（一個多方奇襲後守住換倉成本就上去），這種「遊物（尤物）非追不可」。

### 2. 怎樣的換倉很難搞（醜對象／人水）

- **口數零星**（一兩千、幾百口、長短不一）→ 主力決心不足，常在成本區「洗刷刷」反覆洗，搞不清方向。
- **長短腳**（兩根低點落差大、不平行）→ 回測時不知道是測哪一隻腳、哪一個成本，Range 太大，是波段操作最煩惱的地方。
- **正幅相（振幅相）、不乾脆、人水盤**：先突破又下來、戴你綠帽，命盤難搞。
- **應對原則**：
  - **不確定就不要做、不要追**，連朋友都不要當，免得信心被醜的磨掉、真遇到正人（好機會）又不敢追。
  - 口數小的建倉，**換倉後多空單可能馬上異動**，要持續觀察多空增減比。
  - 遇到難搞盤就**屈肩短坐（縮小口數、做短）**，等下一個結算再看有沒有「清秀長腿」。

### 3. 多單／空單成本怎麼定點

- 主力邏輯：**做多就是買最低、做空就是空（賣）最高**。
- 所以：
  - 主力做多 → 取**換倉當天（那兩根）的低點**當多單成本（防守點）。
  - 主力做空 → 取**換倉當天的高點**當空單成本。
- 兩根低點若接近，畫一條稍粗的線即可涵蓋；若是長短腳，就**兩個低點都畫出來**，看它去測哪一個。

### 4. 用「流倉口數」精算重心（打破沙鍋版）

想更精準知道「哪一天換得比較多、重心在哪根」，可看籌碼資料：

- 取換倉前那幾天**期貨「所有契約」對「當月（一月）倉」的流倉口數**。
- 用**遠月（全部契約）減掉一月倉**，差額幾乎就是換到二月（連續月）的量（可能含少數三、四月，但大部分是二月）。
- 可用「特法（特定法人，較代表外資）」或直接用「總計（全市場：法人、前五大/十大、前五特/十特全部）」兩者相減。
- 實例算法（1 月）：
  - 1/8 相減約 1 萬多口（已換到二月）。
  - 1/9 變約 1.9 萬 → 比 1/8 **增加約 5000 口**。
  - 1/10 → **增加約 1.3 萬口**。
  - 另一段兩天合計約增加 **2.2 萬口**。
- 結論：哪兩天「增加萬口以上」，就是真正大量換倉的日子，**把那兩天的低點抓出來**當換倉成本。

## 四、進場、停損、停利的操作流程

| 階段 | 做法 |
|------|------|
| **判斷方向** | 換倉後看表態（缺口往哪開）→ 推估主力建多單或空單 |
| **進場** | 順著表態方向，回測換倉成本（防守點／那條低點線）時進場、加碼；來不及追的，回測時更該進場 |
| **停損** | 換倉成本（框框）被反向「收破＋反向奇襲」就停損；做多被跌破、做空被漲回都先停損 |
| **停利** | 跑到下一個換倉成本附近就停利；若用月選大量區，到大量區先停利（以下會死），大量區再被站上/跌破再進場 |

**關於「換倉成本到底有沒有破」的定義（很多人搞混）：**

- 要看**這個換倉成本上的「發球權」是誰**——發球權還在誰手上，就認定換倉成本有沒有破。
- 復盤（覆盤）要**一根一根看**，不能用後面的走勢回頭裝懂。某一根收破紅色框框、又是空襲缺口，當下你會判斷是空單、可以做空——這沒問題；
- 但**隔天若出現「多方奇襲」、發球權又易手**，就是被耍了 → **立刻停損**。不一定要反手做多（因為還沒脫離換倉框），但要先停損、先分手、調適一下，再等好對象（好訊號）出現。
- 看到真正好的對象（多方奇襲缺口＋突破換倉成本）就**手起刀落**進場，後面這一段絕對能補回之前的停損。
- 老師原話：**「換倉成本是一個依據，看錯不對就停損，訊號出來就再進場，這才叫復盤。」**

> 楊家軍（央家軍）特色：**不事後諸葛、都是實戰**。

## 五、選擇權波段選哪一檔

- 上下沒有換倉成本可參考時，用**月選大量區**抓終點與停利／反彈點。
- 大量區是**反彈自救／停利**的關卡：做空的人只能吃到大量區上緣前、做多的人從低點吃到大量區。
- **履約價（不要追控／勿追高）**：跌到月選大量區的履約價附近不要去追空。
- 大量區**會移動**，要尊重它「先到這裡停一停」，但也要留意它可能更高／更低，隨指數移動而微調。

### 實例：1 月 8 日（星期三）盤前實戰紀錄

- 8:41（未開盤）即指出：**月選大量區在 11850**，留意盤中反彈自救。
- 8:48：指出**月選 11700 履約勿追控**，這裡是月選大量區。
- 當天跌到 11700 不能追空；以 11850 會反彈自救規劃：
  - **做空者只能吃到 11700**。
  - **做多者從 11700 吃到 11850，約 150 點**。
- 老師強調這是**盤前發文的實戰、不是事後諸葛**。

## 六、實例：開春行情的完整波段規劃（1 月當月）

老師以當下最近的一次換倉，直接規劃開春行情：

### 1. 抓換倉成本（起點）

- 連續三天換倉，其中 **1/10、1/13 兩天量特別大**（六七千、四千多口，且 1/8→1/9→1/10 流倉口數連續增加萬口以上）。
- 換完倉往上漲、且都是**多一缺口（多方缺口）一次上去** → 推估**這次換倉成本是多單**。
- 因兩隻腳是高低腳（非水平），所以**兩個低點都畫出來**當換倉成本：
  - **11939**（第一點）
  - **12030**
- 兩者位置其實與「前一個換倉成本」差不多 → 之所以著重某一根，是因為它**對過來剛好落在前一個換倉成本附近**。

### 2. 往上看（多單目標）

- 上方無換倉成本可考（要追溯到 1990 年），改用**月選大量區 12300** 當終點。
- **做多波段規劃：11939 → 12300**。
- 提醒：12300 大量區**可能往上移動**，但它還是大量區時要尊重、先到那邊停一停。

### 3. 往下找退路（萬一跌破換倉成本）

- 軍隊打仗不能只求勝利，要先找好退路。
- 換倉成本（約 11939/12030）若跌破，往下看 **11600 大量區**——而 11600 大量區**剛好又是前面的換倉成本**（大量區與當初換倉成本常「不謀而合」，很毛）。

### 4. 過與不及的提醒

- 這些都是理想規劃，會有**過／不及**：
  - **過**比較不可能（這個月結算前再往下跌到 11600 以下機率很低，結算後是另一回事）。
  - **不及**：可能只跌到 11650／11700 就反轉反彈。
- 判斷靠**發球權**：跌到 11650 停住、又出現**多方對稱缺口或多期（多方）缺口** → 心裡要有數，空單可能要先出；若**多期缺口＋阻斷空方缺口**＝**斷勢、球權易手**轉多方勢，空單前散（全散）、反手做多。

### 5. 月 K 指標風險

- 雖然換倉成本沒破、要偏多思考，但**月 K 的 RSI 偏高（已是「小妹」）**，月 K 指標收斂很可怕。
- 開春若往上衝甚至過高（會不會到 12300 不知道），要小心**過高後反轉去收斂月 K**。
- 原因：過完年只剩兩天，**月底是收斂 RSI 最好的時候**（同理週 K 週五常大跌收斂指標——只跌最後一天就能收斂，不會用五天慢慢跌）。
- 操作：**過高之後開始減碼**，先看 12300（除非移動）；若發球權換回空方、出現空方對稱缺口、或跌破換倉成本 → 小心它在收斂月 K RSI，很可能下來測 11600。

## 七、名詞

| 名詞 | 解釋 |
|------|------|
| **換倉成本／轉倉** | 換倉日前後主力把部位從當月期轉到連續月（隔月期）所形成的成本區；本堂作為波段的多空分界、起點與防守點 |
| **當月期／連續月** | 當月期＝最近到期月份；連續月＝隔月（次近月）期貨 |
| **結算** | 期貨／選擇權每月的到期結算；當月最低只能看到前一個換倉成本，常在換倉成本附近結算 |
| **波段單／波段操作** | 以換倉成本到換倉成本（或到月選大量區）為一段的中波段交易 |
| **奇襲** | 開盤跳空攻擊、表態的動作，是一種發球權的發動 |
| **奇襲缺口／多方缺口（多一缺口）／空方（空襲）缺口** | 跳空形成的缺口；洞往上＝多方表態，洞往下＝空方表態 |
| **多方對稱缺口** | 強烈的多方攻擊訊號 |
| **發球權／球權** | 「誰在發動、主導方向」；多方奇襲＝多方握球權，反之亦然 |
| **球權易手／斷勢** | 發球權從一方換到另一方（如收破後隔天反向奇襲），趨勢中斷、要反手或停損 |
| **勢（趨勢）** | 行情的方向性；斷勢即趨勢被破壞 |
| **正幅／振幅（正服相、正幅相）** | 一段行情的波動幅度；本堂波段正幅約 300～500 點 |
| **一滿／兩滿（滿足點）** | 等幅滿足的量度位置，一到兩滿約 100 點 |
| **大量區** | 月選擇權未平倉最集中的履約價區，當作終點／反彈自救／停利關卡；會隨指數移動 |
| **月選／週選** | 月選＝月結算選擇權（本堂抓大量區用月選，非週選） |
| **履約價** | 選擇權的執行價；跌到大量區履約價附近勿追控（勿追高/追空） |
| **特法（特罰）** | 特定法人，較能代表外資籌碼 |
| **流倉口數** | 各契約未平倉口數；遠月減當月可估算換到連續月的量 |
| **復盤（覆盤）** | 一根一根真實重現當下判斷與操作，非事後諸葛 |
| **顏值理論（清秀／長腿／長短腳／人水）** | 用挑對象比喻換倉訊號品質：口數大＝決心、水平換倉＝好防守、長短腳/口數零星＝難搞（人水＝難搞的命盤） |
| **屈肩短坐** | 縮小口數、做短，應對難搞盤的保守做法 |
| **楊家軍／央家軍** | 本課程體系，主打不事後諸葛、實戰教學 |

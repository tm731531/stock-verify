## 一句話結論

這是「鞅子六法」系列的**綜合應用與收尾班**，主軸是把前面學過的軌道、指標三兄弟、當沖三法、滿足點、頸線防守點、籌碼成本「**全部串在一起實戰**」，核心信念只有一句：**不理消息面與陰謀論，只看技術訊號；把進貨成本壓到比主力（外資）更低，並且嚴守防守點，破了就跑。**

## 鞅子六法是哪六法

> **誠實說明**：本堂是「**應用班**」（系列第4堂、也是結業班），講師全程是把各種工具**綜合套用在實盤**上，**並沒有逐條唸出「第一法、第二法……第六法」的標準定義**。下表是依本片實際反覆使用、互相驗證的六大工具所做的整理（與術語校正表對應），可視為「六法」在本片的應用版；正式逐條定義應在系列第1~3堂。

| # | 法（工具） | 用途 | 本片關鍵口訣 |
|---|-----------|------|-------------|
| 1 | **軌道法** | 判斷**趨勢方向**（上升／下降） | 「軌道判斷趨勢」；兩點決定一條線，複製平移即知上下壓力支撐 |
| 2 | **指標法（三兄弟＋小妹）** | 判斷**反轉時機** | 大哥＝**背離**、二哥＝**乖離**、三弟＝**急遲（極值）**、小妹＝**RSI 極值（5／95）** |
| 3 | **當沖三法（三法）** | 沒軌道、沒指標時也能**斷多空** | ①大紅／大黑K過破 ②出大軍（**粗量／量價**） ③**關卡過破**＋回測不破（虛攻） |
| 4 | **滿足點法** | 抓**停利目標** | 把前一段波幅「複製平移」過來；到滿足點先跑 |
| 5 | **頸線／防守點法** | 抓**進場點＝停損點** | 頸線、大量底部就是**勢段防守點**；回測點＝防守點＝停損點 |
| 6 | **籌碼／成本法** | 看**主力建制成本**、估修正力道 | OP 未平倉最大量、外資多單口數、近10日/20日/季的主力平均成本 |

**判斷流程的核心分工**：
- **軌道 → 看趨勢**（現在是上升還是下降）。
- **指標 → 看反轉**（什麼時候轉、轉多少）。
- **籌碼 → 看力道與成本**（修正會修到哪、誰的成本低）。

## 段落一：心法──不看消息面，只看技術訊號

- 技術分析準時大家說「果然準」，磨人時（高低檔盤整）就說「不準、主力在作弊」。講師強調：**主力作弊也會反映在技術指標上，還是有訊號**，我們就靠訊號「望聞問切」。
- **不參與消息面、陰謀論討論**（如「台彩開在台南＝作弊」式聯想）。主力最大的敵人是其他主力，不是散戶；他一定以**自己的建制成本獲利最大化**為前提。
- 講師所有堅持成本與分析點位**以外資為主**（OP 金額、未平倉大量都看外資）。外資也會賠，但很少，且**賠時會有技巧地撤退（逃命波）**。
- 結論：**依訊號進出，不管背後陰謀**。技術分析是「提前預測」，不是事後算命。

## 段落二：軌道的判斷與「微調」

- **下降轉上升**：下跌軌道突破後，第一波高低點兩個低點連線→軌道成形；**複製平移**即可預知上方壓力。
- **為什麼要微調軌道**：原本軌道畫在引線位置，但出現背離受阻時，要把下緣軌道**往上挪一點**；挪上去後會發現「W底頸線、前方關卡受阻」都吻合，反證調整正確。
- **驗證原則**：軌道調整後要**往前看前方有沒有關卡過破／受阻**，吻合才算對。軌道**不是一成不變，要隨時微調**。
- 換軌道要小心：**成交量一放大軌道就會破**，所以**還是要搭配指標**，不能只信軌道。
- 「**被尬突破**」（破軌後馬上反手）這種被迷惑的破軌，**幾年來統計幾乎都會反轉**──「要不然我靠三兄弟怎麼活到現在」。

## 段落三：背離（大哥）的判斷與修正

這是本片講最細的指標重點。

- **背離怎麼算**：指數越拉越高、但指標柱一波比一波低（一次、二次、三次背離）。
- **背離怎麼才算「修正完成」**：
  - **一定要跌破「第一個基準點」以下**才算完全修正。
  - 只要第一個基準點沒破，就算中途回檔、暫時看似沒背離，**再拉上去仍是背離**（趨勢線向上、指標趨勢線向下，攤開就很清楚）。
- **背離＝逆勢單**：有賺到就跑。
- **背離幅度**：通常 **100 點以上**，「絕對是一兩個滿足點以上」；多年交易紀錄「**修正一定超過 100 點**」。
- **操作**：做波段時，確認背離訊號就先把多單出掉（不一定要放空），等它回來打 W 底再接。

## 段落四：要不要留倉？三兄弟說了算

- 軌道中間（無訊號）講師**不給留倉保證**，因為「沒有三兄弟，我真的不知道」。
- **沒有三兄弟訊號 → 一定要留場（留倉）**；有訊號（尤其在處低／處高且 RSI 低於 5）才考慮反手。
- **留倉判斷法（站上30分鐘20MA）**：
  - 看**摩台、台指期、加權**有沒有**站上 30 分鐘 20MA**。
  - **三個裡有兩個站上 → 可以留多**；多頭走勢下若都沒站上，就不要留，也不建議留空。
- 例：上週五雖極接近下軌但**沒有任何指標訊號**（RSI 才 6 點多、沒低於 5），所以不敢保證可留 → **大黑K隔天通常還有餘威**，不去抓不可靠的轉折。

## 段落五：當沖三法可「斷多空」（不只用於當沖）

重點觀念：**三法把日K、週K拿來當「中」（中線）看也成立**。

- **三法組成**：
  1. **大紅／大黑K 過破**（一法）：大量黑K被大量紅K突破，或大量紅K被跌破。
  2. **出大軍（粗量／量價）**（二法）：突破／跌破要有**夠大的量**（如近千億、明顯高於均量）才算數。
  3. **關卡過破＋回測**（三法）：突破後**回測底部不破＝虛攻（續漲）**；回測破了＝**封封滴（要小心、續跌）**。
- **大量K的底部怎麼抓**：
  - **跳空缺口**要算**前一天的收盤價**，不是當天開盤價（它不是從那邊開始漲）。
  - 盡量算**實體K線**，引線、缺口都要還原。
- 應用：就算**沒有軌道、沒有指標**（在外上班只有一張圖），只要找出**最大的那根量**，三法一樣能判斷波段大轉折。
- 口訣延伸：**滿足點＋大量＋三法**互相驗證，就是好的轉折點。

## 段落六：用 OP 未平倉量定軌道區間（4/16 結算實例）

- 看**結算前一天籌碼**：外資多單 **24,000 多口**（偏多），SC（Sell Call）最大量 **9000**、SP（Sell Put）最大量 **8700**。
- **主力（外資）想法**：手上 2 萬多口多單等結算，又 SC9000／SP8700，當天指數約 8900 → **最理想是在 8700~9000 間、且盡量靠 9000 以下結算**，讓選擇權全收、多單獲利最大。
- **拉抬手法**：1點前消耗時間價值，**最後30分鐘開始往上拉**（加權最後30分鐘均價＝結算價），輕鬆拉 50 點 → 台指多賺 50 點。
- **講師操作**：跨市建在 8900，開盤指數一近 8900 就提醒**趕快把跨市平掉**（獲利最大），不要賭它怎麼動。「一開盤就賺到 15→16 日的時間價值，後面點數不要貪。」

### 區間佈單原則

| 原則 | 說明 |
|------|------|
| **盡量包住未平倉最大量** | 包不住也不能差太遠 |
| **看趨勢方向偏** | 趨勢向上 → 區間盡量往上（軌道）靠，要尊重外資多單（會有逃命波） |
| **有頸線／軌道最好** | 那裡是壓力或支撐，籌碼多、不易過 |

- 本例佈 8750~8950：8750＝**頸線＋滿足點**（結算不會跌破頸線）；未平倉最大量在 8700（外資比散戶更怕，往外多抓 50 點）。

## 段落七：滿足點──抓區間，不抓精準點

- **討厭抓精準點數**：頸線常是「一個區間」而非一個點（如 8200 其實是 8260幾）。「一點不差」沒有意義，**知道堅持成本大概在附近就好**。
- **算法**：把前一段波幅（如 8200→8650 約 400 點）**複製平移**到下一段 → 滿足點約 8900 附近（不中亦不遠矣）。
- **抓滿足點的懶人法（複製平移）**：用看盤軟體（如 PTT）畫一條等於前波段長度的線，複製、平移到目前波段起點 → 線的頂端就是滿足點，「**連小學生都會**」。把線貼在電腦前，股價快碰到就賣。
- 抓不到 VT（轉折時間點）時的兩法：①**VT 往上一個滿足點再加碼**；②**SZ 再往上抓 100 點**（如 9100），然後安心去上班，「心裡默念大哥二哥會挺你」。**有錢的 SZ，沒錢的才 BP；買方買月選不要買週選**（週選攤不到、會歸零）。

## 段落八：用未平倉多單口數「估修正力道」

判斷背離會修正到哪（上軌→下軌？→20MA？→60MA？），依據是**外資期貨未平倉多單口數 ＋ OP 金額**。

| 指標 | 偏多門檻 | 力道判讀 |
|------|---------|---------|
| **OP 金額** | **> 2 億** 偏多；< 2 億多空不定；**正負 1 億都不夠** | 金額大＝偏多、回檔小 |
| **外資未平倉多單** | **> 1 萬口** 算多 | 口數越多、回檔修正越少 |

- **關鍵規則**：OP 金額與多單口數**只要有一個偏少**（多單在萬口內、或金額不到2億），**修正幅度就會稍微大一點**。
- 統計可靠度極高：「從 102 年 5 月到現在快一年，密密麻麻全是鐵證」──但**外資不是每次都對，這一次（本片當下）就錯了**，所以仍要對外資籌碼予以尊重、稍微依賴。
- 重要提醒：**沒有天天留倉這種事**。法人也是「靠近有訊號就開始佈單、慢慢加碼、耐心等」，沒人能算到當天佈當天殺。

## 段落九：選股 SOP（股票實戰）

### 1. 基本面
- **EPS（盈利率）盡量連兩季正成長**（通常第三季開始發動）。
- **避開增資股**：股本膨脹會稀釋 EPS、壓低股價；**減資反而不錯**。
- 看財報「賺錢、連兩季賺」就夠，**不必細到考會計師**。

### 2. 籌碼面
- **一定要有大量**：有量才會動，會動才有價差可賺。
- **主力＋法人**：找兩個同步做多很少（找到都已大漲）；**至少一方籌碼持續向上、股價持續向上**即可；兩個對作但股價仍向上 → 可輕輕搶。
- 工具：永豐金，看**近10日／20日／3個月**主力與三大法人的建制成本買在哪。對比「三個月前在賣的、近10日轉買」＝可進；反之＝出貨。

### 3. 技術面
- 找**頸線或大量底部的防守點**；看**所屬類股線型**是否多頭（不會畫軌道就看**站上30分鐘20MA／日K20MA**）。
- **散戶優勢＝靈活**：5張10張說買就買、說撤就撤；主力幾百張撤不動，「我們打游擊戰」。所以**該停損快停損、滿足點到先散**。

### 選股核心信念
> **我們在玩的遊戲：建制成本一定要比主力／法人低。** 回測點幾乎就是主力近期成本，買在回測點＝成本不輸甚至更低，**立於不敗之地**。要買前先把籌碼成本圖調出來比一比，「主力成本比你低就別進場，你做不過他」。

## 段落十：滿足點到先跑 ＋ 暴漲暴跌最愛

- **滿足點到先跑**（落袋為安）：除非是「大量紅K過滿足點、回測滿足點不破又虛攻」才可續抱；**到滿足點又沒大量紅K → 先出**（一定有人下車）。
- 用訊號確認滿足點會不會再漲：**RSI 超過 95（小妹）就會有人下車**。注意門檻是 **95，不是 93、94**（很多人 93、94 就喊小妹不準）。
- **有風吹草動先撤**：有三兄弟、大盤可能跌時，手中持股有獲利或不賠就先撤，避開這一波，等大盤回到下軌＋有訊號再進。
- **最愛暴漲暴跌**（操作期貨/選擇權時）：小幅震盪訊號不易產生，**只有暴漲暴跌才容易出三兄弟（乖離過大、背離、急遲）**。暴跌時別追，要去找**反轉訊號＋軌道下緣有手**的做多買點；這時很多好股票正回測防守點還沒破，正是進場時機。

## 段落十一：防守點＝回測點＝停損點（全片核心反省）

- 開場與結尾呼應：講師發現自己設的**防守點形同虛設**──很多人破了沒跑、私下問「能不能再觀望」。
- **跌破防守點的意義**：股價已跌破主力建制成本，**主力短期沒有意願再往上攻**。對主力（資金商／大股東）來說只有這家公司、長期沒差；**但對散戶是辛苦錢，破了就要跑**。
- **第一時間跌破就停損**，不要想「等它跌到下面有手再上去」──你不知道會不會有手，上面可能又有頸線。要接，等它回到下方支撐、確認有手再接。
- 收盤真跌破才算；只留下影線、收回則續抱。

## 段落十二：個股實例

### 2387（晶圓／電腦周邊類股）
- 連三季盈利率成長；技術面爆量起漲後第一個滿足點、複製平移抓出 12.7 附近、13.5 籌碼糾結處（成本光塔）。
- **近10日成本 14.5、近一季成本 13.5**；軌道頸線畫出來約 13.5 → **回測 13.5 買，成本比主力一季成本還低，立於不敗之地**。
- 月K：15 元有頸線＋W底，下一波滿足點約 15 → 衝上去有難度，到 15 先散。
- **預設異常**：股票（尤其股本小）軌道難畫，要往前看；它在 13.5 纏鬥久＝主力近期成本埋在這 → 敢在 13.5 附近賭，跌破就停損，賠的不多但賭對是一個滿足點。

### 週光電（電腦周邊）
- 近10日成本 38.06、近一季 34.66；回測 34、主力季成本 30.66 → 在回測買仍比主力高一點但合理。
- 滿足點到沒訊號可續抱 → 但出現**週K RSI 背離**（明顯一波低一波）就先下車，等修正背離、回測 34（季線＝60MA≈33.9~34，主力建制成本）有手再進。

### BDI／運輸類股（BTS／BDI 指數）、防守點實例
- 3月初過頸線、回測頸線不過續攻、站上季線（季線≈頸線）→ 推薦；RSI 過高（小妹）＋怪異乖離 → 該等回測。
- 後來 **BDI 跌破頸線、運輸類股走跌**，股票跌破防守點（28、27 多）卻有團員沒出 → **防守點形同虛設**的痛點。跌破防守點＝跌破主力成本、主力無意願短期攻，**跌破關卡會回測（逃命波），回測就出**。
- 月K 已跌破月K頸線（約26）→ RSI 到極值會隨大盤反彈，但別期望太多，**有反彈就趁機跑**。

### 三K互相驗證
- **月K、週K、日K 互相驗證、不謀而合**：60MA、頸線、主力建制成本常落在同一價位（如 33.9~34），交叉確認支撐。看一支股票約 5~10 分鐘即可決定。

## 段落十三：各商品操作策略（結業調整）

> 結業後請各自依工作屬性、個性、資金，**選一個最有把握的商品為主力**（像聯考選類組，理科強就別報第一類組）。

### 波段單
- **OP 買方為主、用月選、離結算至少 3 星期以上**（才熬得過攤平）。
- 以**軌道操作、三兄弟抓轉折**；**破軌先停損、沒破軌續抱**。
- 攤平：上漲趨勢可倍數攤（最多一個滿足點，到兩個＝軌道畫太遠）；**下跌趨勢不建議攤（刀下不要接）**，講師曾攤到三個滿足點、撐近10個交易日才逆轉勝（「哭著笑了」）。

### 當沖單
- **最難的就是當沖**，要大量練習（講師當年每天練、約五天才有手感），別因受挫失去信心。
- **多空心情要會轉換**：例如**價跌量縮到一半**，多頭趨勢隔天易漲 → 該轉做多；**多單上去獲利了結再反手空**。心中要先**模擬一套走勢路徑**，才知道為何同時留多空單（不是賭大小）。
- **驚弓之鳥派 vs 訊號派**：講師習慣**碰到關卡就先平（落袋為安）**，會贏大部分天數、但會 lose 掉一兩百點的大行情；用 5 分鐘過破／30 分鐘 20MA 跌破才平，能吃到大行情、但平常滿足點50的吃不到。**無標準答案，賺到錢就是好方法（賺一塊也是）**。
- 當沖三法實例：9:33 後**大紅K底 8950 被破（一法）＋空方出大軍（二法）＋回測大黑頂 8910 不破續跌（三法）**→ 空方防守點 8910，之後一路貼。
- **乖離（關一）過大收斂的罕見情況**：日K RSI 已近 22（乖離過大，本該收斂反彈），結果迭次加殺竟然「收斂」（關一過大卻沒反彈）→ 策略要立刻修正，最後變成集職（看小妹），盤尾沒跌破 5 → 不具反彈資格。

### OP 賣方（最不用擔心、勝率最高）
- 慢慢防護、做動作都來得及；89 跨市做很早，跌 200 點仍多半賺到。
- **熱試（RSI）接近軌道做、跨市接近軌道中間做、往外抓一排**。
- **賣方常見錯誤（反面教材）**：

| 錯誤 | 正解 |
|------|------|
| BP 時不小心把 SP 頂掉，又馬上 BP＋SP 加回再防護 | 建倉要**建新倉**、別亂頂；疑慮解除就不該再加回 |
| 賺錢就把 SD（跨市）平掉 | **賣方賺的是時間價值不是價差**；指數離履約價越遠越安全，**沒點數（剩五七點）才平** |
| 不確定就亂建倉、亂動 | **不隨意建倉、一建倉不亂動**；不確定先問 |
| 跨市先 SP 再 SC | **一定先 SC 再 SP**（先有上方保護），逆做很危險 |
| 分開建怕保證金 | 資金不夠**同時建組合單**（第一時間保證金最佳化）；想攤震盪點數的高手才分開建 |

- **防護（房屋）要留意倉別**（設成新倉）；保證金一對二要問券商。

### 股票
- **嚴守防守點、比成本**；有三兄弟動向該撤先撤，大盤有訊號要漲再找買點。
- **出大量 → 停利點往上移**：有買有賺者保護獲利；空手者因成本墊高被**嚇阻亂追**（停利38、回測35、滿足40 時就不敢在38買，等於買主力倒給你的貨）。

## 段落十四：講師的自我反省（操作節奏）

- 不能「**頂盤**」（一邊盯盤一邊操作一邊報單）：曾因「先操作再報／先報再操作」兩難，導致「前一分鐘叫買、後一分鐘破」，學員才剛買就破。
- 律師朋友（高勝率）一再告誡謹慎，怕觸法 → 講師改採**盡量提醒訊號（空方/多方三法、防守點、反桌點），但進不進場由學員自己決定**。

## 名詞

| 名詞 | 說明 |

| **鞅子六法** | 本系列教學方法總稱；本片為第4堂「應用班」，綜合套用各法。 |
| **三法（當沖三法）** | ①大紅/大黑K過破 ②出大軍（粗量） ③關卡過破＋回測不破。不只用於當沖，日K/週K當中線也適用。 |
| **三兄弟＋小妹** | 指標家族：大哥＝**背離**、二哥＝**乖離**、三弟＝**急遲（極值）**、小妹＝**RSI極值（低於5或高於95）**。 |
| **背離** | 指數創高、指標柱反而走低；須跌破「第一個基準點」以下才算完全修正；幅度常>100點。 |
| **乖離** | 價格偏離均線過大；RSI 乖離過大（如>20）易收斂反彈，但本片出現「過大卻不反彈」的罕見例。 |
| **急遲／極值** | 指標到達極端值（如 RSI 5／95）的反轉訊號。 |
| **軌道** | 趨勢通道；兩點一線、複製平移得壓力支撐；需隨量微調，破軌＝警訊。 |
| **被尬（迷）軌道** | 被誘騙式的假突破，常隨即反手；統計上幾乎都會反轉。 |
| **滿足點** | 量價測幅目標；以前波幅複製平移取得；到滿足點先跑。 |
| **頸線** | 籌碼密集的壓力/支撐線，常即防守點。 |
| **防守點／勢段防守點／奇襲防守點** | ＝回測點＝停損點；跌破代表跌破主力成本，破了就跑。 |
| **關卡（過關卡）** | 前波高低點、大量K底等阻力；過破後會回測，回測不破＝虛攻。 |
| **虛攻** | 過破關卡後回測底部不破、續走原方向。 |
| **封封滴／滴滴滴** | 回測大量紅K底部被跌破，要小心（轉弱續跌）。 |
| **粗量／量價／出大軍** | 突破跌破要有足夠大的成交量才算數。 |
| **未平倉最大量** | OP 賣方（外資/主力）佈最多口的履約價；定區間、頸線的依據。 |
| **OP 金額** | 選擇權整體部位金額；>2億偏多，正負1億不夠。 |
| **建制成本／主力成本** | 主力/外資進貨平均成本（近10日/20日/季）；散戶要買得比它低。 |
| **逃命波／逃贏波** | 主力（外資）虧損後拉一段讓自己撤退的反彈。 |
| **跨市（跨式）** | 同時 SC＋SP；接近軌道中間做；先 SC 再 SP；資金不足建組合單最佳化保證金。 |
| **SC／SP／BC／BP／SZ／VT** | Sell Call／Sell Put／Buy Call／Buy Put／賣權（往外抓一個滿足點+加碼）／買方轉折進場。 |
| **房屋（防護）／倉別** | 賣方加買的保護單；要留意設成「新倉」。 |
| **30分鐘20MA／日K20MA** | 不會畫軌道時判斷強弱、決定留倉的快速依據（摩台/台指期/加權三取二站上即偏多）。 |
| **驚弓之鳥（落袋為安）** | 碰關卡就先平的操作個性，勝率高但易錯過大行情；與「5分鐘過破/30分鐘20MA才平」相對。 |
| **頂盤** | 一邊盯盤一邊操作一邊報單；講師認為不可行。 |

# 新手教室系列第5堂 - 點到點波段操盤法

> 來源：新手教室系列第5堂 - 點到點波段操盤法.mp4 | 逐字稿：`_逐字稿/新手教室系列第5堂 - 點到點波段操盤法.txt`

## 一句話結論

**點到點波段操盤法**就是先在「地圖」上把**關卡**抓出來當作起點與終點，再依**慣性**（均線、多空成本、驛站理論）規劃路徑，重點不在神預測，而在於擁有一套「**到了就獲利、破了就停損**」的攻防進退邏輯。

---

## 核心概念：位移 vs 路徑長

借用物理運動學的比喻：

| 名詞 | 定義 | 對應操盤 |
| --- | --- | --- |
| **位移** | 只管起點與終點的直線距離 | 點到點波段操盤法要抓的東西 |
| **路徑長** | 指數實際走走停停、來來回回的全程 | 真實行情的曲折過程 |

指數不可能從 5000 點一路直線狂飆到 6000 點，一定是走走停停、又回回。**我們只抓起點與終點，中間怎麼跑不重要**。

而要定義起點與終點，就像在地圖上叫車：你不能只說「從這裡到那裡」，必須明確講出「從台北到台中」。所以**點到點操作最重要的第一件事就是「抓關卡」**——關卡就是地圖上的地名（台北、新竹、台中…）。

---

## 步驟一：抓關卡（定出地名）

沒有關卡就無法規劃路徑。關卡就是台北、新竹、台中等關鍵點位，必須先在圖上標出。

- **盤前**可先把固定的關卡（如缺口）抓出來。
- **盤中反擋必有因，必有關卡**，未必是你盤前抓的，但要趕快把它抓出來。好處是「關卡就那些，沒有很多」。
- 細部關卡要再挑：例如缺口沒來但被某價位擋住，就要當下把該處（如出現呂布的位置）當成新的台北。

---

## 步驟二：看慣性（規劃路徑）

抓到慣性就能規劃路徑、排劇本。三大慣性：

| 慣性 | 內容 |
| --- | --- |
| **均線的慣性** | 主力多單／空單成本線，站上後遠離成本獲利，獲利到一定程度收斂、指數回到均線，再看是否站上或跌破決定方向 |
| **多空成本的慣性** | 指數會沿著主力多空成本上下跑；某一道多空成本收上，就去看下一道多空成本 |
| **驛站理論（缺口慣性）** | 哪個洞（缺口）收上，就往哪個洞去跑；一關一關接力 |

> 開盤初期常先呈現**均線的慣性**；隨後再用多空成本、驛站理論延伸規劃。

### 驛站理論：一關一關看

- 出現多方缺口 → 往上力道啟動 → 收上這個洞，再看下一個洞，路徑就出來了。
- **一定要一關一關看**：新竹沒過，怎麼看台北？台北沒過，怎麼看宜蘭、基隆？「看得再遠沒有用，你看到吃不到」。

---

## 步驟三：攻防進退（起點＝防守點）

點到點操作的真正意涵**不是預測得多準**，而是**有一條攻防進退的路徑**：

- **到了就是獲利**，**不到（破了進場點）就停損**。
- **你的起點規劃好了，它就是你的防守點**。
- **哪裡破了該停損，哪裡沒破就續抱。**

### 「你要不要下車」心法

你坐遊覽車要從台中到台北，結果車子反而往彰化、高雄開，**你會不下車嗎？** 既然會下車，為什麼很多人不停損？

- 最好：在台中上車，看苗頭不對就在台中附近下車（離進場點近）。
- 最差：彰化也一定要下車，不能眼睜睜被載到高雄、屏東。
- **以後遇到看錯砍不下手，只要問自己一句：「你要不要下車？」然後按下去。**

> 停損要點：**防守點不要離進場點太遠**。25點、50點砍不下手，100點、200點更砍不下手。

---

## 步驟四：選對商品與操作週期

依操作週期決定觀察級數（不能週期短卻看週K，或週期長卻看1分K、5分K）。

### 選擇權買方 vs 賣方

| 項目 | 買方 | 賣方（SP） |
| --- | --- | --- |
| 保證金風險 | **無**（最多歸零），可以睡好覺，美股大跌也不干你的事 | 有，與大小台一樣有流倉、被吹腳、強制砍倉風險 |
| 主要風險 | **時間價值**（沒在時間內跑到就歸零） | 保證金、看錯方向 |

> **先談風險，不要先談獲利。**

### 用時間反推商品

從新竹規劃到台北，要先估「跑這段需要多久」：
- 例：日K上 95xx 到 10200 約 700 點，看歷史K線約需半個月 → 用**月選**，且離結算最好還有約一個月時間。
- **半個月的行情不能用週選**：一週沒跑到很可能歸零。保守者甚至用隔月月選。
- 週K級數的驛站理論：絕對不能用週選買方，一定要用月選（行情可能要 2～4 週才到位）。
- 短單（當沖、隔日沖、PM盤沖掉）才可用週選，但防守點一樣要設好。

---

## 進出場原則：進場嚴謹、出場寬鬆

> **求進場成本先好，你怎麼出都會賺。**

- **進場**：成本一定要離關卡（呂布、缺口）很近。例：多方呂布在 9725，進場成本就要貼近 9725。盡量買最低、空最高。
- **出場**：寬鬆一點沒關係，但**一定要出得掉**——「錢沒放進口袋都是假的」。可在出量、衝高時分批出。
- 成本好的附帶好處：**不容易被洗**，且盤中看損益時不會因帳面難看而抱不住。

### 選擇權買方的出場陷阱

- 當天結算的買方很危險：第二次衝高就算指數比剛剛更高，**權利金點數未必更多**（尤其接近尾盤、回更深時）。
- 所以寧願在出量衝高時先低迫出掉，「他咬不到我」，不必為了拼兩倍單而硬抱。

---

## 不要貪：到站就下車

- 點到點操作的及格標準在於**「關卡到了沒」，不是獲利多少**。台北到了，就算只賺一點也要下車。
- 規劃到台北，行情多跑到基隆，那是**下一段**的規劃，不關你的事，不要懊惱少吃。
- 攔順風車心態：人家免費載你台北到苗栗，剩下台中那段自己走路就好，不要貪。
- 接近目標可**分批停利**（到桃園、中壢就開始分批，留一些拼台中）。

---

## 分段吃：用接力跑完長路

「我是200公尺好手，要跑800公尺就分四段跑」——體力／心臟接受度因人而異，路途太長就分段接力。

**兩種接力方式：**

1. **大小台**：在中間關卡（如新竹）過了之後，以新關卡當新防守點再接著吃。
2. **選擇權換檔接力**（12/14 實例）：
   - 先在某關卡落袋為安（先出一趟）。
   - 接力時**換價外一檔**（如從 97 put 換 9650 put），而非原履約價繼續抱。
   - 原因：萬一中間關卡擋住、反勢力道來，**價外一檔反彈時點數縮的幅度遠小於價平／價內**，剛吃到的獲利比較不會吐回去；兩筆加起來獲利更大。

> **接力時防守點要從「新的進場點」重抓**，不能還設在原起點（台北）。新竹進場，防守點就設新竹，新竹過了就看台中。

## 實例彙整

### 當日盤（即時案例）

- **AM盤多方奇襲、PM（連續）盤空方奇襲**，兩邊方向不同也不衝突：
  - 做空 → 依**連續盤**慣性：空襲回測缺口／虛擬黑頂去空（缺口空、虛擬黑頂空都有檔）。
  - 做多 → 依**AM盤**慣性：多襲回測 120分K 60MA，然後續攻。
- **第一筆單**：9:03「多襲回測 120分K 60MA（黃線），多空線不破續抱」，吃到 9595。吻合均線慣性＋關卡過破法。
- **第二筆單**：多襲回測後，到空襲防守點 9616 閃人。
- 關鍵點位：9616、9595、9555、9624。當日因日K出現多方對稱缺口，偏多操作。
- 9624 是當天抓的，但幾天前（12/25）已用**多空成本的慣性**規劃到該道——驗證提前規劃有效。

### 12/12 盤

- 關卡 9734／9725 有多方呂布（多方訊號）。同學規劃 9275 一到兩滿、98履約，路徑點到點一致。
- 該日幾乎沒回、直接上去，要趁衝大量那根把買方出掉，接近兩倍單。

### 12/14 盤

- 跳空破 9818 關卡（當台北），台中在 9687。
- 作者「屁股小」中途分拆：9750 履約附近先出一趟 → 換履約價接力 → 再換價外一檔（9650 put）接力，一路報到 9687。

### 12/20 盤

- 空方奇襲後反彈，缺口 9718 沒來，被 97 攔胡（出現空方呂布）。
- 盤中提醒「線劃粗一點」確認 97 是台北、沒穿，忍住，往新竹（9654）跑。
- 快縮盤，作者選擇在新竹下車即合格，不強求到台中。

## 口數與心態

- **胃口是一天一天養大的**：一開始一口一口慢慢加。
- 口數太大又成本不好，稍微跌破防守點5～10點就受不了、抱不住。
- 不要高估自己的心理素質；長期統計每天振幅多落在**一到兩個滿足點**之間，超過兩滿足點少之又少。
- 用一到兩滿足點的心態執行，勝率高；遇到真的走兩、三滿的盤再接力跑。天天妄想三、四滿足點，等於天天賭趨勢盤，常吃了又吐回去。

---

## 重點整理

1. **第一件事抓關卡**——沒關卡無法規劃路徑。
2. **定出關卡後規劃路徑**——點位不破不出、不到不進，規劃到哪就到哪，不臨時加碼貪心。
3. **規劃範圍看操作週期**——當沖／PM盤約一到兩滿足點正幅；嫌小就用驛站理論＋多空成本慣性放大。
4. **進場嚴謹、出場寬鬆**，但一定要出得掉。
5. **起點即防守點**，看錯砍不下手就問「要不要下車」。
6 **方法人人看得懂**，價值在於提供攻防進退邏輯——不知何時進出，就無法操作。

## 名詞

| 名詞 | 說明 |
| --- | --- |
| **點到點（操作／波段）** | 從一個關鍵點操作到下一個關鍵點，只管起點與終點，不管中間路徑 |
| **位移／路徑長** | 位移＝只看起終點；路徑長＝實際走走停停的全程 |
| **關卡（過破法）** | 地圖上的地名（關鍵點位）；觀察價格到關卡時是續行或反轉的痕跡（煞車轉向） |
| **慣性** | 指數律動的規律，分均線、多空成本、驛站三類 |
| **均線慣性** | 主力成本線站上後遠離成本獲利、收斂回均線，再看站上或跌破定方向 |
| **多空成本慣性** | 指數沿主力多單／空單成本上下跑，一道收上再看下一道 |
| **驛站理論** | 缺口與缺口之間的慣性；哪個洞收上就往哪個洞跑 |
| **缺口（多方／空方）** | 跳空留下的洞，作為路徑的目標點位 |
| **奇襲／奇襲防守點** | 單邊突襲方向訊號（多方奇襲、空方奇襲）；防守點為其關鍵守點（如 9616） |
| **呂布（多方／空方）** | 關卡攔胡反轉的關鍵K棒型態（攻防進退訊號之一） |
| **三法** | 與呂布並列的轉折判讀技法（本片未展開） |
| **多空線** | 判斷多空的成本基準線（「不破續抱」） |
| **虛擬黑頂** | 做空可依循的反壓區（虛擬黑頂空有檔） |
| **滿足點** | 衡量行情幅度的單位；每日振幅多在一到兩個滿足點 |
| **正幅（振幅）** | 當沖一到兩滿足點之間的波動幅度 |
| **履約（價）** | 選擇權的履約價位；換履約價接力＝分段操作技巧 |
| **流倉** | 部位留倉過夜；選擇權不出就是賭流倉 |
| **120分K 60MA** | 120分K圖上的60期均線（黃線），當作均線慣性的「點」 |

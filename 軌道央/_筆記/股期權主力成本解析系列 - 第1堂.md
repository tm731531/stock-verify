# 股期權主力成本解析系列 — 第1堂：用量價找出主力成本（入門基礎）

> 來源：股期權主力成本解析系列 - 第1堂.mp4 | 逐字稿：`_逐字稿/股期權主力成本解析系列 - 第1堂.txt`

---

## 一句話結論

**散戶資訊不對稱，無法看透主力布局，但只要透過「量價」找出主力的成本所在（盧賽／馬陵道），跟主力站在同一陣地、甚至取得成本優勢，就能達到六七成勝率而獲利。**

---

## 一、課程定位與核心觀念

- 這一堂是「主力成本解析系列」的第一堂，屬**入門與基礎觀念**。前半堂用歷史故事建立觀念，後半堂用「數學（看數值、比例）」教判讀，請先有心理準備。
- 講師坦言：主力的真實籌碼布局，散戶其實**看不透**，標題打得「心虛」。但因為我們處在**相對資訊不對稱**的市場，只能從這些籌碼線索去回推。
- **不需要 100% 準確**：只要能摸到六七成的籌碼、有六七成勝率，就足以獲利；不必知道主力真正的動機或全部布局。

### 用兩個歷史故事講「攻其必救、埋伏要害」

| 故事 | 對應觀念 |
|------|---------|
| 《瑯琊榜2》長林王被困寧州，世子救援不直接攻寧州，而是埋伏在必經之路 | 解救的關鍵不在被困處，而在**敵人必經的要害**（盧賽／埋伏點） |
| 孫臏 vs 龐涓：齊國「圍魏救韓」，孫臏不真打魏國，只逼龐涓回師，再於**馬陵道**設伏射殺 | 兵力有限，不能到處設防，要**算準對手必走的那一個關卡**埋伏 |

> 註：逐字稿「孫畢／唐娟」應為**孫臏／龐涓**；「攝服／盧射／爐塞」為講師對**埋伏點／主力成本所在**的代號，本系列統一稱「**盧賽**」或「**馬陵道**」。

- 一般散戶的壞習慣：「**哪裡漲（大紅大黑）就追哪裡**」。但出量通常是**轉折**、都「有鬼」，追進去容易被套。
- 整個系列的目的就是：**把馬陵道、盧賽（主力成本／埋伏點）找出來，然後在那裡耐心等。**

---

## 二、為什麼要找主力成本（四個理由）

1. **跟主力站在同一陣地**：你的成本只要與主力一樣，基本上就立於**不敗之地**。
2. **取得成本優勢才抱得住**：若那裡是主力成本，他一定會守；你具成本優勢，才抱得住、不被洗掉。
3. **耐心等待（用現貨等）**：主力成本常是一個**區域**而非單一根 K。散戶兵力（資金）有限，無法每個點都布，必須**挑一兩個關卡，耐住性子掛單等**。沒成交就沒差，這是一種「**勝率包贏**」的等待。
4. **共敵必救（攻其必救）**：散戶沒有攻擊力，所有人加起來也湊不出一根大量。所謂「救」是**埋伏在主力的要害（防守點）**，讓主力自己去守、去救，順勢搭轎。

> 重點提醒：**股票要比期貨更有耐心。** 期貨指數回測可能幾十分鐘、半小時就到；股票回測常要一兩週、兩三週。用現貨慢慢等，每天掛單也無妨。

## 三、股票看不到「借券成本」，所以用「大量買超」當主力成本

- **期貨**有相對單純的多空成本可推；**股票**其實**查不到主力的放空（借券）成本**。
- 原因：
  - 揭露的**借券資料分不出是外資或內資**。
  - **借券 ≠ 借券賣空**：借券有多種用途，未必拿去放空；只有「**借券賣空**」才確定是在空。
  - **融券餘額**少人在做，當主力指標沒用（頂多當反指標參考）。
- 因此講師的做法：**直接用「大量買超 / 大量賣超」當作股票主力的成本**，不再從借券去找空方成本。

### 兩個衍生觀察

- **借券有效期約半年** → 推測股票常出現「**約 5 個月到半年一次的較大回彈**」（主力半年內一定要發動）。此為推測、非定論。
- **熱錢進來不一定上漲**：借券需付利息成本，熱錢進來未必買股票，可能拿去支付借券利息。**別以為熱錢進來股市就一定漲。**

## 四、判讀方法 SOP（復盤找主力成本）

### 步驟 1：正確的復盤姿勢

- **把後面的走勢全部遮住**，從前面一根一根往後看，**不能從後往前看或對照後面**，才能模擬當下心情。

### 步驟 2：先看財報（篩選，不是保證）

- 選股程式**先用財報篩**。財報好＝像看求職者的**學歷**，是初步篩選。
- 但**財報好不一定會漲**——漲不漲還是要回到「**量價**」、回到「**三法**」、看**主力要不要買**。

### 步驟 3：對照三大法人，找出「主角（誰在操控這檔）」

- 把**外資 / 自營 / 投信**的籌碼曲線與股價（主力）對照，看誰最吻合，找出操盤主角，通常有 1～2 個。

| 法人 | 操作特徵 |
|------|---------|
| **外資** | 要做的東西就是**連續買超**，曲線幾乎與股價一模一樣 |
| **投信** | 偏**短單**，多空多空交替（買了隔兩天又賣），一路墊高，類似講師打法 |

- 主角**未必是三大法人**：還可能是**公司派、中實戶、政府基金**等。這些資料揭露看不到。
- 若**三法成交量遠小於總成交量**（例如三法只有幾百張、總量卻四五千張），代表**主力不在三法之內** → 改看「**籌碼集中度**」。

### 步驟 4：劃出防守線（防守點）並一直留著

- 找**大根的買超 K**、**連續出量的第一根**、**缺口（多方起始缺口 / 多方奇襲缺口 / 空方奇襲缺口）**，把**防守點劃線並永久保留**。
- **沒回測到的線先劃但無意義**，要**往上（或往下）再找有效的那一根**。
- 若該根除了外資，**投信／自營也有量**，威力更強；不能少（量太小不算）。
- 心法：**「現在不回測，不代表以後不回測」** → 線一定要擺著等。

## 五、判讀的關鍵細節

### 1. 看「量」不能只看 K 棒長度，要看數值與比例

- 範例：某根**金額 7 萬多口、1 萬多張**，理論上應是另一根的 7 倍長，但圖上**不可能畫 7 倍（會爆表）**。
- 所以**自營賣超看起來比外資長，未必代表自營是主力**——要去看**實際數字與比例**，別被視覺長度誤導。

### 2. 爆量／出量 = 轉折，常是出貨

- 「**一柱天量（一時天亮）**」般的爆量要特別小心，很可能是**最後出貨量**。
- 講師習慣：漲了一段後爆量，**順勢先出掉再說**。就算後面續漲，也只是**少賺、不會賠**。
- **起始攻擊量 → 攻擊 → 最後出貨量**：是一個完整節奏。賺到價差**先跑**，尤其是爆量之後（否則容易把價差又吐回去）。

### 3. 套牢區「麥芽」與形態

- 漲不上去、套了一堆籌碼的區域會變成**麥芽（黏住、壓著）**。
- **自己劃線**比講一堆形態術語更清楚。M頭、三尊頭等不必鑽研——**三尊頭就是空方呂布一號的放大版**，重點是「**回測壓力一直過不了、一直出大黑**」。

### 4. 大紅底 / 大黑頂的陷阱

| 定義 | 一般意義 | 陷阱 |
|------|---------|------|
| **大紅底** | 防守點（支撐） | **大紅不一定是多**：若衝壓力衝不過，可能是**出貨（空）**，接在大紅底容易失誤 |
| **大黑頂** | 壓力 | **大黑未必是空** |

- 衍生鐵則：**最靠近滿足點的階梯（防守點）不要接**——主力可能已出貨完、不再守，那個階梯會斷。

### 5. 用「三法」過濾籌碼疑慮

- 當籌碼看不清是**出貨量還是供給量**時，用三法（如「大黑之後下一根是否仍買超、是否再出一個大紅」）去過濾、確認。
- **大紅上大黑下 = 呂布**（空方呂布一號 / 多方呂布），**個股也適用**。

### 6. 區間震盪時：先看「發球權」在誰手上

- 多方陣地、空方陣地都守住、來回震盪時，**先別急著多空**，要回歸看**發球權（球權）**：
  - 看 **30 分鐘**圖、**多空線**（在線上或線下）。
  - 看最後出現的呂布是**多呂還是空呂**，其防守點有沒有破。
  - **多呂未破 → 在支撐做多；空呂未破 → 在壓力做空。**
- **若看不出發球權，就不要進場。** 一下出大紅又破、一下出大黑又破 = 雙方搶球權、未分勝負，不做。
- 「**第一次空位置很高，第二次再空容易被穿**」：被穿也沒關係，**精準再反手**即可。

### 7. 「三天法則」判斷缺口是否被攻破

- 缺口是否真被攻破：用**連續三天**觀察。**連三天站上才算站上**；一上一下要再看。同樣可用於壓力突破的確認。

## 六、進階工具：價量分布圖（籌碼分布圖）

- 一般 K 線以**時間**為單位；**價量分布圖**以**股價**為單位，呈現一段期間內**各價位的成交量分布**，可看出籌碼集中在哪裡。
- **大量區（大亮區）**：套牢籌碼最多處，是強壓力／支撐。
- **用法**：搭配**大亮區 + 大紅底**畫出區間，做**高出低進**的價差；細部進出再用**多方奇襲缺口**的防守點。
- **注意**：價量分布圖的防守是一個 **range（區域）不是一個點**，遇到大區間（高架骨）帳面會很煎熬。**建議把該區域（例：85～90）拿回日K圖去找缺口或大量紅K防守線**，較好操作。

### 期貨特性：結算前回大亮區

- 期貨**結算前常會回大亮區（回補）**，前提是當下**離大亮區有一段距離**（約結算前一個月）；若結算前就在大亮區內就不會。
- 跌破時，往下看**當月籌碼**；做波段可看**連續月**籌碼。

## 七、選股、參數與其他實戰提醒

- **選股條件難設**：曾試「外資/投信買超為近半年最大量或次大量」+ 基本面缺口，**成效不佳**。
- **碳值（量能／籌碼力道參數）**：加了碳值選出來的標的**通常已跑一段**（因為買賣盤比例已達起漲水準），考慮**把碳值參數拿掉**再試。
- 比起連續出量，**「顏值（EPS／業績）複合或倍數成長」**的標的比較容易抓，但**發動時間很不一定**（兩個月到半年），需細看。
- **基本面 / 產業面**：講師自己不研究（沒時間、重心不在股票），認為主力最終都反映在**籌碼與量價**上；產業研究有用但效率低。產業面可請助教「**怡怡**」討教。
- **總經題材**可留意：台幣升值（資產／傳產題材）、原物料、季節性（暑假遊戲股）、外資匯入等。
- **籌碼是輔助、不是主角**：看不出主力是誰時，就**回歸三法、回歸成交量**。

### 不看盤的操作法（自動化）

- **進場單 + 停損單都先掛好**：成交後若對就開始賺，跌破防守點就自動停損。
- 人會忐忑，**用程式幫忙**：掛防守點等、停損掛在附近，沒破就沒事，破了就停損。
- **防守點破了就先出**，代表成本找錯或找得不好，重新再找——**不要破了還凹單**。

## 八、實例重點摘要（逐字稿提及的標的）

| 標的 | 重點 |
|------|------|
| **616 系列** | 過高的大根 + 多方起始缺口 → 劃防守線；後段爆超大量 = 最後出貨量，順勢先出 |
| **8039** | 手術式迅攻、挑戰前高；前高「直接跳空過」算仁慈，「過高又跌破／補完缺口又跌破」最賤 |
| **5443** | 三法成交量遠小於總量 → 主力可能不在三法，看籌碼集中度；連續出量第一根劃線；大紅上大黑下＝空方呂布一號 |
| **3034**（看空範例） | 量加最快反應；空方奇襲缺口、回測不過＝空區；開始賣的第一根先劃線；發球權換手（多方派兵、突破空方防守線＝奇襲，需回測奇襲防守點完成三防） |
| **大型權值（大龍）** | 空方大根多、且防守點都很近（如同 5K 出 8000～10000 口、頂部位置接近）＝盧賽附近布兵，多方攻不過要小心，空方已拿回發球權 |
| **怡怡的最愛（投信接棒）** | 外資賣、投信接棒過高 → 後續可改盯投信；連續買超不知劃哪根時，抓**缺口當防守點** |

- 共通做法重複強調（「洗腦式重複」）：**找主角 → 找大根／連續出量第一根／缺口 → 劃防守線 → 拉長耐心等回測 → 量縮回測進場 → 爆量先出**。

## 九、名詞解釋

| 名詞 | 解釋 |
|------|------|
| **主力成本／盧賽／馬陵道** | 主力的成本所在＝散戶該埋伏等待的關鍵點位 |
| **量價** | 成交量與價格，本系列找主力成本的核心依據 |
| **三法 / 三大法人** | 外資、自營、投信；用其籌碼曲線比對找出操盤主角 |
| **中實戶／公司派／政府基金** | 三法之外可能的主力，資料多半看不到 |
| **籌碼集中度** | 籌碼集中程度，當主力不在三法時改看此指標 |
| **大根** | 量特別大的 K 棒，常是主力出手痕跡 |
| **粗量** | 偏大的量，但若過不了關卡（壓力）就不算數 |
| **爆量／出量** | 異常放大的量，常為轉折／出貨訊號 |
| **起始攻擊量 → 最後出貨量** | 一段行情從發動到結束的量能節奏 |
| **缺口（多方起始／多方奇襲／空方奇襲／多方對稱／空襲缺口）** | 跳空形成的價格真空，常為防守點，且「缺口幾乎都會回補」 |
| **防守點／防守線** | 用大根、缺口、連續出量第一根劃出的支撐／壓力線，要長期保留等回測 |
| **奇襲／奇襲防守點** | 開盤跳空式攻擊；回測其防守點以確認 |
| **滿足點** | 行情目標滿足位置；最靠近滿足點的階梯不要接 |
| **發球權／球權（換手／易手）** | 多空主導權；區間震盪時須先判斷在誰手上，看不出就不進場 |
| **多空線** | 判斷多空方向的均線／指標 |
| **呂布（大紅上大黑下）** | 反轉 K 形態，分多方呂布／空方呂布一號，個股亦適用 |
| **大紅底／大黑頂** | 大紅 K 底＝防守點、大黑 K 頂＝壓力；但大紅未必多、大黑未必空 |
| **麥芽** | 漲不上去、套牢籌碼黏住的區域 |
| **碳值** | 量能／籌碼力道的選股參數（加了易選到已跑一段的標的） |
| **顏值（EPS／業績）** | 業績／EPS 成長題材，倍數成長者較易抓但發動時間不定 |
| **價量分布圖（籌碼分布圖）／大亮區** | 以股價為單位的籌碼分布；大亮區＝大量套牢區，搭配大紅底做區間 |
| **三天法則** | 連續三天站上／站不上，判斷缺口或壓力是否真被攻破 |
| **借券 vs 借券賣空** | 借券用途多不一定放空；借券賣空才確定是空 |
| **散戶多空比（散風）** | 散戶多空比例；散戶過多時可拼波段 |

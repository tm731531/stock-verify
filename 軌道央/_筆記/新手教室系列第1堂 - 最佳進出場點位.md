# 新手教室系列第1堂 — 最佳進出場點位

> 來源：新手教室系列第1堂 - 最佳進出場點位.mp4 ｜ 逐字稿：`_逐字稿/新手教室系列第1堂 - 最佳進出場點位.txt`

## 一句話結論

**最佳進出場點位永遠在「關鍵點位」，而不是在中間追價；用「滿足點」估算今天會跑多遠（多數盤是 1～2 個滿足點），在起點/終點的關鍵點位逆勢進場、設好停損、以一個滿足點為第一停利目標，勝率最高。**

---

## 一、核心觀念：用「滿足點」估算當日空間

- 開放漲跌幅 10% 之後，大部分的盤都會「出手」（走出方向），純粹一個滿足點內震盪的雙八盤反而是少數。
- 統計上，一個交易日的高低點落差大多落在 **80～100 點**，也就是**超過一個滿足點、不到兩個滿足點，或剛好兩個滿足點**的機率最高。
- 因此操作的基本假設：**把每天都當作「1～2 個滿足點」來操作**，在兩個滿足點之間反手，勝率會很高。
- 真正的趨勢盤（單邊大跑、三個滿足點以上）屬於少數，不要每天都期待。

| 當日型態 | 出現頻率 | 操作心態 |
|---|---|---|
| 一個滿足點內震盪（雙八盤） | 少數 | 區間來回 |
| 1～2 個滿足點 | **多數** | 抓起點/終點關鍵點位逆勢 |
| 兩個滿足點以上（趨勢盤、空方階梯） | 少數 | 順勢守階梯，心理準備跑兩個滿足點 |

> 重點：因為**關鍵點位盤前就能算出來**，所以盤中只要對照高低點與關鍵點位，就很好抓「車從哪裡發、終點在哪裡」。

---

## 二、如何找最佳進場點

### 1. 只在「關鍵點位」附近進場

- 一天之中，指數真正去摸關鍵點位、或接近關鍵點位的時間，**只有短短幾分鐘**；大部分時間都在關鍵點位與關鍵點位「之間」混。
- 這證明：**最佳出手點位就是這些關鍵點位**，而不是中間。
- 抓關鍵點位的優先順序（沿用衝刺盤抓支撐壓力的方法）：
  1. **缺口（第一優先）**
  2. **奇襲的關卡**（不一定是缺口，與缺口不同）
  3. 日 K 重要均線
  4. 日 K 其他重要關卡

### 2. 用「讀大小」判斷方向，一翻兩瞪眼

- 若搞不懂關鍵點位附近的粗量、大黑大紅等細節，**最簡單就是直接「讀大小」**：
  - 讀對了 → 拼一個滿足點。
  - 讀錯了 → 停損。
- 往前看高低點，數紅 K 與黑 K：**「大隻紅 K 多，還是大隻黑 K 多」**，就能判斷今天空方還是多方軍隊居多（連兒子女兒都看得出來）。空方軍隊居多時，反彈只能視為「短彈」，不是「就此回彈」。

### 3. 關鍵點位可以「賭」（逆勢進場）的幾種訊號

| 訊號 | 說明 |
|---|---|
| **大量關卡受阻** | 衝到關鍵點位量增、收黑留下隱（影）線；下一關還收紅、還大量 → 形成「大黑下、大紅上」 |
| **接近關鍵點位時沒量（沒亮）** | 攻擊力道衰竭 |
| **穿架（較難）** | 關鍵點位被穿上去/穿下去，是較難判斷、最容易嚇人出場的型態 |

- 關鍵點位「不是亂賭」：至少要看到**有程式單設在那邊接**（大量承接）。
- 要小心**呂布二號**：穿下去後又收上來、回測不破，這種最會把人嚇出場。

### 4. 進場像「擋卡車」，要擋第二波

- 在關鍵點位逆勢進場，等於是**擋卡車**（指數往上衝你做空、往下殺你做多）。
- 技巧：**不要擋第一波，擋第二波**。通常「跌→反彈→再下來」時會在打底，去做第二波。

### 5. 最佳點位往往是「你最不敢進場的時候」

- 既然關鍵點位是最佳出手時機，行情不會讓你輕鬆卡位；**轉折往往發生在你最不敢進場的時候**。
- 所以「別人最不敢進場時，你更應該進場」——但前提是**進的是事先算好的關鍵點位**，不是亂進。

## 三、不敢在關鍵點位進場時怎麼辦

- **不要離關鍵點位太遠**就好。例：關鍵點位 9226 擋下、殺一根大黑，從 9226 到大黑這邊只殺了**滿足點的一半**，代表還有可能再殺一半 → 仍可接受的進場區。
- 原則：**「空紅不空黑、買黑不買紅」**。殺一根大黑後不要追殺，等回測、等見紅再進。
- **回測大黑頂**：殺出大黑後通常會有回測、會見紅（出現好幾根紅 K）。
  - 若回測到大黑頂 → **大膽進場**，並以**大黑頂當停損點**。
  - 若沒回測到大黑頂 → 自己看時機去接（沒人能保證回到中間還是大黑頂）。
- 不確定就**分批進場**。

### 為什麼用選擇權（OP）分批

- 小台一口下去，保證金可能就卡死；若被卡死又往上尬，帳面虧損、信心崩潰，往往在最不該出的時候出在最低點。
- **OP 一口了不起一兩千**，三根紅 K 各進一口、共三口才六千，比小台一口便宜，能從容分批 → 這就是用選擇權做逆勢分批的優勢。

## 四、中途進場（追價）的方法

- 一開始可以**先不躺渾水**，等它跑一段、確定今天趨勢向上或向下，再中途進去追。
- 中途追的當下，**一定要算「離兩個滿足點還有多遠」**：
  - 離終點還有把握吃得到的空間 → 進場。
  - 沒把握吃得到 → **等下一段**。
- 中途進場只能看兩件事：**發球權（球權）**、**終點到了沒、還差多少距離**。
- 走「道恩（道 N）」的推法：若兩個滿足點的終點在某關鍵點位（例 9151），就能反推中間反彈會彈到哪裡（往上一個滿足點，例 922 附近、關鍵點位 9206），再回到終點。

> 節奏觀念：你問「現在多還空」時，老師早已開往終點。在 9151 會叫你多、在 9226 會叫你空；**到了 9226 不但不能多、還要反手空**。關鍵是搞清楚**起點與終點**，不要把「剛剛叫你多」的記憶留到已經到終點時。

## 五、停損與停利的設定

### 停損

- 逆勢追空/中途進場時，**務必設停損點**，例如**以大黑頂當停損**。
- 小道窮（小道瓊）每個滿足點約 **100 點**，做逆勢單**停損一定要設好**。
- 關鍵點位讀大小：**讀錯就停損**，乾脆俐落。

### 停利

- 好的點位進場，**通常不會只跑一個滿足點**；但可以先**以「一個滿足點」當第一停利目標**。
- 台指一個滿足點約 **50 點**，已相當可觀。
- **獲利別急著平倉**：在關鍵點位逆勢進場，通常要先克服「靜摩擦力」（在那邊纏一下你會很煎熬、沒信心），好不容易下來別因為一點獲利就跑。
- **分批停利＋反彈再進**：
  1. 跑完一個滿足點 → 先出一些（落袋）。
  2. 反彈到該進場處 → 再進場（因已落袋，最多把剛賺的吐回去）。
  3. 後面那一把可以**抱得更牢**，吃第二個滿足點。

## 六、實例與練習

### 禮拜五台指當沖（逐字稿主例）

- 關鍵點位：**9226（高/擋）**、**9151**、**9206**。
- 9226 是關鍵點位，殺下來一個滿足點約在 927X，也是大量區。
- 往下兩個滿足點是 9126，但**9126 沒有關鍵點位、9151 才有** → 所以不會一次殺到 9126，而是走「道恩」：跑一個滿足點→反彈→再跑一個滿足點，終點落在 **9151**。
- 反推反彈高點：9151 往上一個滿足點 ≈ 922 附近，關鍵點位 9206（當天最高只到 9203，差 3 點），且這區畫得出一條**頸線**（低點有擋、高點有擋）。
- 滿足點附近的關鍵點位約 9183、9180（實際多跌到 917X）。

### 多空方階梯的判讀

- **守住多空方階梯**（沒斷、收破馬上又上）→ 心理準備跑到**兩個滿足點**，順勢守。
- **跌破多空方階梯、且回得比較深／反彈比較多** → 很可能**走一個道恩**。

### 小道窮（小道瓊）範例

- 一個滿足點 = 100 點；常見約 1.5～2 個滿足點（例：低點 17988、高點 18177）。
- 兩個滿足點附近的整數關卡 / 開盤價（18182）、或缺口（收盤 18190、18172、18177）都可當關鍵點位。
- **看量定空間**：量大的那段正幅（振幅）比較大，會偏向兩個滿足點甚至三個滿足點；量小則收斂。
- 操作：到滿足點找關鍵點位**做反向（逆勢）單**勝率高（停損設好）；還沒到兩個滿足點時可**順勢中途追一腳**。

### 波段（軌道）用法

- 一樣畫軌道：**兩點乘一線**，之後照線操作。
- 真正在線上的時間不多，多頭時會「黏」在線邊較久；通常摸一下就下來。
- **軌道（上下緣）一定要進場**，接近軌道進場勝率也很高，因為關卡都已抓住（例 9262、9251、9253，再上 9322、9348）。
- 中間落差大時**不建議用買方**：例如 9251 進 put，漲到 93XX 要攤平，這口 put 可能早已腰斬、帳面難看。
- 較佳做法：關卡突破先試單，真突破就先停損，上去再空、再 P 下去；或用 **SC（賣 call）／下方跨池**等兵種，對付長時間盤整造成的二度、三度被離（把人洗到沒信心撤單後才開始殺）。

### 賭第一個高/低點 vs. 第二個

- **第一個高點或第一個低點最難賭**。
- 若能確定第一個是高點 → 往下約兩個滿足點附近的低點、抓關鍵點位通常抓得到；反之確定第一個是低點亦然。

## 名詞

| 名詞 | 解釋 |
|---|---|
| **滿足點** | 行情一段「應該跑的距離」單位。台指約 50 點、小道窮約 100 點。多數當日盤跑 1～2 個滿足點。 |
| **關鍵點位** | 盤前就能算出的重要支撐壓力，是最佳進出場位置。優先序：缺口 > 奇襲關卡 > 日K均線 > 其他關卡。 |
| **缺口** | 抓關鍵點位的第一優先參考。 |
| **奇襲（的關卡）** | 開盤跳空攻擊所形成的關卡，不一定是缺口，抓關鍵點位的第二優先。 |
| **道恩（道 N）** | 一種走勢路徑：跑一個滿足點→反彈→再跑一個滿足點，常用來推算反彈高/低點與終點。 |
| **多空方階梯** | 順勢推進的階梯型結構。沒斷可守、目標約兩個滿足點；破階梯且回深易轉為道恩。 |
| **大量關卡受阻** | 衝到關鍵點位時量增受阻、留隱線收黑，下一關又大量收紅，形成「大黑下、大紅上」的承接訊號。 |
| **大黑頂 / 大黑下大紅上** | 大黑頂常用作停損點與回測參考；「大黑下、大紅上」是關鍵點位的承接型態。 |
| **穿架** | 關鍵點位被直接穿越，較難判斷、最易嚇人出場。 |
| **呂布二號** | 穿破關鍵點位後又收回、回測不破的型態，最容易把人嚇出場。 |
| **頸線** | 由有擋的高點與低點連成的水平線。 |
| **發球權 / 球權** | 多空哪一方掌握主動，中途進場時的重要參考。 |
| **正幅（振幅）** | 當日波動幅度，受量能影響，量大正幅大。 |
| **空紅不空黑、買黑不買紅** | 進場口訣：做空要在收紅時、不在收黑時；做多要在收黑時、不在收紅時（逆勢承接的紀律）。 |
| **靜摩擦力** | 逆勢進場後行情先「纏一下」才反轉，過程煎熬、易使人提早出場的現象。 |
| **OP / SC / 跨池** | OP＝選擇權（分批成本低）；SC＝賣 Call；跨池＝跨式部位等不同「兵種」對付不同盤勢。 |
| **小道窮** | 小道瓊（小型道瓊指數期貨），一個滿足點約 100 點。 |
| **雙八盤** | 一個滿足點內來回震盪的盤，屬少數。 |

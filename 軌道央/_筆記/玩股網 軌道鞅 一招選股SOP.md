## 一句話結論

用「基本面（盈益率連三季成長/持平且 >3%）＋ 技術面（回測 20MA、多方三法、所屬類股在 20MA 之上）＋ 籌碼面（主力法人軍線向上）」三面向交叉篩選，再到「滿足點等幅停利」，建立一套一分鐘就能跑完、提高勝率的選股 SOP。

---

## 核心觀念

- 我們玩的是一個**機率統計的遊戲**，目的不是「保證賺幾億」或「不敗」，而是把**勝率提高**到能穩定獲利。
- 真正不敗的人不需要設停損；會叫你設停損，正是因為沒有人能 100% 看準（除非你是主力）。
- **重點是學到方法、回家自己驗證**，不是事後諸葛。本片講的個股都是「事前」在社團點名、事後才驗證上漲的。
- 整套方法的母課程是**三法（關卡過破）**：學會三法，股票、期貨、選擇權都通用。本片是濃縮版的「一招選股」。

---

## 選股 SOP（核心三面向）

判定一支股票是否值得進場，從三個面向交叉檢視：

| 面向 | 檢視項目 | 合格條件 |
|------|----------|----------|
| 基本面 | 盈益率 / 營業利益率 | 連續 **三季**成長或持平（略增最佳，跳躍式成長更棒），最好每季 **> 3%** |
| 技術面 | 回測 20MA | 與 20MA 的乖離率 **大於 0、小於 1%**（即將回測、尚未報大量） |
| 技術面 | 多方三法訊號 | 破大黑出大紅 → 回測大紅底（或回測關卡不破），具備多方三訊號 |
| 技術面 | 所屬類股 | 該股所屬「類股指數」要在**日K 20MA 之上**（多頭走勢） |
| 籌碼面 | 主力 / 法人軍線 | 軍線向上（至少持平、不向下）；主力、法人**至少一邊在買** |

### 步驟拆解

1. **基本面篩選（盈益率）**
   - 拋開傳統財報認知，重點看「盈益率／營業利益率」——這是公司**賺錢能力是否穩定**的指標。
   - 看法：用**三季**比較，增減持平就代表賺錢能力穩定；最好略增，有跳躍式成長更好。
   - 主力炒一支股票要砸幾十億，一定先看公司有沒有賺錢能力 → 大漲股票的盈益率幾乎都與股價**正相關**。
   - 央大自設標準：個人推薦給社員的股票，盈益率至少要 **> 3%**；小於 3% 就算穩定也不主動推薦。

2. **技術面切入點（回測 20MA）**
   - 不要等「三線合一、報大量」才追——那時已經漲完了，追不到還風險大。
   - 要找的是「**即將報大量、還沒報大量**」的標的：好的多頭股票回測 20MA 守住後，**一定會再報大量**。
   - 篩選條件：與 **20MA 乖離率 > 0 且 < 1%**。
   - **不建議找回測 60MA 的**：回測 60MA 通常已出現空方三法或報過大黑，主力是否再攻難說，風險較大。

3. **技術面確認（多方三法 + 類股）**
   - 回測 20MA 前，最好已出現多方三訊號：**破大黑、出大紅、回測大紅底（或回測關卡不破）**。
   - 不會三法也沒關係 → 看 K 線像不像一個**「樓梯」（多方階梯走法）**；像樓梯就可進場。
   - **關鍵：一定要「粗量」**——沒有粗量的樓梯不算數。
   - 再多看一個：該股**所屬類股指數**要在日K 20MA 之上。

4. **籌碼面最後 confirm**
   - 看主力、法人**軍線是否向上**（各券商定義不同，5 日或 10 日均線）。
   - 回測 20MA 途中，主力法人**至少要有一邊在買**（通常是法人賣主力買，或主力賣法人買）；兩個都偏空就要小心 20MA 可能跌破。
   - 看不清楚時：把日期拉遠、放大，或畫一條水平線判斷籌碼曲線在線上或線下。
   - 央大觀點：**籌碼已反映在技術面**（技術面就是所有籌碼成本），所以「會看現行（線型）比會看籌碼更重要」，籌碼當輔助確認即可。

5. **進場掛價技巧**
   - 怕掛不到 → 設在比 20MA 多測一些的位置。
   - 不擔心、資金有別處運用 → 直接測 20MA 或比 20MA 少一點（防主力假突破/假跌破洗掉散戶後再進場接）。

6. **停利（滿足點等幅停利）**
   - 用三法找出**歷史滿足點**做**等幅**測量，可停利在最高點附近。
   - **不必等跌破 20MA 或出現大黑**，到滿足點直接停利。

7. **加權軌道圖（位階確認）**
   - 再多加一個條件：看目前指數在加權**軌道圖的位階**。
   - 接近**軌道下緣**時開始做多、找回測 20MA 的標的；接近**軌道上緣**（或出現警戒線、三兄弟乖離背離訊號）時開始減碼出清。
   - 出清時機要**提前**：不能等黑K出來、等它真的反轉才動作（來不及）；在三度背離、還沒反轉時就先做「汰弱留強」。
   - 大盤表現不好時，好股票也會被波及，所以這條件要一併加入。

## 實例驗證

> 央大強調：這些都是「事前在社團點名、事後才驗證上漲」，非事後諸葛。皆以同一 SOP 篩出。

| 標的 | 重點 | 結果 |
|------|------|------|
| 南僑（資訊/食品類股） | 營業利益率持平、灰色大紅有守、灰色 20MA、所屬類股多頭在 20MA 之上、籌碼軍線向上 | 回測 20MA 進場，吃到一段至滿足點 |
| 華豐 | 盈益率自 101 年第 4 季暴增後持平；股價發動常比財報晚一季 | 102 年第 2 季（4月）起漲，回測 20MA 進場可獲利 |
| 橡膠類股標的 | 突破上市橡膠類股日K 20MA、出現「過回測不破」、有多方三法 | 到滿足點停利，已獲利出場 |
| 中光電 | 多方階梯走法、大黑→大紅破大黑、回測有守續攻、財報穩定 | 回測 20MA 進場到滿足點停利（後續類股轉弱下跌，已先出場） |
| 矽品（半導體類股） | 定義絕對大量約 1.5 萬張（該根大紅約 1.6–1.7 萬張）、大紅底有守、類股多頭強 | 進場後又漲一波；到滿足點後法人才開始賣 |
| 淨X（淨棚） | 回測 20MA 後未如預期上漲、反跌破 20MA；但體質佳故續留觀察名單 | **反例（失敗單）**：基本面好者即使跌破防線也較不怕殺到深 |
| 聖火（負值財報標的） | 盈益率為負（-13、-20 → -7，僅「賠比較少」）、籌碼一直在賣 | **不推薦**：賠錢公司即使技術面像、即使漲也賺得不安心 |

**反例的啟示**：
- 賠錢公司「賠比較少」不代表會獲利，籌碼一直賣的股票盡量不要碰。
- 基本面（賺錢能力）好的公司，遇大盤/國際股市回檔時賣壓較輕——外資大戶會**先賣賺錢能力差的**，最後才賣體質好的。所以先選好體質股，跌破防線也較安心，可再找下一道防守點，失守再停損仍來得及。

## 不同操作族群的應用

- **權證玩家**：此 SOP 很適合——回測 20MA 通常沒幾天就反彈，轉折抓得準、利率放大。比「猜底打底」死等一季半年好。
- **上班族 / 資金多者**：可用「營業利益率翻倍」那一招，買進後放著等漲，到籌碼雙雙轉弱、跌破 20MA / 防線 / 到滿足點再賣（缺點是等待時間長、投報率較低）。
- **做空者**：把多方三法整套反過來——到滿足點 + 出現空方三訊號 + 回測大黑底放空。但央大**不太建議做空，盡量做多**。

---

## 操作流程一句話總結

> 用軟體設好條件（盈益率連三季增/持平、回測 20MA 乖離 0~1%、所屬類股在 20MA 上）→ 一鍵跑出名單（約 5 秒）→ 人工確認財報、多方三法/階梯粗量、籌碼軍線 → 接近軌道下緣進場、回測 20MA 掛價 → 滿足點等幅停利 → 接近軌道上緣或出現背離訊號時汰弱留強出清。

## 名詞

- **軌道鞅（軌道央 / 央家軍）**：本課程體系名稱，核心是「量價找主力」，主打三法與軌道戰法。
- **三法（關卡過破）**：母課程，判斷關卡「過 / 破」的訊號系統，股票、期貨、選擇權通用。
- **多方三法 / 多方三訊號**：破大黑、出大紅、回測大紅底（或回測關卡不破）三個多方確認訊號。
- **大紅 / 大黑**：帶量的長紅 K / 長黑 K；「灰色大紅底」指顏色較淡但底部有守的大紅 K。
- **粗量**：明顯放大的成交量，是判斷階梯/訊號是否成立的必要條件。
- **盈益率 / 營業利益率**：衡量公司賺錢能力的指標；央大用其取代傳統財報，看連三季的增減。
- **20MA / 60MA / 120MA**：20 / 60 / 120 日移動平均線（投資人平均成本線）。
- **乖離率（歸離率）**：股價與均線的偏離程度；回測進場找「乖離 0~1%」。
- **回測**：股價漲後回跌測試某條均線或關卡是否守住。
- **過回測不破**：突破關卡後回測該關卡未跌破，續攻訊號。
- **滿足點**：以歷史波段等幅測量出的目標價，作為停利依據（一滿 / 兩滿）。
- **軌道圖（加權軌道）**：以軌道上下緣判斷指數位階——下緣偏買、上緣偏賣。
- **三兄弟訊號**：乖離、背離等可能反轉的提醒訊號（如「三度背離」代表將反轉）。
- **軍線（籌碼均線）**：主力 / 法人籌碼的移動平均線，向上代表持續買進。
- **主力 / 法人**：永豐金等券商定義的前十大或前十五大買賣方；用以判斷進出貨。
- **頸線**：一條重要的成本 / 支撐線，作用近似 120MA。
- **汰弱留強**：減碼時優先出清表現弱的持股、保留強勢股。
- **權證**：以小博大的衍生性商品，漲跌利率放大但需精準抓轉折。
- **空氣單**：不實際下單、僅紙上模擬，用來對照老師盤勢文驗證自己判斷。
- **盤勢文（盤式文）**：社團每晚發布的隔日大盤 / 台指期走勢與點位預判。

## 🔴 最終裁決(別重做回測)
**4 引擎~60 配置 + 接子站法,全部無 robust alpha:**
- 第一根突破、選擇性進場 v1/v2/v3、頸線系統 → 全負或脆弱;唯一「動量版」+2690點但單月佔59%不可信。
- **接子站法(四線確認,最後一個全機械候選)**:修完 bug 的當沖忠實版全年僅+866/+829點,**jackknife 拿掉最賺單月(2026-01)即轉負**、正月數僅6-7/13 → 靠單月=雜訊。
- **A2 硬證據**:孤立「大量」1分K 之後同向率 46~48%(<50%)= 擲銅板。老師用的同一個訊號,機械照抄是隨機。
- ⚠️ 曾出現的假象:接子站法「+7478」是「留倉吃隔夜gap」的多頭beta(BUG-2),修成當沖後多單從+11786縮到+2141。**驗證教訓:先驗算法+驗資料再下結論,對抗式審查找到3個bug。**
- **原因**:edge 在「打在哪個關卡 / 觸架vs穿架 / 起始攻擊vs出貨 / 球權×勢 / 軌道有沒有守」的人眼判讀 + 風控紀律,不是進場公式。

## ✅ 已確認的體系核心(多堂互相印證,詳見梳理檔)
- **兩大主軸 = 關卡 + 發球權**。各級數是三法換名:日K=奇襲缺口 / 30分=三法(大紅底大黑頂) / 5K=階梯 / 1分=呂布。**三法=呂布=奇襲=八球拳**同一套(關卡過破+量,看量不看色)。
- **鞅子六法 = 當沖三法(3) + 波段三法(4訊號:軌道+背離+乖離+極值)**;指標另開非六法。
- **兄妹家族**:大哥=軌道、二哥=背離、三弟=乖離、小妹=極值(RSI3);**三兄弟=大哥+二哥+三弟(小妹不算)**。
- **八球拳**=大量關卡受阻+大量過了不破。**NBA理論**(級數互斥)老師後來升級成「考試比喻」(小考1分/段考30分/模擬考日K/聯考週K,威力vs頻率反比)。
- **一滿=50點**(比例化;非早期錯的25)。**大量門檻分級**:1分K=1000口、30分K=2萬口、3000口=趨勢盤(§17驗證=前1%,合理)。
- **大小流氓=30分20MA + 60分20MA**;**AVL**=Σ(收盤×量)/Σ量(1分reset/5K不reset);**多空成本=大量K開盤價(定樁固定成本)≠AVL**。
- **觸架=呂布一號**(影線碰守住)/**穿架=呂布二號**(實體穿破看回不回);呂布兩腳=第一腳訊號→掛第二腳(-20/+100)。
- **軌道指標=手繪趨勢通道**(過高破低+粗量,斜率與量成正比);**道N=道恩=N字**(兩段式,1:1測幅,分鐘級特別準)。
- **球權(對稱缺口)≠勢(奇襲缺口)**,勢是天花板。**制勝三要素**:技術+操作+資金各⅓,操作>技術。
- **選擇權**:買方用近月月選(周選只當賣方,除非不留倉);勒式=區間邊緣/跨式=衝關卡上方建;防護單=VC;免盯盤兩套(買方樂透+100/-20、賣方SC往外100)。
- **盤前劇本規劃11步SOP**(形態+量價+頸線+測幅+對稱缺口)。

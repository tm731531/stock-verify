## 1. 核心哲學(幼幼班第一堂)

- **不信基本面,只信「有沒有主力在買」。** 「這間公司股價會不會漲,重點在於主力有沒有買嘛」;用 GameStop 反證(財報爛照樣炒 +1200%)。基本面只有「篩選」作用(被炒的不會太差)。
- **央家軍唯一核心 = 量價。**「我從量價去找這檔股票的主力有沒有介入、成本在哪裡,然後擬定攻防進退。」
- **兩種停損(李佛摩):** 價格停損(看錯方向)+ 時間停損(方向對但遲遲不到、卡時間價值)。
- **風險分兩類商品:** 保證金商品(期貨/選擇權賣方)=租來的車,系統性風險虧損無限;股票/選擇權買方=自己的車,虧損有限(買方最多賠權利金)。
- **選商品兩前提:** 流動性(成交量要夠)+ 操作週期(級數=比例尺,看短用小級數、看長用大級數)。

## 1.5 制勝關鍵三要素(頂層框架,老師自承的重心修正)

老師明講「我這一年犯了一個錯,太著重技術」。**制勝 = 三要素各佔 1/3:**
1. **技術分析(1/3)** —— 只有兩套工具:**三法**(看多空消長)+ **軌道指標**(看趨勢轉折)。是門檻,但「學了兵法不一定會打仗」。
2. **操作策略(1/3,> 技術分析)** —— 派探子摸清這座城(易守難攻/守將是外資or自營/地形),選兵種(BP/BC/SC/SP/大小台/跨式/周選)+ 攻防進退。
3. **資金控管(1/3,決定長期能否賺)** —— 第一筆1成/加碼2成/**最多5成**;資金分10等分;**固定口數**(每次下一樣,別忽大忽小);勝率七成+固定下注=長期必賺。

**紀律(本框架反覆強調):** 見好就收/達標就撤、去頭結尾(進場抓遠、出場截短)、先想退路再進場、「怎麼來的怎麼去」(別想一次扳回)。
⚠️ **「兩敗收手」的張力**:三法奧義有老師個人「兩敗我就不玩」;但本篇**批評**學員「賠兩筆就縮手→踏空七連勝」。判讀:兩敗收手=老師選擇性盤感下的當日冷卻,**不是鐵則**;新手更該「勝率夠就固定下、別因兩敗失去信心」。

## 2. 統一邏輯:三法 = 呂布 = 奇襲,同一套東西(幼幼班第四堂)

整個系統是**同一套邏輯在三個級數的化身**:

| 級數 | 方法名 | 出量/表態訊號 | 防守點(扎營地) |
|---|---|---|---|
| 日K | 奇襲缺口(發球權與勢) | 奇襲(跳空) | 奇襲防守點(奇襲那根收盤價) |
| 30分K | 三法(截止戰法) | 大紅 / 大黑(出量) | 大紅底 / 大黑頂(開收盤畫線) |
| 5分K | 多空階梯(其實也是三法) | 大量 | 階梯(5分K大紅底/黑頂) |
| 1分K | 呂布 | 粗量打在關卡 | 呂布關卡 |

> 來源:策略速成班前言「關卡和發球權」——「整個體系兩大主軸=**關卡 + 發球權**;各級數其實都是三法,只是不同級數換名字」。
> **⭐ 級數訊號互斥時:NBA理論 + 顏值理論(以日K為主,日K影響力最大)。**

**⭐ NBA理論(第四批解鎖,來源:新手第3堂主力多空成本的慣性):**
籃球比喻——湖人隊=空方、馬刺隊=多方。**30分K成本 = 整場比賽勝負(定方向)；5分K成本 = 各節(節內震盪)。** 一隊整場佔優勢 ≠ 每一節都贏(可能第一節輸、二三四節贏)。對應操作:**大級數定方向、小級數管中間震盪**;30K多方成本還沒被打、但被 5K 成本提前擋住 → 當沖先出別死守(少賺不算賠),或分批(10口先出7-8口、留2-3口拚30K)。這就是「四級數發球權訊號互斥」的解法骨幹。

**⭐ 八球拳(第四批解鎖,同來源):**
老師明說「八球拳就是這個——**大量關卡受阻 + 大量過了不破**」:
- **大量關卡受阻** = 派大軍攻城,連門口都摸不到/摸到被擋下(大紅衝上馬上大黑打下 = 阻力掛單在那)。
- **大量過了不破** = 突破後回測不破(回射、突破續攻)。
→ 八球拳本質就是「關卡過破法 + 量」的招式化命名,跟三法/呂布同源。

**三國行軍比喻(統一判斷三步驟):**
1. **有沒有表態** = 有沒有粗量/奇襲(出大軍 = 攻擊意願)。
2. **攻擊延續** = 扎營地往前推(新階梯 / 新奇襲)。
3. **斷勢** = 最後扎營地被破。

⚠️ **關鍵但常被忽略**:防守點被破「不一定」逆轉 —— 必須**對方也出量**才算換勢;否則可能只是主力獲利了結撤退(吃了200~300點走人),不是空方攻擊。

**懶人速成版:** 站上多空梯做多、跌破紅黑線做空。但 5分K 梯太小易被洗,要搭滿足點看。

## 3. 主力成本地圖(幼幼班第三堂)

主力成本 = 系統的座標系,分兩大類:

**(A) 固定成本(死關卡,不會動):** 換倉成本、缺口、奇襲防守點。
**(B) 變動成本(隨指數移動):** 均線、AVL(加權成本線)。

各成本的精確定義:

- **大流氓 / 小流氓:** 小流氓 = 30分K 的 20MA;大流氓 = 60分K 的 20MA(因 60K20MA = 30K40MA,實作直接在 30分K 畫 20MA 藍線、40MA 紅線)。用法 = **長線保護短線**:大流氓不破,即使跌破小流氓也不能看空;小流氓破、離大流氓有距離 → 先短空到大流氓,到大流氓再反手做多。
- **AVL / 公道伯:** 加權平均成本線(收盤價×成交量加權,本質 WMA,刻意改名「不讓別人知道我們加權的標的」)。公道伯 = 當月期的 AVL,自己用 15分K 看。**最重視台積電股期的 AVL**(外資操控台指用它);沒股期的股票不要做。
  - **精確算法(主力成本解析第2堂):** AVL = Σ(每根收盤價 × 該根成交量) ÷ Σ成交量。**1分K 連續 AVL 每天開盤 reset**;**5分K 不 reset**(從大月合約起跑第一根算到結算)→ 5K AVL 當「趨勢延續多空線」。**站上 AVL 做多、跌破放空。** 每檔股票股本不同、有效 AVL 級數不同 → 切級數試,「延續多頭只要測到就打、空頭反彈過不了」那個級數的 AVL 才對(用關卡過破法驗)。
- **OP 主力成本(SC/SP)算法(主力成本解析第2堂):** 契約金額(千元)× 1000 ÷ 口數 ÷ **50**(選擇權1點=50元)= 點數;**SC 點數「加」履約價、SP 用履約價「減」點數** = 外資 SC/SP 成本。多重履約價取接近中間的、用 1~2 滿足點範圍框。
- **大紅底 / 大黑頂:** 三法的大量,定義 = **K線的開收盤價**畫線。換級數換名稱但同理:5分K 叫階梯、30分K 叫多空成本、日K 叫奇襲。
- **外資多空「單」成本:** 盤後流暢**空單增 3000 口以上** → 當天K棒**高點** = 空單成本(壓力);多單增 3000 口 → 當天**低點** = 多單成本(支撐)。換倉前後雙邊齊變要忽略,回歸換倉成本。
- **回測機制(過而不破):** 主力成本被突破後,主力把價壓回成本(最不傷)停損/平倉再反手 → 所以會回測;回測不破才是真突破。

**判主力成本看影線、畫關卡線取實體** —— 這是「丟影線」推測被推翻的關鍵:
- 紅K下影線端點 = 阻力(主力)買的成本;黑K上影線端點 = 阻力空的成本。
- 但大紅底/大黑頂這種「畫給自己看的關卡線」取開收盤價。

## 4. 三個級數的實際打法

> **道恩 = Down(第三批新手最佳進出場堂定義)**:價格的「兩段式走法」——走一個滿足點(50點)→ 反彈 → 再走一個滿足點。用來預期一段方向走完會分兩滿出腳,不是一口氣到底。(Tom 原說沒聽過這詞,此為現有定義。)

### 4.1 日K — 發球權與勢(奇襲缺口)
- **奇襲 = 跳空。** 奇襲缺口 = 奇襲那根的**開盤價**(洞,判多空的眼睛);**奇襲防守點 = 奇襲那根的收盤價**(扎營處)。兩者可能差 30~50 點,要分批。
- **進場 = 防守點,進場點破了就停損,沒破就續爆。** 越接近奇襲防守點進場越好。
- **四種題型:**(1)送分題:回測防守點不破續攻;(2)只回測中間整數關卡(如10700)就走;(3)假突破(失守又收回再攻,不建議凹);(4)直接破防(下影線超過一個滿足點)→ 必停損。
- **可重複進場**:破防先閃,收回去可以再進(牴觸「每天一筆」)。
- **對稱缺口** = 阻斷對方奇襲而生,屬「勢」框架不是進場點。

### 4.2 30分K — 三法(大紅底/大黑頂)
出大紅 → 回測大紅底(多方成本)做多;出大黑 → 回測大黑頂做空。底/頂 = 開收盤畫線當關卡。

**三法進場精度(三法伏魔篇=心魔篇 補充):**
- **回測大紅底要看「離滿足點遠近」**:靠近滿足點的大紅底**容易破**(到滿足點會反轉),別接;還不到滿足點的才接。這解釋「為什麼有時回測大紅底就漲、有時就破」。
- **接近/突破滿足點不要追**,多看幾根,尤其當天動能不同步時。
- **起始攻擊量 vs 最後出貨量**是核心過濾:剛漲沒多久+關卡有守+量續放=起始攻擊(可追);跑完一段、那根特別長=出貨量(追了全吐回)。
- **離場紀律:不二過/不三過** —— 當天防守(五分階梯)失守一次(不二過)或兩次(不三過)就離場,離場只看防守點破沒破、不看這單賺賠。
- **方法邊界**:三法/這套只覆蓋約**七八成盤**;趨勢盤(動能不同步卻狂跑兩三滿)是它會漏的兩三成,「頂多沒賺到」不至於賠。

### 4.3 1分K — 呂布 + 第一根開盤突破法
- **呂布 = 主力大量(粗量)的埋伏 = 預掛單關卡**(三法奧義):「主力一下去一定都是一千口…從量價觀察主力進場的點位就叫埋伏」。不管紅黑,只看**粗量 + 過不去的關卡 + 回測守住**。分多方呂布/空方呂布(看量打在哪)。第一隻腳/第二隻腳:把進場掛在第二隻腳。
- **回射(回測)的原理**(三法奧義):主力 1000 口砸出一根還沒買完,回射時讓當時沒成交的口數再成交 → 所以進場點=回射點=跟著主力一起進。**買黑不買紅、空紅不空黑**(回射的那根是反向色)。
- **⭐ 觸架成交 vs 穿架成交(關卡型態判讀;「穿架」拼法已由新手最佳進出場堂 L447/L480 確認,架=關卡):**
  - **觸架成交 = 呂布一號**:價格只用**影線**碰關卡、實體收回正確側(大紅上大黑下、守住)→ 易判、清楚 = 順勢進場。
  - **穿架成交 = 呂布二號**:被**實體穿破**關卡(「穿下去然後收上來」),**會讓人家嚇出場** → 較難,要再判:**回射不破=可接(但難)/真破=閃**。⚠️ 不是「一穿就失效」,而是穿破後看回不回得來。
  - 呂布一號/二號是**兩種型態**,跟「第一隻腳/第二隻腳」(進場掛第二腳)是**不同概念**。
- **⭐ 第一/二隻腳(第四批部分解鎖):**
  - **進場時序確認**(videoplayback 免盯盤堂 行932-939):「**呂布的第一隻腳出來了,我把進場掛在第二隻腳**,一樣往下抓20點、往上抓100點」→ 第一腳是訊號、進場單掛在第二腳,停損20/停利100(當沖 5:1)。
  - **呂布二號的觸發組合**(換倉成本補充堂):**跑完兩滿 + 出量 + 穿頭後回測不破 + 阻斷空梯 + 站上多梯** → 逆勢進場訊號。
  - ❌ **仍缺**:兩隻腳各自的「精確 K 棒型態判定」(哪根算第一腳、哪根算第二腳),目前只有時序與停損停利,沒有 K 棒定義。
  - 呂布一號定義補充(大紅大黑的迷思堂):「**粗量關卡不破 = 呂布一號**」。
  - 判別靠盤感:「看久了你就會知道那個是不是破」「小破一兩點但它就是不下去=有問題(=守住)」。容錯:破一兩點看實體還是影線、那根有沒有大量,別計較一兩點。
- **時間紀律:10 點後不要亂做**(「10點過後沒亮不好判斷,不要下大口數」);**滿足點不要追**(跑完一滿的大量=出貨);**兩敗就收手**(老師自訂「兩敗我就不玩」);**見好就收**(看到關卡/光塔就撤,別貪)。

### 4.4 頸線操作 — 一線判多空(獨立的「一招」系統,最可機械化)
這是另一個軸,**不是** AVL/公道伯(成本線)也不是大小流氓(均線),而是**手畫的水平歷史壓力支撐**。
- **頸線定義**:**過前高 → 回測不破 → 續攻**(關前受阻 / 破前低反彈不過 亦然);兩點成一線。不是教科書的斜頸線,只用**橫的**。
- **級數**:指數用 **120分K**(歷史K棒夠多才能確認關卡守過幾次)、股票用 **60分K**;畫準時下到 **5分/15分K** 看歷史那天擋過幾次。大股本股(台積電/鴻海)會「黏」頸線、過破不明 → 改用日K/週K。
- **判多空**:接近上方壓力頸線→做空,接近下方支撐頸線→做多。觸發=**過→回測不破→續攻**,且**必須大量(大軍)攻破**才算數,小量假突破不接(紅K=多方大軍/綠K=空方大軍,看顏色量判戰場)。
- **進出場**:進場=回測頸線(設價等、**不追價**,可在頸線±3~5點掛確保成交);**進場點=停損點**(頸線兩邊破就砍,≤10點);**停利=下一條頸線**(等距測幅內建,台指≈50點/小道瓊100~150點);取八九成落袋留一點。
- **頸線可微調 ≤10點**(畫粗一點涵蓋);要調超過10點代表畫錯。
- **留倉**:台指期先不留倉(跳空風險);股票可留;海期近24h但**必設停損單**才能安心睡。
- **為什麼值得記**:規則最乾淨、概念上最接近可回測(水平S/R + 回測+量確認 + 固定R:R)。**但已回測(2026-06-27):機械化還是負期望**(見第14節)—— 演算法 swing pivot ≠ 老師用判斷挑的「跨月被擋多次的兵家必爭之地」,回測進場在關卡是修羅場,缺人工讀盤(大量攻破+位置+觸架vs穿架)就是擲銅板倒貼成本。**結論:連最乾淨的頸線都不能自動化,坐實軌道鞅是人工讀盤框架。**
- **起始攻擊量 vs 最後出貨量(最關鍵):** 剛開始攻擊的粗量可進、勝率高;**跑完滿足點的階梯是出貨量,追了被尬。** 常見錯誤:剛攻擊不敢接,跑完兩滿才接最後一個階梯。
- **第一根開盤高低點突破法(講師明說是「輔助」不是主方法):**
  - 開盤第一根 **1分K** 畫出高低點區間。
  - 突破要**收定**(收破才算,不是觸價):過高不破低 → 偏多;破低不過高 → 偏空。
  - 停損 = 對側(做多守低點、做空守高點)。
  - 停利 = 滿足點(50點),不是固定 +50 這個寫法是別堂的數字。
  - 講師原話:「搭配原來的方法為主,這個是輔助觀察」「會困擾判斷就不要用」。

## 5. 球權 vs 勢(操作矩陣)

**球權(發球權)= 當下短線方向主控** —— 由**對稱缺口**決定(多方對稱缺口 → 球權在多方)。
**勢 = 趨勢** —— 由**奇襲缺口**是否被阻斷決定。
**兩者是兩回事,且勢是硬天花板:**

- 勢沒斷時,即使球權短線回到多方,**做多只能做到「勢斷防守點」之前**,不能整路追。
- 要等多方對稱缺口**阻斷空方勢**,才能放手做多到「球權再易手」為止。
- **顏值理論:日K球權 > 30分K球權**(臉蛋 vs 個性,臉蛋最重要)。
- 操作矩陣:球權多但空方勢 → 短多長空;球權空但多方勢 → 短空長多;兩邊都無球權 → 空手等發球。
- 調倉:勢未斷但球權易手 → 多單先減不全出;回測缺口不破 → 加碼;缺口被破 → 全出。

## 6. 選擇權商品操作

### 6.1 買方
- **交往理論(招牌比喻):** 時間價值=虛的(還沒發生,交女友/結婚/生小孩的賭注),內涵值=實的(已發生)。價外=單身幻想、價內=已有女友。周選結算當天勝率 = 「五天內必須交女友結婚生小孩」。
- **商品選擇:** 當沖用**周選**(gamma 大);波段用**月選且價內**(有內涵值、delta 近 1:1、安全不被追繳)。
- **履約價:** 平常當沖選價平附近、權利金帶 **70~90**;**周選結算當天**才選 30 幾的價外。**不要買架外**(波動率不如預期,賺了指數賠了權利金)。
- **挑履約價不用算 Delta/Gamma**:直接看價格,兩個履約價的價差有沒有 20 點,有就選。
- **方向鐵則:** 要 BC(買買權)一定是**回測買**(≤關卡);要 BP(買賣權)一定是**突破買**。永遠別在權利金膨脹時去追。
- **翻倍單:** 要 double,當下進場後指數要漲約 **200 點(≈4滿)**;越快結算越容易翻(靠 gamma),慢爬會被時間價值吃掉。
- **接力加碼:** 換履約價接、**接黑不接紅**(做多接黑、做空接紅);換**架外**接(delta 沒那麼敏感,苗頭不對可閃還保住前段獲利),不換原價位(選擇權非線性,跌回原位點數可能還是賠)。
- **時間價值衰減:** 周選一天消失約 8~10 權利金點(換算台指約16點);月選前兩週慢、**第三週開始快**。

### 6.2 賣方
- **收膨脹權利金:** 大紅大黑時 Call/Put 供需失衡、權利金膨脹,賣方去收那膨脹;就算指數不再衝,開始盤整權利金回歸正常你就賺。
- **依軌道建倉**(支撐壓力進場,收的權利金點數高);但**別太貼軌道**(軌道沒破反市力道強)。壓力做 SC 優於做 BP(盤整 BP 還是賠,SC 不往上衝都賺)。
- **必鎖防護(價差單):** 價外防護(SC96+BC97,防小幅假突破)/ 價內防護(SC96+BC95,已確定突破很多、追虧損速度)。價差單 = 獲利有限風險有限,鎖死。建倉順序**先補防護 VP 再建 SP**。
- **一組價差賺 20 點以上才及格**;周選收時間價值有利(衰減快)但必須短單。
- **區間突破就砍,不能凹**:「再痛還是要砍」。
- 收的點數 > 付出 → 要繳保證金;付出 > 收的 → 只付權利金不用保證金。
- **周選統計:約七成結算落在前收 ±350 點內。**

## 7. 換倉(換倉後勢與球權)

- **何時換:** 不是死在結算日,前後一兩天都可能,要細看當月怎麼搞。
- **抓換倉成本(精準法):** 找**多空單同時大增**那幾天(主力佈局遠月倉),那天的低點 = 多單建倉成本。粗略法:換倉日K棒重疊處推估(RAF)。
- **換倉造成的跳空 = 「空幫勢息」假缺口**,不是真勢息(除權息最明顯),只當關卡;**換倉成本不破才能說這個月做多**。
- **方向判讀用當月期、不要用連續月:** 連續月的空幫換倉缺口會讓你「很晚才出手、吃不到肉」。實例:連續月斷勢752、當月期691,用當月期當天幾乎都吃得到。
- 等兩邊訊號同步、換倉成本守住再往上攻 → 才換回連續月看。
- **波段用換倉成本控賠:** 收上換倉成本做多/跌破停損,跌破做空/收上停損;AM 盤可能洗 10 次賠約 200 點,但咬住一波(1500點)賺賠比可達 75:1。
- **抓換倉成本精準法(第四堂):** ①只看**多空單同時大增**那幾天(門檻 ≥千口、最好八九千口~萬口,口數越多決心越大);做多抓**當天低點**/做空抓**當天高點**當成本;粗略法=框住缺口當防守點。②精準法=**全部契約留倉 − 當月倉 ≈ 次月(換倉)倉**,逐日相減找增最多那天 → 抓那天高低點。
- **波段規劃 = 換倉成本 → 換倉成本(或月選大量區)**,**振幅約 300~500 點**;缺口一破就去找上/下一個換倉成本當終點。**結算限制:當月最多看到前一個換倉成本**。上下沒換倉成本時 → 用**月選**(非周選)大量區當終點(大量區會移動,要跟著微調)。核心紀律:**分批吃、不要一單爆到底**。

## 8. 免盯盤操作(對應你回測的 resting limit sell)

- **目前只能「半套」:** 必須先掛進場單、**成交後才能補掛**停利+停損,然後去上班。全自動(無單預掛條件單)要等券商功能。
- **掛單法(實例):** 進場 = 回測奇襲防守點/大紅底/呂布第二隻腳;成交後掛**停利 +100點(兩滿)**、**停損 -20點**,賺賠比固定 **5:1**。
- **進場要離關卡越近越好**(有 20 點 buffer,離太遠停損容易被掃)。
- **被掃就認**:當它 20% 勝率(出手5次賺1次),但賺賠比是對的。
- **趨勢盤可放大:** 電子同步、50檔全紅 → 抱久一點、接力、賭兩倍單,5:1 不是死的。
- **凱利公式盲點(重要警告):** 當沖代 25%勝率/75%/賺賠比5 → 約投 10% 資金。**寧願把勝率壓低估(20~25%)**;若高估成 9 成,一開始輸 9 成資金後面翻不了本(100萬→10萬→1萬)。
- **波段不能用固定賺賠比:** 波段只死控賠(-20點),賺不設限,只要求那一波 > 累積賠額。

## 9. 籌碼判讀(賣方那堂第三部分,降級為「輔助」)

講師自承「**三法為先,籌碼輔助**」「籌碼已反映在技術面,會看線型的人比籌碼重要」。指標:

1. **外資期貨 OI:** 不要只看淨額差,多單/空單**分開看**,記住增減發生在哪天/哪個指數位置(該位置 = 成本關卡)。
2. **選擇權買賣權 OI:** 把自己當外資,**看金額不看口數**(買1000台腳踏車比不上1台賓士)。自創 OP金額 = 多方金額 − 空方金額,正很多(10~15億以上)偏多。
3. **期貨大額交易人未沖銷結構表:** 換倉時最好用,看大戶下月偏多偏空;只差兩三千口的結算隔天可能翻盤。
4. **融資維持率:** 低於 160 大部分人賠錢,破 160 可能多殺多。

## 10. 一招選股 SOP(個股波段)

「三面向」交叉篩選:

1. **基本面:** 盈益率看三季比較,**最好都 >3%**(<3% 不推薦)。
2. **技術切入點:** 找跟 20MA 乖離率 **>0、<1%**(即將報大量、還沒報大量的);不建議回測 60MA(通常已出空方三法/報過大黑,風險大)。
3. **技術確認:** 多方三訊號(破大黑、出大紅、回測大紅底/關卡不破),或像「樓梯(多方階梯)」**但一定要有粗量**;所屬類股日K 在 20MA 之上。
4. **籌碼 confirm:** 主力法人軍線向上(各券商定義不同,5日/10日皆可),至少持平不向下;回測中至少一邊在買(法人賣主力買 or 反之)。
5. **進場掛價:** 怕掛不到 → 比 20MA 多測一些;不擔心 → 直接測 20MA 或比 20MA 少一點(防主力假突破洗單後再進)。
6. **停利:** 滿足點等幅(歷史滿足點 1:1 投射),不用等 20MA 跌破,直接停在最高點。
7. **加權軌道圖位階:** 接近軌道下緣做多;接近上緣或出現警線/三兄弟(乖離背離,三度背離=要反轉)就減碼出清,要提前(不能等黑K才動)。

> 三兄弟 = 乖離/背離類擺盪指標群(大哥、三弟為個別指標),位階低於三法。

## 11. 總經框架(總經小教室)

只到「擇時+格局」層級,不是單一數據觸發進出場,且強調「多項數據同步吻合才確認景氣循環轉折」。

- **GDP(第一堂):** GDP=國家總產出(流量),看一國像看一間公司財報。不直接看 GDP 絕對值(怕通膨灌水),用 **美國消費年增率**當代理(消費佔美國GDP七成、台/中六成,擒賊先擒王)。⭐ **把技術分析套到總經:消費年增率 1.2% 是一條頸線,「破而不過」= 景氣警訊**(2008/2000 都提前示警)。發動點仍回技術面(空方對稱缺口/高檔爆量/回測空方大黑點不過)才進場做空。比喻=**中醫望聞問切**(四指標=症狀、利率=藥),非農夫。GDP=第一道最大領先指標,但要多數據同步+技術面確認。進口總額≈消費≈S&P500(高度吻合)可當衰退領先。
- **CPI:** 看**名目 CPI vs 核心 CPI 背離**(核心=去掉能源食物)。名目拉高但核心拉不動 = 假通膨真通縮 = 熱錢炒、實質需求疲弱 = **空頭前兆**(原物料是景氣循環最後一棒)。沒給具體門檻數字。央行=農夫、貨幣=水、商品=作物;「通膨好治、通縮難治」。
- **就業:** 兩組曲線判循環位置 ——(A)新開職缺 vs 初領失業金開口擴到極致 → 反轉(2000/2008前兆);(B)時薪年增率 vs 勞參率黃金/死亡交叉(雇主是最敏感領先指標)。沒用「非農 NFP」這詞,用時薪/勞參/初領。
- **利率(第三堂,⭐最具操作性的總經訊號):** 利率一律用「**資金借貸成本**」想最易通;費雪:名目=實質+通膨。兩學派=兩種利率:古典(可貸資金說/債市/決定**實質利率**)、凱因斯(流動性偏好說/貨幣市場/決定**名目利率**)。債券價格與利率成反比(死記)。長債利率≈房貸利率、且影響股市估值(當時長債~2.2% vs 股市殖利率~3.8% → 錢往股市跑)。**負利差(殖利率倒掛,長利<短利)= 判斷股市空頭來臨的重要訊號:近30年三次 1989/2000/2007,之後台股都接空頭。** 機制=多頭末段「最後煙火」資金棄債進股 → 債價跌殖利率升、短利拉得比長利快 → 倒掛 → 崩盤。實質負利率(公債利率≤通膨)=債券被高估會崩。
- **連到交易:** 多總經指標互相驗證 → 判景氣循環在哪一棒 → 偏多/偏空格局與防升息回檔時機。

## 15. 第四批逐字稿新增(2026-06-30,10 份精讀整併)

### 15.1 軌道指標圖 = 手繪趨勢通道(覆盤軌道篇)— 補「還缺」最大塊
- **重大澄清**:軌道**不是有參數的內建指標**,是「**用過高破低 + 粗量位置手繪的趨勢通道**」。上升軌道=多方勢、下降軌道=空方勢。
- **高低點怎麼定**:用粗量打不穿的位置(主力程式單接的地方)+ 長上/下影線 + 出量認定。
- **轉勢判定**:低點不破低 + 高點過高 → 轉多;破低又不過高 → 轉空。軌道走平=煞車→轉向。
- **畫法**:手連能「同時顧到 3 點」的線當主軌(顧越多點威力越大),再對過去畫一條平行線 → 一組軌道≈3 條線(主軌+平行+中間)。日盛軟體一次只能畫 2 條。
- **⭐ 鐵則:軌道斜率與成交量成正比** → 除非量越放越大,否則**軌道修正只會越來越緩、不會越來越陡**;陡軌道要小心遲早走平轉向。
- **級數差異**:級數越小越難被軌道束縛;30分K 軌道很容易被破要時時修正,大級數久久才修。
- **復盤 SOP 核心**:「**只能往左看,不能往右看**」(假裝右邊還沒發生),修正軌道只准用已出現的點。
- **操作**:打軌道下緣做多;**出量沖軌道上緣/關卡 = 停利訊號**(「只要出量沖關卡我一定先跑」);跳空逆勢先出。
- **濾網疊加**:軌道 + 頸線 + 切線 + RSI(乖離/背離)越多吻合勝率越高。**切線=兩點成一線,突破+回測不破=趨勢改變**(解釋「為何有時摸不到軌道下緣」=被切線/頸線擋住)。
- **三兄弟疑似真身**:覆盤+選擇權實戰班都出現「大哥/小妹/3D」「三兄弟」。**3D=三度背離**(對上「三度背離=反轉」),大哥/小妹疑為同家族不同等級的乖離背離訊號;精確定義仍缺。

### 15.2 主力成本的「慣性」與多空成本(新手第3堂)
- **慣性定義**:指數**一定**會在多方成本與空方成本之間反覆互測,**不管趨勢盤或盤整盤**。「多方成本擋就去測空方成本;空方成本擋就去測多方成本」(乒乓球)。
- **⭐ 慣性的原因 = 累積籌碼**(老師當堂標準答案):互測=主力在區間裡裝貨,累積越久噴越高,動能夠了才往一方向突破。盤整不是沒方向,是主力在裝貨。
- **多空成本的精確定義**:= **大量紅/黑 K 的底部 = 開盤價**(跳空用虛擬紅底/黑底)。防守點關鍵句:「**這根 K 棒從哪裡攻擊,你就從哪裡算**」(從前收跳空攻擊就從前收算)。
- **⚠️ 這條「多空成本」是定樁型固定成本,≠ AVL**(AVL 是加權均線型變動成本)。兩條不同的線,別混。
- **每商品專屬級數**:台指期=30分K、股票=日K、小道瓊=120分K、小日經=60/120分K。找法:把各級數歷史「大量K棒防守點」叫出來,看哪個級數最常擋,那個就是該商品級數;級數越大誤差越大(50-60點)、越小誤差1-2點。
- **大量門檻**:台指期30分K = **兩萬口**(見第0節翻案)。
- **進出場**:鐵律「不要在接近空方成本時做多、不要在接近多方成本時做空」;**進場依據失守就出場**;去頭去尾。
- **倒推起疊點(老師稱「最高境界」)**:先估多方成本在哪,用滿足點(50點)往回倒推「起跌點」→ 當天劇本就出來(估多方成本9820 + 一滿50 → 起疊點9870 = 空點,吃9870→9820)。靠近滿足點的成本防線最容易破,別接。

### 15.3 點到點(位移)波段操盤法(新手第5堂)
- **定義**:用物理「位移 vs 路徑」比喻,只管起點與終點兩個關卡。**起點 = 進場點 = 防守點**;終點 = 下一個關卡。
- **關卡只有三類慣性**:均線慣性、多空成本慣性、驛站理論(缺口)。**均線值本身就是點**(如120分K的60MA)——我原本「換倉成本→換倉成本」定義太窄。
- **⭐ 鐵律:進場嚴(離關卡很近、買最低空最高)、出場寬**(出得掉就好,錢進口袋才算)。
- **分批接力**:OP **換履約價接力、接黑不接紅、改買價外一檔**(保住已吃獲利,苗頭不對可閃);大小台用「中間關卡」接力(台北→新竹→台中);**每次接力防守點重設到新進場點**。
- **⚠️ 振幅校正**:不是固定 300~500 點,是**依操作週期決定**;當沖日內最多 1~2 滿、超過兩滿少之又少;週波段才幾百點。
- **一關一關看**:前一關沒破不看下一關(「新竹沒過怎麼看台北」)。

### 15.4 看懂量價(幼幼班第2堂)— 量價地基
- **大量/粗量 = 相對量,無絕對門檻**(絕對門檻去三法/慣性堂找=2萬口那種)。**看量不看 K 棒長度**:量大十字線 > 量小長 K;小量長 K = 虛漲不重要。
- **單根 K 棒阻力成本定位**:紅 K(漲)阻力做多,成本在「開盤~最低」下影線;黑 K(跌)阻力做空,成本在最高(上影線)。(⚠️ 與三法「大紅底/大黑頂取開收盤」是不同層次,別互套。)
- **級數=比例尺**:當沖抓20/50/100點用1分/5分/30分K;波段抓500~1000點用日/週/月K。

### 15.5 大紅大黑的迷思 — 為什麼要用呂布
- **核心迷思**:把「大黑頂做空、大紅底做多」當機械規則用,會死在轉折(「大黑頂做空就一直下去?不是這樣」)。
- **K 棒顏色不可靠**:同一根 K,開收盤時間切法不同,黑 K 會變紅 K。**所以改看「粗量打在哪個關卡」,不看實體顏色**——這就是老師把三法重新詮釋成呂布(看量不看色)的底層理由。**三法=呂布是同一套東西。**
- **真假大紅大黑靠影線/位置分**:低點粗量=多單防守點、高點粗量=空單防守點。
- **粗量有三個時候**:起始攻擊量(可追)/ 中間過關卡的量(不管)/ 最後出貨量(別追);顏色只是機率傾向不是必然。

### 15.6 選擇權機制與賣方避險專章(實戰班 + 商品介紹 + 基本操作)
**這幾堂幾乎不講技術訊號,是選擇權機制專章。校正第6節若干誤併:**
- **契約乘數**:權利金 1 點 = NT$50(成交價×50 換台幣)。**⚠️ 與「一滿=50點」是兩回事**(乘數 vs 點數單位)。
- **Put-Call 推算指數**:價平時 call價=put價;call多→(call−put)+履約價;put多→履約價−(put−call)。算幾月看幾月台指期。
- **Delta(老師口語叫「波動率」)**:價平=0.5,越價內越大、越價外越小;**價平移動時整排 Delta 跟著移**(避險核心)。IV=隱含波動率=恐慌指數,系統性風險暴增→跌得比理論多。
- **Theta/結算**:價平每天約消失5點,結算前一週水平線、進一週內斜率銳減;周選衰減最快但收的點數也最少。**結算價=當天加權最後半小時101個價位平均**(漲跌看台指期、結算看加權)。
- **保證金**:買方無保證金;**賣方保證金 = 權利金市值 + MAX(A值−價外值, B值)**(A=19000、B=10000;價平/價內 價外值=0);SPAN 同時 SC+SP 會合併最佳化吐回保證金。維持率盡量>150%、120%危險。
- **勒式 vs 跨式精確區分**:**勒式 = 區間邊緣、分開建倉、用「區間」做防護**(SC往外100、SP往外100~200);**跨式 = 區間中間、同時建倉、用「收的權利金點數」做防護**。「價平做跨式 ≈ 價外做勒式」。
- **防護(避險)**:**事前防護(未虧)買價外**,且防護權利金不得大於 SELL 收的點數;**事後防護(已虧)買價平/價內**(Delta才追得上虧損速度)。**⚠️ 順序校正:先做跨式 SC+SP → 用 SC 保護 SP → 盤勢不如預期再補 VP**,不是「先 VP 再 SP」。
- **買方校正**:**當沖買方該用「近月月選」不是周選;周選只當賣方**——除非當天一定平掉、絕不留倉,才可周選當買方。**賭缺口買「價內一檔」**(賭12150缺口買12100的call,避免到了卻沒點數)。
- **⚠️ 履約價「兩檔價差≥20」誤併拆解**:這個20點分三個不同脈絡——(a)內含值門檻(指數−履約價>20才算價內)、(b)賣方一組價差賺≥20及格、(c)選履約價看「指數跑一滿足點該檔權利金價差有沒有到20」。**不是單一「買方選檔規則」。**
- **當沖賣方短單法**:當天跑完一到兩滿振幅(出現呂布)後,勇敢去 SP(跌完)/SC(漲完)最靠近價平履約價、不用防護(當沖可盯盤),勝率比買方高;例外=連假/封關前大家賭開紅盤,點數壓不下去。

### 15.7 資金控管:賺賠比 + 凱利(videoplayback,免盯盤母帶)
- **半套 vs 全套免盯盤**:全套=軟體出「進場+停損+停利一次掛」(當時還沒);半套=開盤掛進場、**成交後**補停利停損再上班。
- **凱利白話版**:F=勝率−敗率÷賺賠比;當沖 25%−75%÷5 → 動用資金約10%。
- **凱利盲點**:勝率設太高(如90%),選擇權買方歸零/連輸會「100萬→10萬→1萬」翻不了身 → **寧願把勝率壓低估(當沖最低抓20%)**。
- **當沖固定 5:1 的理由**:每日漲幅最常兩滿~三滿,保守抓兩滿=100點當賺、停損20點當賠 → 鎖 5:1(停損10點太極端辦不到)。
- **⚠️ 免盯盤有兩套,別混**:(1)**買方樂透單**=掛進場→補停利+100/停損−20、5:1、勝率~20%;(2)**賣方版**=觸軌道上緣SC往外100點包到結算。
- **1比1測幅 = 亞當理論**(老師個人認定);三法「出大紅回射大紅底」進場、1比1當停利。
- **顏值理論(換倉補充堂再確認)**:**日K球權 > 30分K球權**(臉蛋>個性)。
- **伏筆**:「散戶長期數學上必賠到0」有純數學推導,留 12月直播講(待挖)。

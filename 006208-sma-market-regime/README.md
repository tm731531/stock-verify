```

驗證: 2020 COVID 和 2022 大空頭都準確偵測
```

### Rule 2: 空頭確認 📉
```
條件: 50日 SMA < 200日 SMA
動作: 保持現金或最小倉位
目的: 確認你在下跌趨勢中
```

### Rule 3: 進場訊號 🚀
```
條件: 50日 SMA > 200日 SMA AND 波動率正常
動作: 滿倉進場
目的: 捕捉上升趨勢恢復
```

## ⚖️ 優缺點

### SMA 系統
✅ **優點**
- 超簡單（只看 2 個指標）
- 自動規則，無情緒
- 實證有效的空頭保護
- 易於自動化執行

❌ **缺點**
- 多頭期間落後 12-13%
- 偶爾誤訊號
- 需要耐心等待信號

### 定期定額
✅ **優點**
- 0 工作量
- 無誤訊號
- 多頭時表現更好

❌ **缺點**
- 空頭時全部承受
- 無風險管理

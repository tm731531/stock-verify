## 📊 案例 1：2025 年多頭反彈 (實際發生)

### 初始狀態 (2025-01-15)
```
現金: $500,000
倉位: $0
訊號: 無
```

### 📍 Step 1: 黃金交叉進場 (2025-01-20)

**市場狀況**:
- 50日 SMA: $118
- 200日 SMA: $115
- ATR: $2.5 (低於 MA 平均)
- 訊號: 黃金交叉 ✅ 進場

**執行**:
```
進場金額: $100,000
進場價格: $120
購買股數: 100,000 / 120 = 833.33 股

交易後狀態:
  現金: $400,000 (500k - 100k)
  倉位: $100,000 (@120)
  狀態: 等待加倒機會
```

---

### 📍 Step 2: 第一次加倒 (5 天後，2025-01-25)

**進場後監控**:
- Day 1-4: 價格緩慢上升 → 無出場訊號
- Day 5: 價格繼續上升 → 看漲信號確認

**加倒條件**:
- ✅ 無出場訊號（無死亡交叉、無警訊）
- ✅ 持倉滿 5 天
- ✅ 還有現金（$400k > $100k）
- ✅ 倉位未達上限（$100k < $300k）
- ✅ 價格持續上升

**執行第二筆進場**:
```
加倒金額: $100,000
加倒價格: $125 (略高於進場價，但繼續看漲)
購買股數: 100,000 / 125 = 800 股

累積倉位:
  現金: $300,000 (400k - 100k)
  倉位: $200,000 (100k + 100k)
  持股: 1,633 股 (833.33 + 800)
  平均成本: $122.4 (200k / 1,633)
```

**狀態**:
```
進場日期: 2025-01-20 + 2025-01-25
當前現金: $300,000 可用
當前倉位: $200,000 投入 (@125)
等待: 高點出場或進一步加倒
```

---

### 📍 Step 3: 第二次加倒 (10 天後，2025-02-04)

**連續看漲**:
- 過去 5 天價格持續上升
- 無任何出場訊號
- 多頭強勢中

**執行第三筆進場**:
```
加倒金額: $100,000
加倒價格: $130 (繼續上升)
購買股數: 100,000 / 130 = 769.23 股

累積倉位:
  現金: $200,000 (300k - 100k)
  倉位: $300,000 (200k + 100k) ← 達到上限！
  持股: 2,402 股 (1,633 + 769.23)
  平均成本: $124.9 (300k / 2,402)

狀態: 倉位已滿，不再加倒
```

---

### 📍 Step 4A: 第一層獲利出場 (+5% 目標，2025-02-10)

**出場條件達成**:
```
當前價格: $130.5
進場平均成本: $124.9
浮盈: ($130.5 - $124.9) × 2,402 = $13,440
浮盈率: 4.5% (接近 5% 目標)
```

**執行第一層出場**:
```
出場數量: 2,402 × 50% = 1,201 股
出場價格: $130.5
出場金額: 1,201 × $130.5 = $156,731

交易後狀態:
  現金: $200,000 + $156,731 = $356,731
  倉位: 1,201 股 × $130.5 = $156,731
  已實現: $156,731 - $150,000 = +$6,731 ✅

狀態: 保留剩餘倉位繼續持有，獲利已實現！
```

**現金流效果**:
```
初始現金: $500,000
投入倉位: -$300,000
部分出場: +$156,731
───────────────────
當前現金: $356,731 (可用 + 倉位投入)
實現獲利: +$6,731 (已確定)
```

---

### 📍 Step 4B: 第二層獲利出場 (+10% 目標，2025-02-15)

**繼續上升**:
```
當前價格: $137.4
剩餘持股: 1,201 股
浮盈: ($137.4 - $124.9) × 1,201 = $14,900
累積浮盈率: ($137.4 - $124.9) / $124.9 = 10.0% ✅
```

**執行第二層出場**:
```
出場數量: 1,201 × 100% = 1,201 股 (全出)
出場價格: $137.4
出場金額: 1,201 × $137.4 = $165,015

完全平倉後:
  現金: $356,731 + $165,015 = $521,746
  倉位: $0
  已實現:
    第一層: +$6,731
    第二層: +$15,015
    合計: +$21,746 ✅
```

# SMA 市場制度策略 - 簡單說明

## 🎯 策略核心概念

這個策略只做一件事：**在空頭來時減倉，在多頭確認時進場**

---

## 📊 三條簡單規則

### 規則 1️⃣ - 警訊信號（空頭快來了）⚠️

**看什麼**：波動率爆炸 + 大跌
```
條件：
  • ATR (波動率) > 其平均值的 1.5 倍
  • 單日下跌 > 3%
```

**做什麼**：減倉 50%
```
進場前：買 100 股
收到警訊：賣掉 50 股，保留 50 股現金
```

**歷史驗證**：
- 2020 年 COVID 崩盤 → 準確預警 ✅
- 2022 年大空頭 → 準確預警 ✅

---

### 規則 2️⃣ - 確認空頭（你在下跌趨勢中）📉

**看什麼**：50 日線 vs 200 日線
```
50日線在下面（下穿）
↓
200日線在上面（上穿）

  這表示：短期跌破長期
  = 下跌趨勢開始
```

**做什麼**：暫停進場，等待恢復
```
空頭期間：
  • 不主動買入
  • 保持現金充足
  • 等待反彈信號
```

**視覺圖示**：
```
價格走勢         SMA 50 vs SMA 200

多頭階段：          空頭階段：        恢復階段：

  價格              價格                 價格
   ↗                 ↘                    ↗
                     ×(死亡交叉)         ×(黃金交叉)
   200-MA-          50-MA-              50-MA-
   50-MA-           200-MA-             200-MA-

  買進持有         減倉保護             加倉參與
```

---

### 規則 3️⃣ - 進場信號（空頭結束了）🚀

**看什麼**：恢復跡象
```
條件：
  • 50日線穿過 200日線（往上）
  • 波動率回到正常（不再爆炸）
```

**做什麼**：滿倉進場
```
之前狀態：50% 現金 + 50% 股票
收到信號：買回現金部分，變成 100% 持有
```

**歷史驗證**：
- 2020 年 COVID 後 → 準確進場 ✅
- 2022 年底恢復 → 準確進場 ✅

---

## 📈 實際例子：2022 年大空頭

### 定期定額投資者 (買買買，不管市場)
```
1 月：買 $2,000 → 價格 $170 → 買到 11 股
2 月：買 $2,000 → 價格 $160 → 買到 12 股  ⚠️ 開始跌
3 月：買 $2,000 → 價格 $145 → 買到 13 股  📉 持續跌
4 月：買 $2,000 → 價格 $135 → 買到 14 股
5 月：買 $2,000 → 價格 $130 → 買到 15 股  (最低點)
6 月：買 $2,000 → 價格 $135 → 買到 14 股
...
結果：持倉多，虧損很大 ❌
```

### SMA 策略投資者（聰明躲避）
```
1 月：買 $2,000 → 正常進場
2 月：買 $2,000 → 正常進場
3 月：收到警訊 ⚠️
      → 減倉 50%（賣掉一半，保護現金）
4 月-5 月：持有現金 💰
      → 波動率爆炸，堅持不買
6 月：恢復訊號 🚀
      → 用保留的現金加倉
...
結果：虧損少很多，保護了資本 ✅
```

### 數據對比

```
SMA 策略：  +$4,810 小賺

保護價值：  +$18,150 (18% 優勢!)
```

**理解**：
- 定期定額在 6 年大漲時賺更多（多頭優勢）
- SMA 策略在 1 年大跌時保護更多（空頭優勢）
- 你選哪個取決於：怕虧損？還是怕賺不到？

## 🔍 如何判斷？（日常執行）

### 每天 12 點檢查清單（只需 30 秒）

```
1. 查看今天的 50日 SMA 和 200日 SMA
   □ 50日線在上面？  → 多頭信號 ✅
   □ 50日線在下面？  → 空頭信號 ⚠️

2. 查看波動率 (ATR)
   □ ATR > 平均的 1.5 倍？  → 危險信號 ⚠️
   □ ATR 正常？             → 安全 ✅

3. 根據組合做決定
   • 多頭 + 安全  → 滿倉持有 (100%)
   • 多頭 + 危險  → 減倉保護 (50%)
   • 空頭 + 危險  → 空倉等待 (0%)
   • 空頭 + 安全  → 準備進場
```

## ✅ 為什麼這個策略可行？

1. **簡單** - 只看 2 個指標，任何人都能理解
2. **自動** - 規則清晰，電腦可以執行，無需判斷
3. **實證** - 用 6 年真實數據驗證過
4. **有效** - 2022 年大空頭實際保護了資本

---

## ❌ 為什麼不完美？

1. **多頭時落後** - 多頭期間你的收益會比定期定額少
2. **會有誤訊** - 偶爾會有假的警訊信號
3. **需要紀律** - 你要確實執行每個信號

---

## 📞 快速問答

**Q: 一定要每天檢查嗎？**
A: 不一定。可以每週檢查一次，錯過重要信號的機率低（這個例子中只有 2 個警訊）

**Q: 如果信號出錯怎麼辦？**
A: 最多虧 3-5%，因為我們會定期檢查。不會一路跌到底。

**Q: 可以完全自動化嗎？**
A: 可以，但建議保留手動檢查的習慣（發現異常時能及時干預）

**Q: 為什麼不用更複雜的策略？**
A: 複雜 ≠ 賺更多。這個簡單系統已經驗證有效，複雜策略容易過度優化。

---

**結論**: 這個 SMA 策略就是一個簡單的「空頭避險工具」，不是為了賺最多錢，而是為了在空頭時活下去。
